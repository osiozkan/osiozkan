# Bundled Aegisub scripts

The Lua files in `autoload/` and `include/` are the **unmodified stock Automation scripts** shipped with
[Aegisub](https://github.com/Aegisub/Aegisub) (`automation/autoload`, `automation/include`), bundled so SubForge's
karaoke templater and helper macros work out of the box. Each file carries its own copyright/licence header
(BSD-3-Clause for the Niels Martin Hansen / Rodrigo Braz Monteiro files, ISC for the Thomas Goyne files); those headers
must stay intact. SubForge's own code is not affected by those licences.
