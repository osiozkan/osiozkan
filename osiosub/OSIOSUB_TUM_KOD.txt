--- KOMUTLAR ---
Derleme ve test:
  cd osiosub
  cargo test --workspace
  cargo build --release            # target/release/osiosub (CLI), osiosub-app (arayüz)

Arayüz:
  target/release/osiosub-app [altyazi.ass] [video.mkv|ses.flac]

CLI:
  osiosub convert <giris> <cikis>          # ass/srt/vtt/txt arası dönüşüm
  osiosub check <dosya>                    # QC raporu
  osiosub shift <giris> <cikis> <ms>       # tüm satırları kaydır
  osiosub fix <giris> <cikis>              # temizle, çakışma/süre/CPS düzelt, otomatik satır böl
  osiosub macros <script.lua>              # script'in makrolarını listele
  osiosub run <script.lua> <giris> <cikis> [makro-no|ad] [ilk-son]

Lua scriptleri: osiosub/automation/autoload/ klasörüne koyun veya Otomasyon > Betik yükle.
Gereksinimler: Rust, (isteğe bağlı) ffmpeg/ffprobe (video önizleme, ses yedek çözücü).
Not: dicts/*.gz (Türkçe sözlük, 2 MB) ve Cargo.lock bu txt'ye dahil değil; depoda mevcut.

# OsioSub — Yol Haritası / Roadmap

Hedef: Aegisub'ın tam işlevselliği + Subtitle Edit'in en iyi özellikleri + mevcut Aegisub Lua
(Automation 4) scriptleriyle birebir uyum, kolay arayüz, yüksek performans. Gece oturumları
bu dosyayı güncelleyerek devam eder (her gece 22:00 → 06:00).

## Mimari
- `core/`  – ASS/SRT/VTT modeli, zaman, renk, etiketler, QC, zamanlama, arama, geri alma, Türkçe metin.
- `lua/`   – Aegisub Automation 4 uyumlu Lua 5.1 çalışma zamanı (`aegisub.*`, `subs`, `include`, util/karaskel/re/unicode/utf8).
- `cli/`   – `osiosub` komut satırı (convert/check/shift/fix/macros/run).
- `media/` – ses çözme (symphonia + ffmpeg yedek), dalga formu, ffprobe/ffmpeg ile video önizleme (libass).
- `app/`   – egui masaüstü arayüzü (ızgara, editör, dalga formu, önizleme, stil yöneticisi, QC, yazım denetimi, Lua makroları).

## Durum
- [x] ASS okuma/yazma (SSA v4 dahil, bilinmeyen bölümler korunur)
- [x] SRT/VTT/TXT içe/dışa aktarma
- [x] Zaman araçları: kaydır, doğrusal, fps dönüşümü, boşluk kapat/zorla, böl/birleştir
- [x] QC: CPS, satır uzunluğu/sayısı, süre, çakışma, tipografi, tanımsız stil
- [x] Türkçe İ/ı büyük-küçük harf, tipografi düzeltmeleri
- [x] Bul/Değiştir (regex, etiket atlama)
- [x] Geri al/yinele
- [x] Lua: `subs` (okuma/yazma/insert/append/delete/deleterange), register_macro/filter, dialog, log, progress, cancel
- [x] Lua kütüphaneleri: util, karaskel (temel), utf8, unicode, re
- [x] CLI

- [x] GUI: ızgara, editör, geri al/yinele, bul/değiştir, stil yöneticisi, QC, klavye gezinmesi, ayar kalıcılığı
- [x] Dalga formu (sürükle: başlangıç/bitiş, Alt+tık, sağ tık), video önizleme (libass), Ctrl+tık → \pos
- [x] Türkçe yazım denetimi (gömülü Hunspell tr, MIT lisanslı sözlük: `dicts/`)
- [x] Toplu düzeltmeler (otomatik satır böl, HI sil, çakışma, CPS uzat, min süre), karaoke \k üretici
- [x] Gerçek Aegisub `karaskel`/`utils`/`cleantags` dosyaları gömülü (`lua/lib/include`), `aegisub.parse_karaoke_data`, `subs.script_resolution`, ipairs(subs)
- [x] CI iş akışı (Linux/Windows/macOS)

## Sıradaki işler (öncelik sırasıyla)
1. **Kullanıcının kendi Lua scriptleri ile uyumluluk testi**: scriptler `osiosub/automation/autoload/` altına konunca
   gece oturumu hepsini `osiosub run` ile deneyip hataları düzeltecek (şu an elimizde yok). Gerçek `kara-templater.lua`
   ile uçtan uca test (güvenilir kaynaktan, elle eklenince).
2. **Ses oynatma** (cpal) + oynatma imleci, spektrum görünümü, kare adımlı video gezinme, keyframe snap, sahne değişimi.
3. Video önizlemede sürekli oynatma (ffmpeg boru hattı) ve görsel typesetting araçları (\move, \clip, \org sürükle).
4. Kaydetme sırasında font gömme (`[Fonts]`), eksik font uyarısı (`fonts::has_font`).
5. Lua: `aegisub.dialog.open/save`, `ILL`/`Yutils` uyumluluk testleri, `lfs`, `clipper`, tam `karaskel` (furigana), `cleantags`, `auto4 filter config`.
6. Subtitle Edit özellikleri: Netflix/BBC kalite kontrol profilleri, OCR (Tesseract) ile görüntü tabanlı altyazı, otomatik çeviri (API), Whisper ile oto-transkripsiyon, spell-check (Hunspell tr_TR), bul-değiştir çoklu dosya, toplu dönüştürme.
7. Anime özel: Karaoke zamanlayıcı, typesetting araçları (\pos/\move/\clip görsel), stil kopyala, `Dialogue/Comment` toplu işlemleri, çeviri-düzenleme-QC iş akışı, sahne değişimi snap.
8. Paketleme: Windows/macOS/Linux sürümleri (GitHub Actions).

## Bilinen sınırlar
- `text_extents` şimdilik yaklaşık ölçüm yapıyor (font motoru yok).
- Eski oturumlardan "karşılaşılan altyazı sorunları" listesi bu depoda yok; sorunlar `docs/ISSUES.md` altında toplanacak
  (Türkçe İ/ı, çift boşluk, `...` → `…`, çakışmalar, CPS vb. QC'ye eklendi).

use crate::worker::{self, FromWorker, ToWorker, Worker};
use egui::{Color32, RichText};
use egui_extras::{Column, TableBuilder};
use egui_file_dialog::FileDialog;
use osiosub_core::{
    ass::{AssFile, Event, Style},
    color::Color,
    qc::{self, Issue, QcConfig, Severity},
    search::{self, Field, SearchOpts},
    tags, textfmt, time, timing, turkish,
    fixes, karaoke,
    spell::{Misspelling, Speller},
    undo::History,
};
use osiosub_lua::{DialogResult, DialogSpec, DlgVal, MacroInfo};
use osiosub_media::{AudioPeaks, VideoInfo};
use std::collections::{BTreeMap, BTreeSet};
use std::sync::{mpsc, Arc};
use std::path::PathBuf;

#[derive(Clone, Copy, PartialEq)]
enum FileAction { Open, SaveAs, Export, LoadScript, OpenAudio, OpenVideo }

#[derive(Default)]
struct FindState { open: bool, pattern: String, with: String, regex: bool, case: bool, word: bool, skip_tags: bool, field: u8, msg: String }

#[derive(Default)]
struct ShiftState { open: bool, ms: String, start: bool, end: bool, selected_only: bool }

pub struct OsioApp {
    file: AssFile,
    path: Option<PathBuf>,
    dirty: bool,
    rev: u64,
    hist: History,
    sel: BTreeSet<usize>,
    active: Option<usize>,
    anchor: Option<usize>,
    status: String,
    issues: Vec<Issue>,
    issues_rev: u64,
    qc_cfg: QcConfig,
    show_qc: bool,
    show_styles: bool,
    style_idx: usize,
    show_props: bool,
    show_log: bool,
    log: String,
    find: FindState,
    shift: ShiftState,
    fd: FileDialog,
    fd_action: FileAction,
    worker: Worker,
    macros: Vec<MacroInfo>,
    running: bool,
    dialog: Option<(DialogSpec, BTreeMap<String, DlgVal>)>,
    time_buf: (Option<usize>, String, String),
    scroll_to: Option<usize>,
    export_ext: &'static str,
    audio: Option<Arc<AudioPeaks>>,
    audio_rx: Option<mpsc::Receiver<Result<AudioPeaks, String>>>,
    audio_name: String,
    wave_start: f64,
    wave_mspp: f64,
    wave_follow: Option<usize>,
    drag: Option<(usize, bool)>,
    video: Option<(PathBuf, VideoInfo)>,
    prev_tex: Option<egui::TextureHandle>,
    prev_rx: Option<mpsc::Receiver<Result<(i32, i32, Vec<u8>), String>>>,
    prev_last: (u64, i64),
    prev_ms: i64,
    prev_err: String,
    focus_text: bool,
    speller: Option<Arc<Speller>>,
    speller_rx: Option<mpsc::Receiver<Result<Speller, String>>>,
    show_spell: bool,
    spell_hits: Vec<(usize, Misspelling, Vec<String>)>,
    spell_ignore: BTreeSet<String>,
}

impl OsioApp {
    pub fn new(cc: &eframe::CreationContext<'_>, arg: Option<String>) -> Self {
        cc.egui_ctx.set_visuals(egui::Visuals::dark());
        let mut qc_cfg = QcConfig::default();
        let mut ignore = BTreeSet::new();
        if let Some(st) = cc.storage {
            if let Some(v) = st.get_string("max_cps").and_then(|v| v.parse().ok()) { qc_cfg.max_cps = v; }
            if let Some(v) = st.get_string("max_line_len").and_then(|v| v.parse().ok()) { qc_cfg.max_line_len = v; }
            if let Some(v) = st.get_string("min_dur_ms").and_then(|v| v.parse().ok()) { qc_cfg.min_dur_ms = v; }
            if let Some(v) = st.get_string("spell_ignore") { for w in v.lines() { if !w.is_empty() { ignore.insert(w.to_string()); } } }
        }
        let mut app = OsioApp {
            file: AssFile::new_default(), path: None, dirty: false, rev: 0, hist: History::new(200),
            sel: BTreeSet::new(), active: None, anchor: None, status: "Hazır".into(), issues: vec![], issues_rev: u64::MAX,
            qc_cfg, show_qc: false, show_styles: false, style_idx: 0, show_props: false, show_log: false,
            log: String::new(), find: FindState { skip_tags: true, ..Default::default() }, shift: ShiftState { start: true, end: true, ..Default::default() },
            fd: FileDialog::new(), fd_action: FileAction::Open, worker: worker::spawn(cc.egui_ctx.clone()), macros: vec![],
            running: false, dialog: None, time_buf: (None, String::new(), String::new()), scroll_to: None, export_ext: "srt",
            audio: None, audio_rx: None, audio_name: String::new(), wave_start: 0.0, wave_mspp: 20.0, wave_follow: None, drag: None,
            video: None, prev_tex: None, prev_rx: None, prev_last: (u64::MAX, -1), prev_ms: 0, prev_err: String::new(),
            focus_text: false, speller: None, speller_rx: None, show_spell: false, spell_hits: vec![], spell_ignore: ignore,
        };
        if let Some(p) = arg { app.open_path(PathBuf::from(p)); }
        if let Some(a) = std::env::args().nth(2) { let pa = PathBuf::from(a); if pa.extension().map_or(false, |e| ["mp4", "mkv", "avi", "webm", "mov"].contains(&e.to_string_lossy().to_lowercase().as_str())) { app.load_video(pa, &cc.egui_ctx); } else { app.load_audio(pa, &cc.egui_ctx); } }
        // auto-load scripts from ./automation/autoload if present
        if let Ok(rd) = std::fs::read_dir("automation/autoload") {
            for e in rd.flatten() { if e.path().extension().map_or(false, |x| x == "lua") { let _ = app.worker.tx.send(ToWorker::Load(e.path())); } }
        }
        app
    }

    fn touch(&mut self) { self.dirty = true; self.rev += 1; }
    fn snapshot(&mut self, label: &str) { self.hist.record(label, &self.file); }

    fn open_path(&mut self, p: PathBuf) {
        match std::fs::read(&p) {
            Ok(b) => match textfmt::open_any(&p.to_string_lossy(), &String::from_utf8_lossy(&b)) {
                Ok(f) => {
                    self.file = f; self.hist = History::new(200); self.sel.clear(); self.active = if self.file.events.is_empty() { None } else { Some(0) };
                    if let Some(a) = self.active { self.sel.insert(a); }
                    self.status = format!("Açıldı: {} ({} satır)", p.display(), self.file.events.len());
                    let is_ass = p.extension().map_or(false, |e| e.eq_ignore_ascii_case("ass") || e.eq_ignore_ascii_case("ssa"));
                    self.path = if is_ass { Some(p) } else { None };
                    self.dirty = !is_ass; self.rev += 1;
                }
                Err(e) => self.status = format!("Hata: {e}"),
            },
            Err(e) => self.status = format!("Açılamadı: {e}"),
        }
    }

    fn save_to(&mut self, p: PathBuf) {
        let l = p.to_string_lossy().to_ascii_lowercase();
        let s = if l.ends_with(".srt") { textfmt::to_srt(&self.file) } else if l.ends_with(".vtt") { textfmt::to_vtt(&self.file) } else if l.ends_with(".txt") { textfmt::to_txt(&self.file) } else { self.file.to_string() };
        match std::fs::write(&p, s) {
            Ok(_) => { self.status = format!("Kaydedildi: {}", p.display()); if l.ends_with(".ass") || l.ends_with(".ssa") { self.path = Some(p); self.dirty = false; } }
            Err(e) => self.status = format!("Kaydedilemedi: {e}"),
        }
    }

    fn save(&mut self) {
        match self.path.clone() { Some(p) => self.save_to(p), None => { self.fd_action = FileAction::SaveAs; self.fd.save_file(); } }
    }

    fn selected_vec(&self) -> Vec<usize> { self.sel.iter().cloned().collect() }

    fn select_only(&mut self, i: usize) { self.sel.clear(); self.sel.insert(i); self.active = Some(i); self.anchor = Some(i); }

    fn insert_event(&mut self, at: usize, ev: Event) {
        self.snapshot("Satır ekle");
        let at = at.min(self.file.events.len());
        self.file.events.insert(at, ev);
        self.select_only(at); self.scroll_to = Some(at); self.touch();
    }

    fn new_event_after(&self, i: Option<usize>) -> Event {
        match i.and_then(|i| self.file.events.get(i)) {
            Some(e) => Event { start: e.end, end: e.end + 2000, style: e.style.clone(), layer: e.layer, actor: e.actor.clone(), ..Default::default() },
            None => Event::default(),
        }
    }

    fn delete_selected(&mut self) {
        if self.sel.is_empty() { return; }
        self.snapshot("Sil");
        let first = *self.sel.iter().next().unwrap();
        let del = self.sel.clone();
        let mut i = 0;
        self.file.events.retain(|_| { let k = !del.contains(&i); i += 1; k });
        self.sel.clear();
        if !self.file.events.is_empty() { self.select_only(first.min(self.file.events.len() - 1)); } else { self.active = None; }
        self.touch();
    }

    fn duplicate_selected(&mut self) {
        if self.sel.is_empty() { return; }
        self.snapshot("Çoğalt");
        let idx = self.selected_vec();
        let last = *idx.last().unwrap();
        let copies: Vec<Event> = idx.iter().map(|&i| self.file.events[i].clone()).collect();
        for (k, c) in copies.into_iter().enumerate() { self.file.events.insert(last + 1 + k, c); }
        self.touch();
    }

    fn run_macro(&mut self, idx: usize) {
        if self.running { self.status = "Bir makro zaten çalışıyor".into(); return; }
        self.running = true;
        self.log.clear();
        let _ = self.worker.tx.send(ToWorker::Run { idx, file: self.file.clone(), sel: self.selected_vec(), active: self.active.unwrap_or(0) });
    }

    fn poll_worker(&mut self) {
        while let Ok(m) = self.worker.rx.try_recv() {
            match m {
                FromWorker::Loaded(r, all) => {
                    self.macros = all;
                    match r { Ok(n) => self.status = format!("{n} makro yüklendi"), Err(e) => { self.log.push_str(&format!("Script hatası: {e}\n")); self.show_log = true; } }
                }
                FromWorker::Log(s) => { self.log.push_str(&s); self.show_log = true; }
                FromWorker::Dialog(spec) => {
                    let mut vals = BTreeMap::new();
                    for c in &spec.controls {
                        if c.name.is_empty() { continue; }
                        let v = match c.class.as_str() {
                            "checkbox" => DlgVal::Bool(matches!(c.value, Some(DlgVal::Bool(true)))),
                            "dropdown" => c.value.clone().unwrap_or_else(|| DlgVal::Str(c.items.first().cloned().unwrap_or_default())),
                            "intedit" | "floatedit" | "slider" => c.value.clone().unwrap_or(DlgVal::Num(c.min.unwrap_or(0.0))),
                            "label" => continue,
                            _ => c.value.clone().unwrap_or_else(|| DlgVal::Str(c.text.clone())),
                        };
                        vals.insert(c.name.clone(), v);
                    }
                    self.dialog = Some((spec, vals));
                }
                FromWorker::Done(res) => {
                    self.running = false;
                    if let Some(e) = res.error { self.log.push_str(&format!("Hata: {e}\n")); self.show_log = true; self.status = "Makro hatası".into(); }
                    else if res.cancelled { self.status = "Makro iptal edildi".into(); }
                    else if let Some(f) = res.file {
                        if f != self.file { self.snapshot("Makro"); self.file = f; self.touch(); }
                        if let Some(s) = res.selection { self.sel = s.into_iter().filter(|&i| i < self.file.events.len()).collect(); }
                        if let Some(a) = res.active { self.active = Some(a.min(self.file.events.len().saturating_sub(1))); }
                        else if let Some(&a) = self.sel.iter().next() { self.active = Some(a); }
                        self.status = "Makro tamamlandı".into();
                    }
                }
            }
        }
    }

    fn handle_shortcuts(&mut self, ctx: &egui::Context) {
        use egui::{Key, KeyboardShortcut as K, Modifiers as M};
        let c = ctx.input_mut(|i| (
            i.consume_shortcut(&K::new(M::COMMAND, Key::Z)), i.consume_shortcut(&K::new(M::COMMAND, Key::Y)),
            i.consume_shortcut(&K::new(M::COMMAND, Key::S)), i.consume_shortcut(&K::new(M::COMMAND, Key::O)),
            i.consume_shortcut(&K::new(M::COMMAND, Key::F)), i.consume_shortcut(&K::new(M::COMMAND, Key::D)),
            i.consume_shortcut(&K::new(M::COMMAND, Key::Delete)),
        ));
        // grid navigation when no text widget has keyboard focus
        if !ctx.egui_wants_keyboard_input() && !self.file.events.is_empty() {
            let (up, down, home, end, enter, pgup, pgdn) = ctx.input_mut(|i| (
                i.consume_key(M::NONE, Key::ArrowUp), i.consume_key(M::NONE, Key::ArrowDown),
                i.consume_key(M::NONE, Key::Home), i.consume_key(M::NONE, Key::End),
                i.consume_key(M::NONE, Key::Enter), i.consume_key(M::NONE, Key::PageUp), i.consume_key(M::NONE, Key::PageDown)));
            let n = self.file.events.len();
            let cur = self.active.unwrap_or(0);
            let target = if up { Some(cur.saturating_sub(1)) } else if down { Some((cur + 1).min(n - 1)) } else if home { Some(0) } else if end { Some(n - 1) }
                else if pgup { Some(cur.saturating_sub(15)) } else if pgdn { Some((cur + 15).min(n - 1)) } else { None };
            if let Some(t) = target { self.select_only(t); self.scroll_to = Some(t); }
            if enter { self.focus_text = true; }
        }
        // Ctrl+Enter inside the editor: next line, keep typing
        if ctx.egui_wants_keyboard_input() && ctx.input_mut(|i| i.consume_shortcut(&K::new(M::COMMAND, Key::Enter))) {
            if let Some(a) = self.active { if a + 1 < self.file.events.len() { self.select_only(a + 1); self.scroll_to = Some(a + 1); self.focus_text = true; } }
        }
        if ctx.input_mut(|i| i.consume_key(M::NONE, Key::Escape)) { ctx.memory_mut(|m| m.stop_text_input()); }
        if c.0 { if self.hist.undo(&mut self.file).is_some() { self.touch(); } }
        if c.1 { if self.hist.redo(&mut self.file).is_some() { self.touch(); } }
        if c.2 { self.save(); }
        if c.3 { self.fd_action = FileAction::Open; self.fd.pick_file(); }
        if c.4 { self.find.open = true; }
        if c.5 { self.duplicate_selected(); }
        if c.6 { self.delete_selected(); }
    }

    fn apply_fix(&mut self, label: &str, f: impl FnOnce(&mut AssFile) -> usize) {
        self.snapshot(label);
        let n = f(&mut self.file);
        if n == 0 { self.hist.undo(&mut self.file); self.status = format!("{label}: değişiklik yok"); }
        else { self.touch(); self.status = format!("{label}: {n} satır"); }
    }

    fn map_text(&mut self, sel: &[usize], f: impl Fn(&str) -> String) {
        if sel.is_empty() { return; }
        self.snapshot("Metin dönüşümü");
        for &i in sel { if let Some(e) = self.file.events.get_mut(i) { e.text = f(&e.text); } }
        self.touch();
    }

    fn grid(&mut self, ui: &mut egui::Ui) {
        if self.issues_rev != self.rev { self.issues = qc::check(&self.file, &self.qc_cfg); self.issues_rev = self.rev; }
        let bad: BTreeMap<usize, Severity> = self.issues.iter().fold(BTreeMap::new(), |mut m, i| { let e = m.entry(i.line).or_insert(i.severity); if i.severity as u8 > *e as u8 { *e = i.severity; } m });
        let n = self.file.events.len();
        let mut clicked: Option<(usize, egui::Modifiers)> = None;
        let mut tb = TableBuilder::new(ui).striped(true).resizable(true).sense(egui::Sense::click())
            .column(Column::exact(46.0)).column(Column::exact(86.0)).column(Column::exact(86.0)).column(Column::exact(56.0))
            .column(Column::exact(44.0)).column(Column::exact(90.0)).column(Column::exact(80.0)).column(Column::remainder().clip(true))
            .min_scrolled_height(0.0);
        if let Some(r) = self.scroll_to.take() { tb = tb.scroll_to_row(r, Some(egui::Align::Center)); }
        tb.header(20.0, |mut h| {
            for t in ["#", "Başlangıç", "Bitiş", "Süre", "CPS", "Stil", "Aktör", "Metin"] { h.col(|ui| { ui.strong(t); }); }
        }).body(|body| {
            body.rows(20.0, n, |mut row| {
                let i = row.index();
                let e = &self.file.events[i];
                row.set_selected(self.sel.contains(&i));
                let dur = e.end - e.start;
                let cps = qc::cps(&e.text, dur);
                let sev = bad.get(&i);
                let txt = tags::visible_text(&e.text).replace('\n', "  |  ");
                let dim = e.comment;
                let mk = |s: String| { let t = RichText::new(s); if dim { t.weak().italics() } else { t } };
                row.col(|ui| { ui.label(mk(format!("{}", i + 1))); });
                row.col(|ui| { ui.label(mk(time::fmt_ass(e.start))); });
                row.col(|ui| { ui.label(mk(time::fmt_ass(e.end))); });
                row.col(|ui| { ui.label(mk(format!("{:.2}", dur as f64 / 1000.0))); });
                row.col(|ui| { let mut t = RichText::new(if cps.is_finite() { format!("{:.1}", cps) } else { "∞".into() }); if cps > self.qc_cfg.max_cps { t = t.color(Color32::from_rgb(255, 120, 90)); } ui.label(t); });
                row.col(|ui| { ui.label(mk(e.style.clone())); });
                row.col(|ui| { ui.label(mk(e.actor.clone())); });
                row.col(|ui| {
                    let mut t = RichText::new(txt);
                    if dim { t = t.weak().italics(); }
                    match sev { Some(Severity::Error) => t = t.color(Color32::from_rgb(255, 100, 100)), Some(Severity::Warning) => t = t.color(Color32::from_rgb(255, 205, 100)), _ => {} }
                    ui.label(t);
                });
                let r = row.response();
                if r.clicked() { clicked = Some((i, ui_mods(&r))); }
            });
        });
        if let Some((i, m)) = clicked {
            if m.shift && self.anchor.is_some() {
                let a = self.anchor.unwrap();
                let (lo, hi) = (a.min(i), a.max(i));
                if !m.command { self.sel.clear(); }
                for k in lo..=hi { self.sel.insert(k); }
                self.active = Some(i);
            } else if m.command {
                if !self.sel.remove(&i) { self.sel.insert(i); }
                self.active = Some(i); self.anchor = Some(i);
            } else { self.select_only(i); }
        }
    }

    fn editor(&mut self, ui: &mut egui::Ui) {
        let Some(a) = self.active.filter(|&a| a < self.file.events.len()) else { ui.label(RichText::new("Satır seçilmedi — Altyazı ▸ Sonrasına satır ekle").weak()); return; };
        if self.time_buf.0 != Some(a) || !ui.memory(|m| m.focused().is_some()) {
            self.time_buf = (Some(a), time::fmt_ass(self.file.events[a].start), time::fmt_ass(self.file.events[a].end));
        }
        let styles: Vec<String> = self.file.styles.iter().map(|s| s.name.clone()).collect();
        let mut ev = self.file.events[a].clone();
        let mut changed = false; let mut started = false;
        ui.horizontal(|ui| {
            ui.checkbox(&mut ev.comment, "Yorum").changed().then(|| { changed = true; started = true; });
            ui.label("Katman"); let r = ui.add(egui::DragValue::new(&mut ev.layer)); if r.changed() { changed = true; } if r.drag_started() { started = true; }
            ui.label("Stil");
            egui::ComboBox::from_id_salt("stylebox").selected_text(&ev.style).show_ui(ui, |ui| { for s in &styles { if ui.selectable_value(&mut ev.style, s.clone(), s).changed() { changed = true; started = true; } } });
            ui.label("Aktör"); let r = ui.add(egui::TextEdit::singleline(&mut ev.actor).desired_width(90.0)); if r.changed() { changed = true; } if r.gained_focus() { started = true; }
            ui.label("Efekt"); let r = ui.add(egui::TextEdit::singleline(&mut ev.effect).desired_width(90.0)); if r.changed() { changed = true; } if r.gained_focus() { started = true; }
            for (l, v) in [("Sol", &mut ev.margin_l), ("Sağ", &mut ev.margin_r), ("Dik", &mut ev.margin_v)] { ui.label(l); let r = ui.add(egui::DragValue::new(v)); if r.changed() { changed = true; } if r.drag_started() { started = true; } }
        });
        ui.horizontal(|ui| {
            ui.label("Başlangıç");
            let r1 = ui.add(egui::TextEdit::singleline(&mut self.time_buf.1).desired_width(90.0));
            ui.label("Bitiş");
            let r2 = ui.add(egui::TextEdit::singleline(&mut self.time_buf.2).desired_width(90.0));
            if r1.lost_focus() || r2.lost_focus() {
                if let Some(s) = time::parse_ass(&self.time_buf.1) { if s != ev.start { ev.start = s; changed = true; started = true; } }
                if let Some(e) = time::parse_ass(&self.time_buf.2) { if e != ev.end { ev.end = e; changed = true; started = true; } }
            }
            let mut dur = (ev.end - ev.start) as f64 / 1000.0;
            ui.label("Süre"); if ui.add(egui::DragValue::new(&mut dur).speed(0.01).suffix(" s").fixed_decimals(2)).changed() { ev.end = ev.start + (dur * 1000.0).round() as i64; changed = true; started = true; }
            let cps = qc::cps(&ev.text, ev.end - ev.start);
            let lens = tags::line_lengths(&ev.text);
            let col = if cps > self.qc_cfg.max_cps { Color32::from_rgb(255, 120, 90) } else { Color32::LIGHT_GREEN };
            ui.label(RichText::new(format!("CPS {:.1}", cps)).color(col));
            ui.label(format!("Karakter: {}", lens.iter().map(|l| l.to_string()).collect::<Vec<_>>().join(" / ")));
            if ui.button("+ \\N").on_hover_text("İmleç yerine satır sonu (\\N) ekle — metin kutusunda Ctrl+Enter").clicked() { ev.text.push_str("\\N"); changed = true; started = true; }
        });
        let mut shown = ev.text.replace("\\N", "\n");
        let r = ui.add(egui::TextEdit::multiline(&mut shown).desired_rows(3).desired_width(f32::INFINITY).font(egui::TextStyle::Monospace).id_salt("textedit"));
        if self.focus_text { r.request_focus(); self.focus_text = false; }
        if r.gained_focus() { started = true; }
        if r.changed() { ev.text = shown.replace("\r", "").replace('\n', "\\N"); changed = true; }
        if started && changed { self.hist.record("Düzenle", &self.file); }
        if changed { self.file.events[a] = ev; self.touch(); }
    }

    fn start_speller(&mut self, ctx: &egui::Context) {
        if self.speller.is_some() || self.speller_rx.is_some() { return; }
        let (tx, rx) = mpsc::channel();
        self.speller_rx = Some(rx);
        let c = ctx.clone();
        std::thread::spawn(move || { let _ = tx.send(Speller::turkish()); c.request_repaint(); });
    }

    fn scan_spelling(&mut self) {
        let Some(sp) = self.speller.clone() else { return };
        self.spell_hits.clear();
        for (i, e) in self.file.events.iter().enumerate() {
            if e.comment { continue; }
            for m in sp.check_text(&e.text) {
                if self.spell_ignore.contains(&m.word) { continue; }
                let sug = sp.suggest(&m.word, 6);
                self.spell_hits.push((i, m, sug));
                if self.spell_hits.len() >= 1000 { return; }
            }
        }
    }

    fn spell_window(&mut self, ctx: &egui::Context) {
        if let Some(rx) = &self.speller_rx {
            match rx.try_recv() {
                Ok(Ok(sp)) => { self.speller = Some(Arc::new(sp)); self.speller_rx = None; self.scan_spelling(); }
                Ok(Err(e)) => { self.status = format!("Sözlük yüklenemedi: {e}"); self.speller_rx = None; self.show_spell = false; return; }
                Err(_) => {}
            }
        }
        let mut open = true;
        let mut fix: Option<(usize, String, String)> = None;
        let mut goto = None; let mut ignore: Option<String> = None; let mut rescan = false;
        egui::Window::new("Yazım denetimi").open(&mut open).default_width(520.0).show(ctx, |ui| {
            if self.speller.is_none() { ui.horizontal(|ui| { ui.spinner(); ui.label("Sözlük yükleniyor…"); }); return; }
            ui.horizontal(|ui| { if ui.button("Yeniden tara").clicked() { rescan = true; } ui.label(format!("{} hatalı sözcük", self.spell_hits.len())); });
            egui::ScrollArea::vertical().max_height(420.0).show(ui, |ui| {
                for (line, m, sug) in &self.spell_hits {
                    ui.horizontal_wrapped(|ui| {
                        if ui.link(format!("#{}", line + 1)).clicked() { goto = Some(*line); }
                        ui.label(RichText::new(&m.word).color(Color32::from_rgb(255, 120, 90)).strong());
                        for s in sug { if ui.small_button(s).clicked() { fix = Some((*line, m.word.clone(), s.clone())); } }
                        if ui.small_button("Yoksay").clicked() { ignore = Some(m.word.clone()); }
                    });
                }
            });
        });
        if let Some(g) = goto { self.select_only(g); self.scroll_to = Some(g); }
        if let Some(w) = ignore { self.spell_ignore.insert(w); rescan = true; }
        if let Some((line, word, rep)) = fix {
            self.snapshot("Yazım düzelt");
            if let Some(e) = self.file.events.get_mut(line) {
                let mut done = false;
                e.text = tags::map_plain(&e.text, |t| if !done && t.contains(&word) { done = true; t.replacen(&word, &rep, 1) } else { t.to_string() });
            }
            self.touch(); rescan = true;
        }
        if rescan { self.scan_spelling(); }
        self.show_spell = open;
    }

    fn update_preview(&mut self, ctx: &egui::Context) {
        let Some((path, info)) = self.video.clone() else { return };
        if let Some(rx) = &self.prev_rx {
            match rx.try_recv() {
                Ok(Ok((w, h, rgba))) => {
                    let img = egui::ColorImage::from_rgba_unmultiplied([w as usize, h as usize], &rgba);
                    self.prev_tex = Some(ctx.load_texture("preview", img, egui::TextureOptions::LINEAR));
                    self.prev_err.clear(); self.prev_rx = None;
                }
                Ok(Err(e)) => { self.prev_err = e; self.prev_rx = None; }
                Err(mpsc::TryRecvError::Empty) => return,
                Err(_) => { self.prev_rx = None; }
            }
        }
        if let Some(e) = self.active.and_then(|a| self.file.events.get(a)) { if self.prev_ms < e.start || self.prev_ms >= e.end { self.prev_ms = (e.start + e.end) / 2; } }
        if self.prev_last == (self.rev, self.prev_ms) { return; }
        self.prev_last = (self.rev, self.prev_ms);
        let (tx, rx) = mpsc::channel();
        self.prev_rx = Some(rx);
        let ass = self.file.to_string();
        let ms = self.prev_ms;
        let fonts = self.path.as_ref().and_then(|p| p.parent()).map(|p| p.to_path_buf());
        let c = ctx.clone();
        std::thread::spawn(move || {
            let r = osiosub_media::render_frame(&path, &ass, ms, 960, &info, fonts.as_deref());
            let _ = tx.send(r); c.request_repaint();
        });
    }

    fn waveform(&mut self, ui: &mut egui::Ui) {
        let Some(audio) = self.audio.clone() else { ui.horizontal(|ui| { ui.spinner(); ui.label("Ses çözülüyor…"); }); return; };
        let avail = ui.available_size();
        let (resp, painter) = ui.allocate_painter(egui::vec2(avail.x, avail.y.max(60.0)), egui::Sense::click_and_drag());
        let rect = resp.rect;
        let dur = audio.duration_ms() as f64;
        // follow active line
        if self.wave_follow != self.active {
            self.wave_follow = self.active;
            if let Some(e) = self.active.and_then(|a| self.file.events.get(a)) {
                let (s, en) = (self.wave_start, self.wave_start + rect.width() as f64 * self.wave_mspp);
                if (e.start as f64) < s || (e.end as f64) > en { self.wave_start = (e.start as f64 - rect.width() as f64 * self.wave_mspp * 0.25).max(0.0); }
            }
        }
        // zoom / scroll
        if resp.hovered() {
            let (scroll, zoom, ctrl) = ui.input(|i| (i.smooth_scroll_delta, i.zoom_delta(), i.modifiers.command));
            if (zoom - 1.0).abs() > 1e-4 || (ctrl && scroll.y != 0.0) {
                let f = if (zoom - 1.0).abs() > 1e-4 { zoom as f64 } else { (scroll.y as f64 * 0.01).exp() };
                let mx = resp.hover_pos().map(|p| (p.x - rect.left()) as f64).unwrap_or(0.0);
                let anchor = self.wave_start + mx * self.wave_mspp;
                self.wave_mspp = (self.wave_mspp / f).clamp(1.0, 400.0);
                self.wave_start = (anchor - mx * self.wave_mspp).max(0.0);
            } else if scroll.x != 0.0 || scroll.y != 0.0 {
                self.wave_start = (self.wave_start - (scroll.x + scroll.y) as f64 * self.wave_mspp).clamp(0.0, dur);
            }
        }
        let t2x = |t: f64, st: f64, mspp: f64| rect.left() + ((t - st) / mspp) as f32;
        let x2t = |x: f32, st: f64, mspp: f64| st + (x - rect.left()) as f64 * mspp;
        painter.rect_filled(rect, 0.0, Color32::from_rgb(18, 22, 30));
        let mid = rect.center().y; let half = rect.height() / 2.0 - 4.0;
        // subtitle regions
        let (st, mspp) = (self.wave_start, self.wave_mspp);
        let t_end = st + rect.width() as f64 * mspp;
        for (i, e) in self.file.events.iter().enumerate() {
            if (e.end as f64) < st || (e.start as f64) > t_end || e.comment { continue; }
            let r = egui::Rect::from_min_max(egui::pos2(t2x(e.start as f64, st, mspp).max(rect.left()), rect.top()), egui::pos2(t2x(e.end as f64, st, mspp).min(rect.right()), rect.bottom()));
            let col = if Some(i) == self.active { Color32::from_rgba_unmultiplied(80, 140, 255, 70) } else if self.sel.contains(&i) { Color32::from_rgba_unmultiplied(120, 180, 255, 40) } else { Color32::from_rgba_unmultiplied(255, 255, 255, 14) };
            painter.rect_filled(r, 0.0, col);
        }
        // wave
        let w = rect.width() as usize;
        for px in 0..w {
            let t0 = st + px as f64 * mspp;
            let (lo, hi) = audio.range(t0 as i64, (t0 + mspp).ceil() as i64);
            if hi == 0.0 && lo == 0.0 { continue; }
            let x = rect.left() + px as f32 + 0.5;
            painter.line_segment([egui::pos2(x, mid - hi.min(1.0) * half), egui::pos2(x, mid - lo.max(-1.0) * half)], egui::Stroke::new(1.0, Color32::from_rgb(110, 200, 150)));
        }
        // time ruler
        let step = [100.0, 250.0, 500.0, 1000.0, 2000.0, 5000.0, 10000.0, 30000.0, 60000.0].iter().cloned().find(|s| s / mspp > 80.0).unwrap_or(120000.0);
        let mut t = (st / step).floor() * step;
        while t < t_end {
            let x = t2x(t, st, mspp);
            painter.line_segment([egui::pos2(x, rect.top()), egui::pos2(x, rect.top() + 6.0)], egui::Stroke::new(1.0, Color32::GRAY));
            painter.text(egui::pos2(x + 3.0, rect.top()), egui::Align2::LEFT_TOP, time::fmt_ass(t as i64), egui::FontId::proportional(10.0), Color32::GRAY);
            t += step;
        }

        if let Some(e) = self.active.and_then(|a| self.file.events.get(a)) {
            let (xs, xe) = (t2x(e.start as f64, st, mspp), t2x(e.end as f64, st, mspp));
            handles = Some((xs, xe));
            painter.line_segment([egui::pos2(xs, rect.top()), egui::pos2(xs, rect.bottom())], egui::Stroke::new(2.0, Color32::from_rgb(255, 90, 90)));
            painter.line_segment([egui::pos2(xe, rect.top()), egui::pos2(xe, rect.bottom())], egui::Stroke::new(2.0, Color32::from_rgb(90, 160, 255)));
        }
        // interaction: drag handles; click = set start (left) ; secondary click = set end ; ctrl-click selects line
        let near = |x: f32, h: f32| (x - h).abs() < 7.0;
        if resp.drag_started() {

                if near(p.x, xs) { self.hist.record("Zamanlama", &self.file); self.drag = Some((a, true)); }
                else if near(p.x, xe) { self.hist.record("Zamanlama", &self.file); self.drag = Some((a, false)); }
            }
        }
        if let (Some((a, is_start)), Some(p)) = (self.drag, resp.interact_pointer_pos()) {
            let t = x2t(p.x, st, mspp).round().max(0.0) as i64;
            if let Some(e) = self.file.events.get_mut(a) { if is_start { e.start = t.min(e.end); } else { e.end = t.max(e.start); } }
            self.touch();
        }
        if resp.drag_stopped() { self.drag = None; }
        if resp.hovered() { if let Some(p) = resp.hover_pos() { if let Some((xs, xe)) = handles { if near(p.x, xs) || near(p.x, xe) { ui.ctx().set_cursor_icon(egui::CursorIcon::ResizeHorizontal); } } } }
        if resp.clicked() || resp.secondary_clicked() {
            if let Some(p) = resp.interact_pointer_pos() {
                let t = x2t(p.x, st, mspp).round().max(0.0) as i64;
                if resp.secondary_clicked() {
                    if let Some(a) = self.active { self.hist.record("Bitiş", &self.file); if let Some(e) = self.file.events.get_mut(a) { e.end = t.max(e.start + 1); self.touch(); } }
                } else if ui.input(|i| i.modifiers.alt) {
                    if let Some(a) = self.active { self.hist.record("Başlangıç", &self.file); if let Some(e) = self.file.events.get_mut(a) { e.start = t.min(e.end - 1).max(0); self.touch(); } }
                } else if let Some(i) = self.file.events.iter().position(|e| e.start <= t && t < e.end) { self.select_only(i); self.scroll_to = Some(i); self.wave_follow = self.active; }
            }
        }
        resp.on_hover_text("Sol tık: satır seç · Alt+tık: başlangıç · Sağ tık: bitiş · Kenarları sürükle · Ctrl+tekerlek: yakınlaştır");
    }

            }

        }
    }

//! Runs the (non-Send) Lua runtime on its own thread so macros can block on GUI dialogs.
use osiosub_core::ass::AssFile;
use osiosub_lua::{DialogResult, DialogSpec, Host, MacroInfo, MacroResult, ScriptRuntime};
use std::path::PathBuf;
use std::sync::mpsc::{channel, Receiver, Sender};
use std::sync::{Arc, Mutex};

pub type VideoMeta = Arc<Mutex<Option<(i32, i32, f64)>>>;

pub enum ToWorker {
    Load(PathBuf),
    Run { idx: usize, file: AssFile, sel: Vec<usize>, active: usize },
    Quit,
}

pub enum FromWorker {
    Loaded(Result<usize, String>, Vec<MacroInfo>),
    Dialog(DialogSpec),
    Log(String),
    Done(MacroResult),
}

struct GuiHost {
    tx: Sender<FromWorker>,
    replies: Receiver<DialogResult>,
    ctx: egui::Context,
    video: VideoMeta,
}

impl Host for GuiHost {
    fn dialog(&mut self, spec: &DialogSpec) -> DialogResult {
        let _ = self.tx.send(FromWorker::Dialog(spec.clone()));
        self.ctx.request_repaint();
        self.replies.recv().unwrap_or(DialogResult { button: None, values: Default::default() })
    }
    fn video_size(&self) -> Option<(i32, i32)> { self.video.lock().unwrap().map(|v| (v.0, v.1)) }
    fn fps(&self) -> Option<f64> { self.video.lock().unwrap().map(|v| v.2) }
    fn log(&mut self, msg: &str) {
        let _ = self.tx.send(FromWorker::Log(msg.to_string()));
        self.ctx.request_repaint();
    }
}

pub struct Worker {
    pub tx: Sender<ToWorker>,
    pub rx: Receiver<FromWorker>,
    pub reply: Sender<DialogResult>,
    pub video: VideoMeta,
}

pub fn spawn(ctx: egui::Context) -> Worker {
    let (to_tx, to_rx) = channel::<ToWorker>();
    let (from_tx, from_rx) = channel::<FromWorker>();
    let (reply_tx, reply_rx) = channel::<DialogResult>();
    let video: VideoMeta = Arc::new(Mutex::new(None));
    let video2 = video.clone();
    std::thread::spawn(move || {
        let host = GuiHost { tx: from_tx.clone(), replies: reply_rx, ctx: ctx.clone(), video: video2 };
        let mut rt = match ScriptRuntime::new(Box::new(host)) { Ok(r) => r, Err(_) => return };
        while let Ok(msg) = to_rx.recv() {
            match msg {
                ToWorker::Load(p) => {
                    let r = rt.load_file(&p);
                    let all = rt.macros();
                    let _ = from_tx.send(FromWorker::Loaded(r.map(|v| v.len()), all));
                }
                ToWorker::Run { idx, file, sel, active } => {
                    let res = rt.run(idx, &file, &sel, active);
                    let _ = from_tx.send(FromWorker::Done(res));
                }
                ToWorker::Quit => break,
            }
            ctx.request_repaint();
        }
    });
    Worker { tx: to_tx, rx: from_rx, reply: reply_tx, video }
}

//! `osiosub` command line: convert, check, shift, and run Aegisub Lua macros headlessly.
use osiosub_core::{ass::AssFile, fixes, qc, textfmt, timing};
use osiosub_lua::{DefaultHost, ScriptRuntime};
use std::{env, fs, path::Path, process::exit};

const HELP: &str = "osiosub <command>
  convert <in> <out>                 convert between .ass/.srt/.vtt/.txt
  check <file>                       run QC (CPS, line length, overlaps, typography)
  shift <in> <out> <ms>              shift all lines by ms (negative allowed)
  fix <in> <out>                     clean text, fix overlaps/durations/CPS, auto line-break, close gaps
  macros <script.lua>                list macros registered by a script
  run <script.lua> <in> <out> [macro-index|name] [sel-first-last]
                                     run an Aegisub automation macro on a file
";

fn read(path: &str) -> AssFile {
    let bytes = fs::read(path).unwrap_or_else(|e| { eprintln!("{path}: {e}"); exit(1) });
    let text = String::from_utf8_lossy(&bytes).into_owned();
    textfmt::open_any(path, &text).unwrap_or_else(|e| { eprintln!("{path}: {e}"); exit(1) })
}

fn write(path: &str, f: &AssFile) {
    let l = path.to_ascii_lowercase();
    let s = if l.ends_with(".srt") { textfmt::to_srt(f) } else if l.ends_with(".vtt") { textfmt::to_vtt(f) } else if l.ends_with(".txt") { textfmt::to_txt(f) } else { f.to_string() };
    fs::write(path, s).unwrap_or_else(|e| { eprintln!("{path}: {e}"); exit(1) });
}

fn main() {
    let a: Vec<String> = env::args().skip(1).collect();
    match a.first().map(|s| s.as_str()) {
        Some("convert") if a.len() == 3 => write(&a[2], &read(&a[1])),
        Some("check") if a.len() == 2 => {
            let f = read(&a[1]);
            let issues = qc::check(&f, &qc::QcConfig::default());
            for i in &issues { println!("{:>5}  {:?}  [{}] {}", i.line + 1, i.severity, i.code, i.message); }
            println!("{} issue(s) in {} line(s)", issues.len(), f.events.len());
            if issues.iter().any(|i| i.severity == qc::Severity::Error) { exit(2); }
        }
        Some("shift") if a.len() == 4 => {
            let mut f = read(&a[1]);
            let d: i64 = a[3].parse().unwrap_or_else(|_| { eprintln!("bad ms"); exit(1) });
            let all: Vec<usize> = (0..f.events.len()).collect();
            timing::shift(&mut f, &all, d, true, true);
            write(&a[2], &f);
        }
        Some("fix") if a.len() == 3 => {
            let mut f = read(&a[1]);
            let c = qc::QcConfig::default();
            eprintln!("cleaned {} line(s)", fixes::clean_text(&mut f));
            timing::sort_by_start(&mut f);
            eprintln!("overlaps fixed: {}", fixes::fix_overlaps(&mut f));
            eprintln!("min-duration: {}", fixes::enforce_min_duration(&mut f, c.min_dur_ms, 84));
            eprintln!("cps-extended: {}", fixes::extend_for_cps(&mut f, c.max_cps, 84, c.max_dur_ms));
            eprintln!("auto-broken: {}", fixes::auto_break_all(&mut f, c.max_line_len, true));
            eprintln!("closed {} gap(s)", timing::close_gaps(&mut f, 100));
            write(&a[2], &f);
        }
        Some("macros") if a.len() == 2 => {
            let mut rt = ScriptRuntime::new(Box::new(DefaultHost)).unwrap();
            match rt.load_file(Path::new(&a[1])) {
                Ok(m) => for (i, m) in m.iter().enumerate() { println!("{i}: {} — {}", m.name, m.description); },
                Err(e) => { eprintln!("{e}"); exit(1) }
            }
        }
        Some("run") if a.len() >= 4 => {
            let mut rt = ScriptRuntime::new(Box::new(DefaultHost)).unwrap();
            let ms = rt.load_file(Path::new(&a[1])).unwrap_or_else(|e| { eprintln!("{e}"); exit(1) });
            let which = a.get(4).map(|s| s.as_str()).unwrap_or("0");
            let idx = which.parse::<usize>().ok().or_else(|| ms.iter().position(|m| m.name == which)).unwrap_or_else(|| { eprintln!("macro not found"); exit(1) });
            let f = read(&a[2]);
            let sel: Vec<usize> = match a.get(5).and_then(|s| s.split_once('-')) {
                Some((x, y)) => (x.parse::<usize>().unwrap_or(1) - 1..y.parse::<usize>().unwrap_or(f.events.len())).collect(),
                None => (0..f.events.len()).collect(),
            };
            let r = rt.run(idx, &f, &sel, sel.first().copied().unwrap_or(0));
            if !r.log.is_empty() { eprintln!("{}", r.log); }
            if let Some(e) = r.error { eprintln!("error: {e}"); exit(1) }
            if r.cancelled { eprintln!("cancelled"); exit(3) }
            write(&a[3], &r.file.unwrap());
        }
        _ => { print!("{HELP}"); exit(if a.is_empty() { 0 } else { 1 }); }
    }
}

    pub layer: i32,
    pub start: i64,
    pub end: i64,
    pub style: String,
    pub actor: String,
    pub margin_l: i32,
    pub margin_r: i32,
    pub margin_v: i32,
    pub effect: String,
    pub text: String,
}

impl Default for Event {
    fn default() -> Self {
        Event {
            comment: false, layer: 0, start: 0, end: 5000, style: "Default".into(),
            actor: String::new(), margin_l: 0, margin_r: 0, margin_v: 0,
            effect: String::new(), text: String::new(),
        }
    }
}

/// A section we do not interpret (e.g. `[Fonts]`, `[Graphics]`, `[Aegisub Extradata]`).
#[derive(Clone, Debug, PartialEq)]
pub struct RawSection {
    pub name: String,
    pub lines: Vec<String>,
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct AssFile {
    /// `[Script Info]` key/value pairs in file order (comments kept as key `;`).
    pub info: Vec<(String, String)>,
    /// `[Aegisub Project Garbage]` key/value pairs.
    pub garbage: Vec<(String, String)>,
    pub styles: Vec<Style>,
    pub events: Vec<Event>,
    pub extra: Vec<RawSection>,
}

#[derive(Debug)]
pub struct ParseError(pub String);
impl std::fmt::Display for ParseError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { write!(f, "{}", self.0) }
}
impl std::error::Error for ParseError {}

fn pf(s: &str) -> f64 { s.trim().parse().unwrap_or(0.0) }
fn pi(s: &str) -> i32 { s.trim().parse::<f64>().map(|v| v as i32).unwrap_or(0) }
fn pb(s: &str) -> bool { pi(s) != 0 }

fn fnum(v: f64) -> String {
    if v.fract() == 0.0 { format!("{}", v as i64) } else {
        let s = format!("{:.4}", v);
        s.trim_end_matches('0').trim_end_matches('.').to_string()
    }
}

impl AssFile {
    /// New file with Aegisub-like defaults.
    pub fn new_default() -> Self {
        let mut f = AssFile::default();
        f.info = vec![
            ("Title".into(), "Default OsioSub file".into()),
            ("ScriptType".into(), "v4.00+".into()),
            ("WrapStyle".into(), "0".into()),
            ("ScaledBorderAndShadow".into(), "yes".into()),
            ("YCbCr Matrix".into(), "None".into()),
            ("PlayResX".into(), "1920".into()),
            ("PlayResY".into(), "1080".into()),
        ];
        f.styles.push(Style::default());
        f
    }

    pub fn info_get(&self, key: &str) -> Option<&str> {
        self.info.iter().find(|(k, _)| k.eq_ignore_ascii_case(key)).map(|(_, v)| v.as_str())
    }
    pub fn info_set(&mut self, key: &str, val: &str) {
        if let Some(e) = self.info.iter_mut().find(|(k, _)| k.eq_ignore_ascii_case(key)) {
            e.1 = val.to_string();
        } else {
            self.info.push((key.to_string(), val.to_string()));
        }
    }
    pub fn play_res(&self) -> (i32, i32) {
        let x = self.info_get("PlayResX").and_then(|v| v.trim().parse().ok());
        let y = self.info_get("PlayResY").and_then(|v| v.trim().parse().ok());
        match (x, y) {
            (Some(x), Some(y)) => (x, y),
            (Some(x), None) => (x, x * 3 / 4),
            (None, Some(y)) => (y * 4 / 3, y),
            _ => (384, 288),
        }
    }
    pub fn style(&self, name: &str) -> Option<&Style> {
        self.styles.iter().find(|s| s.name == name)
    }

    pub fn parse(input: &str) -> Result<AssFile, ParseError> {
        let input = input.trim_start_matches('\u{feff}');
        let mut f = AssFile::default();
        #[derive(PartialEq)]
        enum Sec { None, Info, Styles, Events, Garbage, Other }
        let mut sec = Sec::None;
        let mut style_fmt: Vec<String> = default_style_format();
        let mut event_fmt: Vec<String> = default_event_format();
        let mut v4 = false;
        let mut saw_any = false;
        for raw in input.lines() {
            let line = raw.trim_end_matches('\r');
            let t = line.trim();
            if t.starts_with('[') && t.ends_with(']') {
                let name = &t[1..t.len() - 1];
                saw_any = true;
                let l = name.to_ascii_lowercase();
                sec = match l.as_str() {
                    "script info" => Sec::Info,
                    "v4+ styles" => { v4 = false; Sec::Styles }
                    "v4 styles" => { v4 = true; Sec::Styles }
                    "events" => Sec::Events,
                    "aegisub project garbage" => Sec::Garbage,
                    _ => {
                        f.extra.push(RawSection { name: name.to_string(), lines: vec![] });
                        Sec::Other
                    }
                };
                continue;
            }
            if t.is_empty() { continue; }
            match sec {
                Sec::None => {}
                Sec::Info | Sec::Garbage => {
                    let target = if sec == Sec::Info { &mut f.info } else { &mut f.garbage };
                    if t.starts_with(';') {
                        target.push((";".into(), t[1..].trim_start().to_string()));
                    } else if let Some(i) = t.find(':') {
                        target.push((t[..i].trim().to_string(), t[i + 1..].trim().to_string()));
                    }
                }
                Sec::Styles => {
                    if let Some(rest) = strip_ci(t, "format:") {
                        style_fmt = rest.split(',').map(|s| s.trim().to_ascii_lowercase()).collect();
                    } else if let Some(rest) = strip_ci(t, "style:") {
                        f.styles.push(parse_style(rest, &style_fmt, v4));
                    }
                }
                Sec::Events => {
                    if let Some(rest) = strip_ci(t, "format:") {
                        event_fmt = rest.split(',').map(|s| s.trim().to_ascii_lowercase()).collect();
                    } else if let Some(rest) = strip_ci(t, "dialogue:") {
                        f.events.push(parse_event(rest, &event_fmt, false));
                    } else if let Some(rest) = strip_ci(t, "comment:") {
                        f.events.push(parse_event(rest, &event_fmt, true));
                    }
                    // picture/sound/movie/command lines are dropped (Aegisub drops them too)
                }
                Sec::Other => {
                    if let Some(s) = f.extra.last_mut() { s.lines.push(line.to_string()); }
                }
            }
        }
        if !saw_any {
            return Err(ParseError("not an ASS/SSA file (no sections)".into()));
        }
        if f.styles.is_empty() { f.styles.push(Style::default()); }
        Ok(f)
    }

    pub fn to_string(&self) -> String {
        let mut o = String::with_capacity(self.events.len() * 80 + 2048);
        o.push_str("[Script Info]\n");
        for (k, v) in &self.info {
            if k == ";" { o.push_str(&format!("; {}\n", v)); } else { o.push_str(&format!("{}: {}\n", k, v)); }
        }
        if !self.garbage.is_empty() {
            o.push_str("\n[Aegisub Project Garbage]\n");
            for (k, v) in &self.garbage { o.push_str(&format!("{}: {}\n", k, v)); }
        }
        o.push_str("\n[V4+ Styles]\nFormat: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding\n");
        for s in &self.styles { o.push_str(&format!("Style: {}\n", style_line(s))); }
        o.push_str("\n[Events]\nFormat: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text\n");
        for e in &self.events { o.push_str(&event_line(e)); o.push('\n'); }
        for s in &self.extra {
            o.push_str(&format!("\n[{}]\n", s.name));
            for l in &s.lines { o.push_str(l); o.push('\n'); }
        }
        o
    }
}

pub fn style_line(s: &Style) -> String {
    let b = |v: bool| if v { "-1" } else { "0" };
    format!(
        "{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{},{}",
        s.name, s.fontname, fnum(s.fontsize), s.primary.to_style(), s.secondary.to_style(),
        s.outline_color.to_style(), s.back.to_style(), b(s.bold), b(s.italic), b(s.underline),
        b(s.strikeout), fnum(s.scale_x), fnum(s.scale_y), fnum(s.spacing), fnum(s.angle),
        s.border_style, fnum(s.outline), fnum(s.shadow), s.alignment, s.margin_l, s.margin_r,
        s.margin_v, s.encoding
    )
}

pub fn event_line(e: &Event) -> String {
    format!(
        "{}: {},{},{},{},{},{:04},{:04},{:04},{},{}",
        if e.comment { "Comment" } else { "Dialogue" },
        e.layer, time::fmt_ass(e.start), time::fmt_ass(e.end), e.style, e.actor,
        e.margin_l, e.margin_r, e.margin_v, e.effect, e.text
    )
}

fn strip_ci<'a>(s: &'a str, prefix: &str) -> Option<&'a str> {
    if s.len() >= prefix.len() && s.is_char_boundary(prefix.len()) && s[..prefix.len()].eq_ignore_ascii_case(prefix) {
        Some(s[prefix.len()..].trim_start())
    } else { None }
}

fn default_style_format() -> Vec<String> {
    "name,fontname,fontsize,primarycolour,secondarycolour,outlinecolour,backcolour,bold,italic,underline,strikeout,scalex,scaley,spacing,angle,borderstyle,outline,shadow,alignment,marginl,marginr,marginv,encoding"
        .split(',').map(String::from).collect()
}
fn default_event_format() -> Vec<String> {
    "layer,start,end,style,name,marginl,marginr,marginv,effect,text".split(',').map(String::from).collect()
}

fn parse_style(rest: &str, fmt: &[String], v4: bool) -> Style {
    let mut s = Style::default();
    let n = fmt.len().max(1);
    let parts: Vec<&str> = rest.splitn(n, ',').collect();
    for (i, key) in fmt.iter().enumerate() {
        let Some(v) = parts.get(i).map(|v| v.trim()) else { continue };
        match key.as_str() {
            "name" => s.name = v.to_string(),
            "fontname" => s.fontname = v.to_string(),
            "fontsize" => s.fontsize = pf(v),
            "primarycolour" | "primarycolor" => s.primary = Color::parse(v).unwrap_or(s.primary),
            "secondarycolour" | "secondarycolor" => s.secondary = Color::parse(v).unwrap_or(s.secondary),
            "tertiarycolour" | "outlinecolour" | "outlinecolor" => s.outline_color = Color::parse(v).unwrap_or(s.outline_color),
            "backcolour" | "backcolor" => s.back = Color::parse(v).unwrap_or(s.back),
            "bold" => s.bold = pb(v),
            "italic" => s.italic = pb(v),
            "underline" => s.underline = pb(v),
            "strikeout" => s.strikeout = pb(v),
            "scalex" => s.scale_x = pf(v),
            "scaley" => s.scale_y = pf(v),
            "spacing" => s.spacing = pf(v),
            "angle" => s.angle = pf(v),
            "borderstyle" => s.border_style = pi(v),
            "outline" => s.outline = pf(v),
            "shadow" => s.shadow = pf(v),
            "alignment" => {
                let a = pi(v);
                s.alignment = if v4 { match a { 1..=3 => a, 5..=7 => a - 5 + 7, 9..=11 => a - 9 + 4, _ => 2 } } else { a };
            }
            "marginl" => s.margin_l = pi(v),
            "marginr" => s.margin_r = pi(v),
            "marginv" => s.margin_v = pi(v),
            "encoding" => s.encoding = pi(v),
            _ => {}
        }
    }
    s
}

fn parse_event(rest: &str, fmt: &[String], comment: bool) -> Event {
    let mut e = Event { comment, ..Default::default() };
    // Text is always last: split into fmt.len() fields, the last receives the remainder (commas intact).
    let n = fmt.len().max(1);
    let parts: Vec<&str> = rest.splitn(n, ',').collect();
    for (i, key) in fmt.iter().enumerate() {
        let Some(v) = parts.get(i) else { continue };
        match key.as_str() {
            "layer" | "marked" => e.layer = pi(&v.replace("Marked=", "")),
            "start" => e.start = time::parse_ass(v).unwrap_or(0),
            "end" => e.end = time::parse_ass(v).unwrap_or(0),
            "style" => e.style = v.trim().trim_start_matches('*').to_string(),
            "name" | "actor" => e.actor = v.trim().to_string(),
            "marginl" => e.margin_l = pi(v),
            "marginr" => e.margin_r = pi(v),
            "marginv" => e.margin_v = pi(v),
            "marginb" | "margint" => {}
            "effect" => e.effect = v.trim().to_string(),
            "text" => e.text = v.to_string(),
            _ => {}
        }
    }
    e
}

//! ASS colors: stored as 0xAABBGGRR (ASS alpha: 0 = opaque).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Color(pub u32);

impl Color {
    pub fn rgba(r: u8, g: u8, b: u8, a: u8) -> Self {
        Color(((a as u32) << 24) | ((b as u32) << 16) | ((g as u32) << 8) | r as u32)
    }
    pub fn r(&self) -> u8 { self.0 as u8 }
    pub fn g(&self) -> u8 { (self.0 >> 8) as u8 }
    pub fn b(&self) -> u8 { (self.0 >> 16) as u8 }
    pub fn a(&self) -> u8 { (self.0 >> 24) as u8 }

    /// Parse `&HAABBGGRR&`, `&HBBGGRR&`, `&H...`, or decimal (SSA).
    pub fn parse(s: &str) -> Option<Color> {
        let t = s.trim().trim_end_matches('&');
        let t = t.trim_start_matches('&');
        if let Some(h) = t.strip_prefix(['H', 'h']) {
            let v = u32::from_str_radix(h.trim_start_matches(['H', 'h']), 16).ok()?;
            Some(Color(v))
        } else if let Some(h) = t.strip_prefix('$') {
            Some(Color(u32::from_str_radix(h, 16).ok()?))
        } else {
            t.parse::<i64>().ok().map(|v| Color(v as u32))
        }
    }

    /// Style-line form: `&HAABBGGRR`.
    pub fn to_style(&self) -> String {
        format!("&H{:08X}", self.0)
    }
    /// Override-tag form: `&HBBGGRR&`.
    pub fn to_tag(&self) -> String {
        format!("&H{:02X}{:02X}{:02X}&", self.b(), self.g(), self.r())
    }
    pub fn alpha_tag(&self) -> String {
        format!("&H{:02X}&", self.a())
    }
}

//! Batch fixes inspired by Subtitle Edit's "fix common errors" and Aegisub's timing helpers.
use crate::ass::AssFile;
use crate::tags;

/// Byte positions of ASCII spaces that are outside `{...}` override blocks.
fn plain_spaces(text: &str) -> Vec<usize> {
    let mut out = Vec::new();
    let mut depth = false;
    for (i, c) in text.char_indices() {
        match c { '{' => depth = true, '}' => depth = false, ' ' if !depth => out.push(i), _ => {} }
    }
    out
}

/// Insert `\N` at the space that best balances the two lines. No-op if the text already has a break
/// or fits within `max_len`. `bottom_heavy` prefers a longer second line (looks better under video).
pub fn auto_break(text: &str, max_len: usize, bottom_heavy: bool) -> String {
    if text.contains("\\N") || text.contains("\\n") { return text.to_string(); }
    let total = tags::visible_len(text);
    if total <= max_len { return text.to_string(); }
    let spaces = plain_spaces(text);
    if spaces.is_empty() { return text.to_string(); }
    let target = if bottom_heavy { (total as f64 * 0.45).round() as usize } else { total / 2 };
    let mut best: Option<(usize, usize)> = None; // (score, pos)
    for &p in &spaces {
        let left = tags::visible_len(&text[..p]);
        let score = left.abs_diff(target);
        if best.map_or(true, |(s, _)| score < s) { best = Some((score, p)); }
    }
    let p = best.unwrap().1;
    format!("{}\\N{}", text[..p].trim_end(), text[p + 1..].trim_start())
}

/// Replace `\N` with a space.
pub fn unbreak(text: &str) -> String {
    text.replace(" \\N", " ").replace("\\N ", " ").replace("\\N", " ")
}

pub fn auto_break_all(f: &mut AssFile, max_len: usize, bottom_heavy: bool) -> usize {
    let mut n = 0;
    for e in f.events.iter_mut().filter(|e| !e.comment) {
        let t = auto_break(&e.text, max_len, bottom_heavy);
        if t != e.text { e.text = t; n += 1; }
    }
    n
}

/// Remove hearing-impaired annotations: `[ ... ]`, `( ... )`, and leading speaker labels like `AYŞE:`.
pub fn remove_hi(f: &mut AssFile) -> usize {
    let re_br = regex::Regex::new(r"\s*(\[[^\]]*\]|\([^)]*\))\s*").unwrap();
    let re_label = regex::Regex::new(r"^(\\N)?\s*[A-ZÇĞİÖŞÜ][A-ZÇĞİÖŞÜ0-9 .'-]{1,24}:\s*").unwrap();
    let mut changed = 0;
    for e in &mut f.events {
        if e.comment { continue; }
        let before = e.text.clone();
        let t = tags::map_plain(&e.text, |s| re_label.replace_all(&re_br.replace_all(s, " "), "$1").trim().to_string());
        e.text = t.replace("\\N\\N", "\\N").trim_matches(|c: char| c == ' ').trim_start_matches("\\N").trim_end_matches("\\N").to_string();
        if e.text != before { changed += 1; }
    }
    f.events.retain(|e| e.comment || !tags::visible_text(&e.text).trim().is_empty() || before_non_text(e));
    changed
}
fn before_non_text(e: &crate::ass::Event) -> bool { !e.effect.is_empty() } // keep effect-bearing empties (typesetting)

/// Trim earlier lines so same-style neighbours never overlap. Returns number of lines changed.
pub fn fix_overlaps(f: &mut AssFile) -> usize {
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment && f.events[i].effect.is_empty()).collect();
    order.sort_by_key(|&i| (f.events[i].start, f.events[i].end));
    let mut n = 0;
    for w in order.windows(2) {
        let (a, b) = (w[0], w[1]);
        if f.events[b].start < f.events[a].end && f.events[a].style == f.events[b].style && f.events[a].layer == f.events[b].layer {
            f.events[a].end = f.events[b].start.max(f.events[a].start + 1); n += 1;
        }
    }
    n
}

/// Extend line ends (never past the next line's start minus `min_gap_ms`, never beyond `max_dur_ms`)
/// until reading speed is at most `max_cps`. Returns number of lines extended.
pub fn extend_for_cps(f: &mut AssFile, max_cps: f64, min_gap_ms: i64, max_dur_ms: i64) -> usize {
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment).collect();
    order.sort_by_key(|&i| f.events[i].start);
    let mut n = 0;
    for (k, &i) in order.iter().enumerate() {
        let len = tags::visible_len(&f.events[i].text) as f64;
        let need = (len * 1000.0 / max_cps).ceil() as i64;
        let dur = f.events[i].end - f.events[i].start;
        if dur >= need { continue; }
        let limit = order.get(k + 1).map(|&j| f.events[j].start - min_gap_ms).unwrap_or(i64::MAX);
        let new_end = (f.events[i].start + need).min(limit).min(f.events[i].start + max_dur_ms);
        if new_end > f.events[i].end { f.events[i].end = new_end; n += 1; }
    }
    n
}

/// Guarantee a minimum duration where room is available.
pub fn enforce_min_duration(f: &mut AssFile, min_ms: i64, min_gap_ms: i64) -> usize {
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment).collect();
    order.sort_by_key(|&i| f.events[i].start);
    let mut n = 0;
    for (k, &i) in order.iter().enumerate() {
        let dur = f.events[i].end - f.events[i].start;
        if dur >= min_ms { continue; }
        let limit = order.get(k + 1).map(|&j| f.events[j].start - min_gap_ms).unwrap_or(i64::MAX);
        let new_end = (f.events[i].start + min_ms).min(limit);
        if new_end > f.events[i].end { f.events[i].end = new_end; n += 1; }
    }
    n
}

/// Collapse spaces, fix punctuation spacing, `...` -> `…`, trim each line. Tags untouched.
pub fn clean_text(f: &mut AssFile) -> usize {
    let mut n = 0;
    for e in f.events.iter_mut().filter(|e| !e.comment) {
        let t = tags::map_plain(&e.text, |s| {
            let mut s = s.replace("...", "…");
            while s.contains("  ") { s = s.replace("  ", " "); }
            for p in [" ,", " .", " !", " ?", " ;", " :", " …"] { s = s.replace(p, &p[1..]); }
            s.replace(" \\N", "\\N").replace("\\N ", "\\N")
        });
        let t = t.trim().to_string();
        if t != e.text { e.text = t; n += 1; }
    }
    n
}

/// Dialogue dash normalisation: lines beginning with "-" get "- " (hyphen + space).
pub fn normalize_dashes(f: &mut AssFile) -> usize {
    let re = regex::Regex::new(r"(^|\\N)[-–—]\s*").unwrap();
    let mut n = 0;
    for e in f.events.iter_mut().filter(|e| !e.comment) {
        let t = re.replace_all(&e.text, "$1- ").into_owned();
        if t != e.text { e.text = t; n += 1; }
    }
    n
}

//! Karaoke helpers: automatic `\k` generation and removal.
use crate::ass::AssFile;
use regex::Regex;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Split { Word, Char, Romaji }

/// Split plain text into syllables according to `mode`. Spaces stay attached to the previous syllable.
pub fn split_syllables(text: &str, mode: Split) -> Vec<String> {
    let chars: Vec<char> = text.chars().collect();
    let mut out: Vec<String> = Vec::new();
    match mode {
        Split::Char => {
            for c in chars { if c == ' ' { if let Some(l) = out.last_mut() { l.push(c); continue; } } out.push(c.to_string()); }
        }
        Split::Word => {
            let mut cur = String::new();
            for c in chars {
                if c == ' ' { cur.push(c); } else if cur.ends_with(' ') { out.push(std::mem::take(&mut cur)); cur.push(c); } else { cur.push(c); }
            }
            if !cur.is_empty() { out.push(cur); }
        }
        Split::Romaji => {
            let is_v = |c: char| "aeiouAEIOUāīūēōâîûêô".contains(c);
            let mut cur = String::new();
            let mut i = 0;
            while i < chars.len() {
                let c = chars[i];
                if c == ' ' { if cur.is_empty() { if let Some(l) = out.last_mut() { l.push(' '); } } else { cur.push(' '); out.push(std::mem::take(&mut cur)); } i += 1; continue; }
                cur.push(c);
                let next = chars.get(i + 1).copied();
                // syllable ends after a vowel, or on lone 'n' not followed by a vowel/y, or after doubled consonant start
                let ends = if is_v(c) { true } else if (c == 'n' || c == 'N') && next.map_or(true, |n| !is_v(n) && n != 'y' && n != 'Y') { true } else { false };
                let ended = ends;
                if ended && !cur.is_empty() { out.push(std::mem::take(&mut cur)); }
                i += 1;
            }
            if !cur.is_empty() { out.push(cur); }
        }
    }
    out
}

/// Distribute `total_cs` centiseconds across syllables proportionally to their length (min 1).
pub fn auto_k(text: &str, total_cs: i64, mode: Split) -> String {
    let plain = crate::tags::strip_tags(text);
    let syl = split_syllables(&plain, mode);
    if syl.is_empty() { return text.to_string(); }
    let weights: Vec<f64> = syl.iter().map(|s| s.trim().chars().count().max(1) as f64).collect();
    let sum: f64 = weights.iter().sum();
    let mut left = total_cs;
    let mut out = String::new();
    for (i, s) in syl.iter().enumerate() {
        let d = if i + 1 == syl.len() { left.max(1) } else { ((total_cs as f64 * weights[i] / sum).round() as i64).max(1) };
        left -= d;
        out.push_str(&format!("{{\\k{}}}{}", d, s));
    }
    out
}

pub fn strip_k(text: &str) -> String {
    let re = Regex::new(r"\\[kK][fo]?\d+").unwrap();
    let out = re.replace_all(text, "").into_owned();
    out.replace("{}", "")
}

pub fn auto_k_all(f: &mut AssFile, idx: &[usize], mode: Split) -> usize {
    let mut n = 0;
    for &i in idx {
        if let Some(e) = f.events.get_mut(i) {
            let dur_cs = (e.end - e.start) / 10;
            e.text = auto_k(&e.text, dur_cs, mode); n += 1;
        }
    }
    n
}

//! Quality-control checks (timing, readability, typography, styles).
use crate::ass::AssFile;
use crate::tags;

#[derive(Clone, Debug)]
pub struct QcConfig {
    pub max_cps: f64,
    pub max_line_len: usize,
    pub max_lines: usize,
    pub min_dur_ms: i64,
    pub max_dur_ms: i64,
    pub min_gap_ms: i64,
}
impl Default for QcConfig {
    fn default() -> Self {
        Self { max_cps: 17.0, max_line_len: 42, max_lines: 2, min_dur_ms: 833, max_dur_ms: 7000, min_gap_ms: 0 }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Severity { Info, Warning, Error }

#[derive(Clone, Debug)]
pub struct Issue {
    pub line: usize, // 0-based event index
    pub severity: Severity,
    pub code: &'static str,
    pub message: String,
}

pub fn cps(text: &str, dur_ms: i64) -> f64 {
    if dur_ms <= 0 { return f64::INFINITY; }
    tags::visible_len(text) as f64 * 1000.0 / dur_ms as f64
}

pub fn check(f: &AssFile, c: &QcConfig) -> Vec<Issue> {
    let mut out = Vec::new();
    let mut push = |line, severity, code, message: String| out.push(Issue { line, severity, code, message });
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment).collect();
    order.sort_by_key(|&i| (f.events[i].start, f.events[i].end));
    for (k, &i) in order.iter().enumerate() {
        let e = &f.events[i];
        let dur = e.end - e.start;
        let vis = tags::visible_text(&e.text);
        if e.end <= e.start { push(i, Severity::Error, "neg-dur", "bitiş başlangıçtan önce / süre sıfır".into()); }
        if vis.trim().is_empty() { push(i, Severity::Warning, "empty", "boş satır".into()); continue; }
        if dur > 0 && dur < c.min_dur_ms { push(i, Severity::Warning, "short", format!("süre çok kısa ({} ms)", dur)); }
        if dur > c.max_dur_ms { push(i, Severity::Warning, "long", format!("süre çok uzun ({} ms)", dur)); }
        let r = cps(&e.text, dur);
        if r > c.max_cps { push(i, Severity::Warning, "cps", format!("okuma hızı {:.1} CPS (> {})", r, c.max_cps)); }
        let lens = tags::line_lengths(&e.text);
        if lens.len() > c.max_lines { push(i, Severity::Warning, "lines", format!("{} satır (> {})", lens.len(), c.max_lines)); }
        if let Some(m) = lens.iter().max() { if *m > c.max_line_len { push(i, Severity::Warning, "len", format!("satır {} karakter (> {})", m, c.max_line_len)); } }
        if vis.contains("  ") { push(i, Severity::Info, "dblspace", "çift boşluk".into()); }
        if vis.lines().any(|l| l != l.trim()) { push(i, Severity::Info, "trim", "satır başı/sonunda boşluk".into()); }
        if [" ,", " .", " !", " ?", " ;", " :"].iter().any(|p| vis.contains(p)) { push(i, Severity::Info, "space-punct", "noktalama öncesi boşluk".into()); }
        if vis.contains("...") { push(i, Severity::Info, "ellipsis", "'...' yerine '…' kullanılabilir".into()); }
        if f.style(&e.style).is_none() { push(i, Severity::Error, "style", format!("tanımsız stil: {}", e.style)); }
        if let Some(&j) = order.get(k + 1) {
            let n = &f.events[j];
            if n.start < e.end && n.layer == e.layer && n.style == e.style && e.effect.is_empty() && n.effect.is_empty() {
                push(i, Severity::Warning, "overlap", format!("sonraki satırla çakışıyor ({} ms)", e.end - n.start));
            } else if n.start >= e.end && n.start - e.end < c.min_gap_ms {
                push(i, Severity::Info, "gap", format!("satırlar arası boşluk {} ms", n.start - e.end));
            }
        }
    }
    out.sort_by_key(|i| i.line);
    out
}

//! Find & replace over events.
use crate::ass::AssFile;
use regex::RegexBuilder;

#[derive(Clone, Debug)]
pub struct SearchOpts {
    pub pattern: String,
    pub regex: bool,
    pub case_sensitive: bool,
    pub whole_word: bool,
    pub skip_tags: bool,
    pub field: Field,
}
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Field { Text, Actor, Style, Effect }

fn build(o: &SearchOpts) -> Result<regex::Regex, regex::Error> {
    let mut p = if o.regex { o.pattern.clone() } else { regex::escape(&o.pattern) };
    if o.whole_word { p = format!(r"\b(?:{})\b", p); }
    RegexBuilder::new(&p).case_insensitive(!o.case_sensitive).build()
}

pub fn find_all(f: &AssFile, o: &SearchOpts) -> Result<Vec<usize>, regex::Error> {
    let re = build(o)?;
    Ok(f.events.iter().enumerate().filter(|(_, e)| {
        let s = match o.field { Field::Text => &e.text, Field::Actor => &e.actor, Field::Style => &e.style, Field::Effect => &e.effect };
        if o.field == Field::Text && o.skip_tags { re.is_match(&crate::tags::strip_tags(s)) } else { re.is_match(s) }
    }).map(|(i, _)| i).collect())
}

/// Returns number of events changed.
pub fn replace_all(f: &mut AssFile, o: &SearchOpts, with: &str) -> Result<usize, regex::Error> {
    let re = build(o)?;
    let rep = if o.regex { with.to_string() } else { with.replace('$', "$$") };
    let mut n = 0;
    for e in &mut f.events {
        let field = match o.field { Field::Text => &mut e.text, Field::Actor => &mut e.actor, Field::Style => &mut e.style, Field::Effect => &mut e.effect };
        let new = if o.field == Field::Text && o.skip_tags {
            crate::tags::map_plain(field, |s| re.replace_all(s, rep.as_str()).into_owned())
        } else { re.replace_all(field, rep.as_str()).into_owned() };
        if new != *field { *field = new; n += 1; }
    }
    Ok(n)
}

//! Spell checking (Hunspell dictionaries via the pure-Rust `spellbook`). Turkish is bundled.
use flate2::read::GzDecoder;
use std::collections::HashSet;
use std::io::Read;

pub struct Speller {
    dict: spellbook::Dictionary,
    pub ignore: HashSet<String>,
}

static TR_AFF: &[u8] = include_bytes!("../../dicts/tr.aff.gz");
static TR_DIC: &[u8] = include_bytes!("../../dicts/tr.dic.gz");

fn gunzip(b: &[u8]) -> String {
    let mut s = String::new();
    GzDecoder::new(b).read_to_string(&mut s).unwrap_or_default();
    s
}

#[derive(Clone, Debug, PartialEq)]
pub struct Misspelling { pub start: usize, pub end: usize, pub word: String }

impl Speller {
    pub fn from_strings(aff: &str, dic: &str) -> Result<Self, String> {
        let dict = spellbook::Dictionary::new(aff, dic).map_err(|e| e.to_string())?;
        Ok(Self { dict, ignore: HashSet::new() })
    }
    pub fn turkish() -> Result<Self, String> { Self::from_strings(&gunzip(TR_AFF), &gunzip(TR_DIC)) }

    pub fn check_word(&self, w: &str) -> bool {
        self.ignore.contains(w) || self.ignore.contains(&w.to_lowercase()) || self.dict.check(w) || self.dict.check(&crate::turkish::to_lower(w))
    }

    pub fn suggest(&self, w: &str, max: usize) -> Vec<String> {
        let mut v = Vec::new();
        self.dict.suggest(w, &mut v);
        v.truncate(max);
        v
    }

    /// Misspelled words in the *visible* text of an event (tags removed). Offsets are byte offsets in the stripped text.
    pub fn check_text(&self, text: &str) -> Vec<Misspelling> {
        let vis = crate::tags::visible_text(text);
        let mut out = Vec::new();
        let mut start: Option<usize> = None;
        let flush = |s: usize, e: usize, out: &mut Vec<Misspelling>, this: &Speller, vis: &str| {
            let w = &vis[s..e];
            if w.chars().count() < 2 || w.chars().any(|c| c.is_ascii_digit() || c == '\'' || c == '’') { return; }
            if w.chars().filter(|c| c.is_alphabetic()).all(|c| c.is_uppercase()) { return; } // acronyms / shouting
            if !this.check_word(w) { out.push(Misspelling { start: s, end: e, word: w.to_string() }); }
        };
        let mut iter = vis.char_indices().peekable();
        while let Some((i, c)) = iter.next() {
            let in_word = c.is_alphanumeric() || ((c == '\'' || c == '’' || c == '-') && start.is_some() && iter.peek().map_or(false, |(_, n)| n.is_alphanumeric()));
            if in_word { if start.is_none() { start = Some(i); } }
            else if let Some(s) = start.take() { flush(s, i, &mut out, self, &vis); }
        }
        if let Some(s) = start { flush(s, vis.len(), &mut out, self, &vis); }
        out
    }
}

//! Override-tag helpers.
use regex::Regex;
use std::sync::OnceLock;

fn block_re() -> &'static Regex {
    static R: OnceLock<Regex> = OnceLock::new();
    R.get_or_init(|| Regex::new(r"\{[^}]*\}").unwrap())
}

/// Remove all `{...}` override blocks.
pub fn strip_tags(text: &str) -> String {
    block_re().replace_all(text, "").into_owned()
}

/// Text as the viewer reads it: no tags, `\N`/`\n` -> newline, `\h` -> space.
pub fn visible_text(text: &str) -> String {
    strip_tags(text).replace("\\N", "\n").replace("\\n", "\n").replace("\\h", " ")
}

/// Visible character count excluding line breaks (used for CPS).
pub fn visible_len(text: &str) -> usize {
    visible_text(text).chars().filter(|c| *c != '\n').count()
}

/// Lengths of each visible line.
pub fn line_lengths(text: &str) -> Vec<usize> {
    visible_text(text).split('\n').map(|l| l.chars().count()).collect()
}

/// Split into alternating (is_tag_block, content) segments.
pub fn segments(text: &str) -> Vec<(bool, String)> {
    let mut out = Vec::new();
    let mut last = 0;
    for m in block_re().find_iter(text) {
        if m.start() > last { out.push((false, text[last..m.start()].to_string())); }
        out.push((true, m.as_str().to_string()));
        last = m.end();
    }
    if last < text.len() { out.push((false, text[last..].to_string())); }
    out
}

/// Apply `f` to plain-text parts only, keeping `{...}` blocks untouched.
pub fn map_plain(text: &str, mut f: impl FnMut(&str) -> String) -> String {
    segments(text).into_iter().map(|(t, s)| if t { s } else { f(&s) }).collect()
}

/// Merge adjacent `{a}{b}` blocks into `{ab}`.
pub fn merge_blocks(text: &str) -> String {
    text.replace("}{", "")
}

/// Karaoke syllable: (duration in cs, text)
pub fn karaoke_syllables(text: &str) -> Vec<(i64, String)> {
    let re = Regex::new(r"\{[^}]*?\\k[fo]?(\d+)[^}]*\}").unwrap();
    let mut out = Vec::new();
    let mut pos = 0;
    let mut cur: Option<i64> = None;
    for c in re.captures_iter(text) {
        let m = c.get(0).unwrap();
        if let Some(d) = cur { out.push((d, text[pos..m.start()].to_string())); }
        cur = c[1].parse().ok();
        pos = m.end();
    }
    if let Some(d) = cur { out.push((d, text[pos..].to_string())); }
    out
}

/// Set (replace) `\pos(x,y)` in the first override block, creating one when needed.
pub fn set_pos(text: &str, x: f64, y: f64) -> String {
    let re = Regex::new(r"\\pos\([^)]*\)").unwrap();
    let f = |v: f64| { let s = format!("{:.2}", v); s.trim_end_matches('0').trim_end_matches('.').to_string() };
    let tag = format!("\\pos({},{})", f(x), f(y));
    if text.starts_with('{') {
        if let Some(end) = text.find('}') {
            let block = &text[..end];
            let cleaned = re.replace_all(block, "");
            return format!("{}{}{}", cleaned, tag, &text[end..]);
        }
    }
    format!("{{{}}}{}", tag, text)
}

//! Import/export of SRT and WebVTT, with format auto-detection.
use crate::ass::{AssFile, Event};
use crate::time;

fn html_to_ass(s: &str) -> String {
    let mut t = s.replace("\r", "");
    for (a, b) in [("<i>", "{\\i1}"), ("</i>", "{\\i0}"), ("<b>", "{\\b1}"), ("</b>", "{\\b0}"), ("<u>", "{\\u1}"), ("</u>", "{\\u0}"),
                   ("<I>", "{\\i1}"), ("</I>", "{\\i0}"), ("<B>", "{\\b1}"), ("</B>", "{\\b0}")] {
        t = t.replace(a, b);
    }
    // drop remaining tags e.g. <font ...>, <c.x>, <v Name>
    let re = regex::Regex::new(r"</?(font|c|v|ruby|rt|lang)[^>]*>").unwrap();
    t = re.replace_all(&t, "").into_owned();
    t = t.replace("&amp;", "&").replace("&lt;", "<").replace("&gt;", ">").replace("&nbsp;", "\\h");
    t.trim_end().replace('\n', "\\N")
}

fn ass_to_html(s: &str) -> String {
    let mut t = s.to_string();
    for (a, b) in [("{\\i1}", "<i>"), ("{\\i0}", "</i>"), ("{\\b1}", "<b>"), ("{\\b0}", "</b>"), ("{\\u1}", "<u>"), ("{\\u0}", "</u>")] {
        t = t.replace(a, b);
    }
    let t = crate::tags::strip_tags(&t);
    t.replace("\\N", "\n").replace("\\n", "\n").replace("\\h", " ")
}

fn parse_cues(input: &str, vtt: bool) -> Vec<Event> {
    let input = input.trim_start_matches('\u{feff}').replace("\r\n", "\n").replace('\r', "\n");
    let mut out = Vec::new();
    for block in input.split("\n\n") {
        let lines: Vec<&str> = block.lines().filter(|l| !l.is_empty() || true).collect();
        let Some(ti) = lines.iter().position(|l| l.contains("-->")) else { continue };
        let (a, b) = lines[ti].split_once("-->").unwrap();
        let b = b.trim().split_whitespace().next().unwrap_or("");
        let (Some(s), Some(e)) = (time::parse_generic(a), time::parse_generic(b)) else { continue };
        let _ = vtt;
        let text = lines[ti + 1..].join("\n");
        out.push(Event { start: s, end: e, text: html_to_ass(&text), ..Default::default() });
    }
    out
}

pub fn parse_srt(input: &str) -> AssFile {
    let mut f = AssFile::new_default();
    f.events = parse_cues(input, false);
    f
}

pub fn parse_vtt(input: &str) -> AssFile {
    let mut f = AssFile::new_default();
    f.events = parse_cues(input, true);
    f
}

pub fn to_srt(f: &AssFile) -> String {
    let mut o = String::new();
    let mut evs: Vec<&Event> = f.events.iter().filter(|e| !e.comment).collect();
    evs.sort_by_key(|e| e.start);
    for (i, e) in evs.iter().enumerate() {
        o.push_str(&format!("{}\n{} --> {}\n{}\n\n", i + 1, time::fmt_srt(e.start), time::fmt_srt(e.end), ass_to_html(&e.text)));
    }
    o
}

pub fn to_vtt(f: &AssFile) -> String {
    let mut o = String::from("WEBVTT\n\n");
    let mut evs: Vec<&Event> = f.events.iter().filter(|e| !e.comment).collect();
    evs.sort_by_key(|e| e.start);
    for e in evs {
        o.push_str(&format!("{} --> {}\n{}\n\n", time::fmt_vtt(e.start), time::fmt_vtt(e.end), ass_to_html(&e.text)));
    }
    o
}

/// Plain text transcript (one line per event).
pub fn to_txt(f: &AssFile) -> String {
    f.events.iter().filter(|e| !e.comment).map(|e| crate::tags::visible_text(&e.text).replace('\n', " ")).collect::<Vec<_>>().join("\n")
}

/// Detect by content/extension and parse.
pub fn open_any(name: &str, content: &str) -> Result<AssFile, crate::ass::ParseError> {
    let lower = name.to_ascii_lowercase();
    let head = content.trim_start_matches('\u{feff}').trim_start();
    if lower.ends_with(".vtt") || head.starts_with("WEBVTT") { return Ok(parse_vtt(content)); }
    if lower.ends_with(".srt") { return Ok(parse_srt(content)); }
    if head.starts_with('[') { return AssFile::parse(content); }
    if content.contains("-->") { return Ok(parse_srt(content)); }
    AssFile::parse(content)
}

//! Time helpers. All times are integer milliseconds.

/// Format as ASS `h:mm:ss.cc` (rounded to nearest centisecond like Aegisub).
pub fn fmt_ass(ms: i64) -> String {
    let ms = ms.max(0);
    let cs_total = (ms + 5) / 10;
    let cs = cs_total % 100;
    let s_total = cs_total / 100;
    format!("{}:{:02}:{:02}.{:02}", s_total / 3600, (s_total / 60) % 60, s_total % 60, cs)
}

/// Parse `h:mm:ss.cc` (also tolerates `.ms`, `,ms`, missing hours).
pub fn parse_ass(s: &str) -> Option<i64> {
    parse_generic(s)
}

pub fn fmt_srt(ms: i64) -> String {
    let ms = ms.max(0);
    format!("{:02}:{:02}:{:02},{:03}", ms / 3_600_000, (ms / 60_000) % 60, (ms / 1000) % 60, ms % 1000)
}

pub fn fmt_vtt(ms: i64) -> String {
    fmt_srt(ms).replace(',', ".")
}

pub fn parse_generic(s: &str) -> Option<i64> {
    let s = s.trim();
    let (main, frac) = match s.find(|c| c == '.' || c == ',') {
        Some(i) => (&s[..i], &s[i + 1..]),
        None => (s, ""),
    };
    let parts: Vec<&str> = main.split(':').collect();
    if parts.is_empty() || parts.len() > 3 {
        return None;
    }
    let mut total: i64 = 0;
    for p in &parts {
        total = total * 60 + p.trim().parse::<i64>().ok()?;
    }
    let mut ms = total * 1000;
    if !frac.is_empty() {
        if !frac.bytes().all(|b| b.is_ascii_digit()) {
            return None;
        }
        // 2 digits = centiseconds, 3 = ms, 1 = deciseconds
        let mut f: String = frac.chars().take(3).collect();
        while f.len() < 3 {
            f.push('0');
        }
        ms += f.parse::<i64>().ok()?;
    }
    Some(ms)
}

/// Frame <-> ms conversion for a constant frame rate (fps as rational num/den).
#[derive(Clone, Copy, Debug)]
pub struct FrameRate {
    pub num: f64,
    pub den: f64,
}

impl FrameRate {
    pub fn new(fps: f64) -> Self {
        if (fps - 23.976).abs() < 0.001 {
            return Self { num: 24000.0, den: 1001.0 };
        }
        if (fps - 29.97).abs() < 0.001 {
            return Self { num: 30000.0, den: 1001.0 };
        }
        if (fps - 59.94).abs() < 0.001 {
            return Self { num: 60000.0, den: 1001.0 };
        }
        Self { num: fps, den: 1.0 }
    }
    pub fn fps(&self) -> f64 {
        self.num / self.den
    }
    /// Frame start time (ms) like Aegisub's `ms_from_frame` for CFR (frame centre rounding).
    pub fn ms_from_frame(&self, frame: i64) -> i64 {
        ((frame as f64) * 1000.0 * self.den / self.num).round() as i64
    }
    pub fn frame_from_ms(&self, ms: i64) -> i64 {
        ((ms as f64) * self.num / (1000.0 * self.den)).floor() as i64
    }
    /// Time to use as a line start so the line appears exactly on `frame`.
    pub fn start_ms_for_frame(&self, frame: i64) -> i64 {
        let a = self.ms_from_frame(frame - 1);
        let b = self.ms_from_frame(frame);
        (a + b) / 2 + 1
    }
    pub fn end_ms_for_frame(&self, frame: i64) -> i64 {
        self.start_ms_for_frame(frame)
    }
}

//! Timing operations on selections of events.
use crate::ass::{AssFile, Event};
use crate::time::FrameRate;

pub fn shift(f: &mut AssFile, idx: &[usize], delta_ms: i64, start: bool, end: bool) {
    for &i in idx {
        if let Some(e) = f.events.get_mut(i) {
            if start { e.start = (e.start + delta_ms).max(0); }
            if end { e.end = (e.end + delta_ms).max(0); }
        }
    }
}

/// Linear retime: map two (old,new) anchor points.
pub fn linear(f: &mut AssFile, idx: &[usize], old1: i64, new1: i64, old2: i64, new2: i64) {
    if old2 == old1 { return; }
    let k = (new2 - new1) as f64 / (old2 - old1) as f64;
    for &i in idx {
        if let Some(e) = f.events.get_mut(i) {
            e.start = (new1 as f64 + (e.start - old1) as f64 * k).round().max(0.0) as i64;
            e.end = (new1 as f64 + (e.end - old1) as f64 * k).round().max(0.0) as i64;
        }
    }
}

/// Convert timings between frame rates (e.g. 23.976 -> 25).
pub fn change_fps(f: &mut AssFile, from: f64, to: f64) {
    let k = from / to;
    for e in &mut f.events {
        e.start = (e.start as f64 * k).round() as i64;
        e.end = (e.end as f64 * k).round() as i64;
    }
}

pub fn sort_by_start(f: &mut AssFile) {
    f.events.sort_by_key(|e| (e.start, e.end));
}

/// Make consecutive lines (sorted by time) contiguous when the gap is < `max_gap_ms`.
/// Returns number of lines changed.
pub fn close_gaps(f: &mut AssFile, max_gap_ms: i64) -> usize {
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment).collect();
    order.sort_by_key(|&i| f.events[i].start);
    let mut n = 0;
    for w in order.windows(2) {
        let (a, b) = (w[0], w[1]);
        let gap = f.events[b].start - f.events[a].end;
        if gap > 0 && gap < max_gap_ms { f.events[a].end = f.events[b].start; n += 1; }
    }
    n
}

/// Enforce a minimum gap between consecutive lines by trimming the earlier line's end (never below min_dur).
pub fn enforce_gap(f: &mut AssFile, min_gap_ms: i64, min_dur_ms: i64) -> usize {
    let mut order: Vec<usize> = (0..f.events.len()).filter(|&i| !f.events[i].comment).collect();
    order.sort_by_key(|&i| f.events[i].start);
    let mut n = 0;
    for w in order.windows(2) {
        let (a, b) = (w[0], w[1]);
        let gap = f.events[b].start - f.events[a].end;
        if gap < min_gap_ms {
            let new_end = (f.events[b].start - min_gap_ms).max(f.events[a].start + min_dur_ms);
            if new_end != f.events[a].end { f.events[a].end = new_end; n += 1; }
        }
    }
    n
}

/// Snap start/end to the nearest frame boundary.
pub fn snap_to_frames(f: &mut AssFile, idx: &[usize], fr: FrameRate) {
    for &i in idx {
        if let Some(e) = f.events.get_mut(i) {
            e.start = fr.start_ms_for_frame(fr.frame_from_ms(e.start + 1));
            e.end = fr.end_ms_for_frame(fr.frame_from_ms(e.end + 1));
        }
    }
}

/// Split an event at `at_ms` (and optionally at text position `char_pos`).
pub fn split(f: &mut AssFile, i: usize, at_ms: i64, char_pos: Option<usize>) -> bool {
    let Some(e) = f.events.get(i).cloned() else { return false };
    if at_ms <= e.start || at_ms >= e.end { return false; }
    let (t1, t2) = match char_pos {
        Some(p) => {
            let chars: Vec<char> = e.text.chars().collect();
            let p = p.min(chars.len());
            (chars[..p].iter().collect::<String>().trim_end().to_string(), chars[p..].iter().collect::<String>().trim_start().to_string())
        }
        None => (e.text.clone(), e.text.clone()),
    };
    let mut a = e.clone(); a.end = at_ms; a.text = t1;
    let mut b = e; b.start = at_ms; b.text = t2;
    f.events[i] = a;
    f.events.insert(i + 1, b);
    true
}

/// Merge events i..=j into one (texts joined with `\N`).
pub fn merge(f: &mut AssFile, i: usize, j: usize, sep: &str) {
    if i >= j || j >= f.events.len() { return; }
    let first = f.events[i].clone();
    let mut m = Event { text: String::new(), ..first };
    let slice: Vec<Event> = f.events.drain(i..=j).collect();
    m.start = slice.iter().map(|e| e.start).min().unwrap();
    m.end = slice.iter().map(|e| e.end).max().unwrap();
    m.text = slice.iter().map(|e| e.text.as_str()).collect::<Vec<_>>().join(sep);
    f.events.insert(i, m);
}

//! Turkish-aware text helpers (dotted/dotless I) plus common typography fixes.

pub fn to_upper(s: &str) -> String {
    s.chars().flat_map(|c| match c {
        'i' => vec!['İ'],
        'ı' => vec!['I'],
        c => c.to_uppercase().collect(),
    }).collect()
}

pub fn to_lower(s: &str) -> String {
    s.chars().flat_map(|c| match c {
        'I' => vec!['ı'],
        'İ' => vec!['i'],
        c => c.to_lowercase().collect(),
    }).collect()
}

/// Capitalise first letter of each word, Turkish rules.
pub fn title_case(s: &str) -> String {
    let mut out = String::new();
    let mut start = true;
    for c in s.chars() {
        if c.is_alphabetic() {
            if start { out.extend(to_upper(&c.to_string()).chars()); } else { out.extend(to_lower(&c.to_string()).chars()); }
            start = false;
        } else {
            out.push(c);
            start = !(c == '\'' || c == '’');
        }
    }
    out
}

/// Sentence case: first alphabetic char after `. ! ? ` or at start is upper.
pub fn sentence_case(s: &str) -> String {
    let mut out = String::new();
    let mut cap = true;
    for c in s.chars() {
        if c.is_alphabetic() {
            if cap { out.push_str(&to_upper(&c.to_string())); } else { out.push_str(&to_lower(&c.to_string())); }
            cap = false;
        } else {
            out.push(c);
            if matches!(c, '.' | '!' | '?' | '…') { cap = true; }
        }
    }
    out
}

/// Typography cleanup suited to Turkish subtitles. Operates on plain text only.
pub fn fix_typography(s: &str) -> String {
    let mut t = s.to_string();
    while t.contains("  ") { t = t.replace("  ", " "); }
    t = t.replace("...", "…");
    for p in [" ,", " .", " !", " ?", " ;", " :", " …"] {
        t = t.replace(p, &p[1..]);
    }
    t.trim().to_string()
}

//! Snapshot-based undo/redo (cheap enough for subtitle-sized documents).
use crate::ass::AssFile;

pub struct History {
    undo: Vec<(String, AssFile)>,
    redo: Vec<(String, AssFile)>,
    limit: usize,
}

impl History {
    pub fn new(limit: usize) -> Self { Self { undo: vec![], redo: vec![], limit } }
    /// Call BEFORE mutating `cur`.
    pub fn record(&mut self, label: &str, cur: &AssFile) {
        self.undo.push((label.to_string(), cur.clone()));
        if self.undo.len() > self.limit { self.undo.remove(0); }
        self.redo.clear();
    }
    pub fn undo(&mut self, cur: &mut AssFile) -> Option<String> {
        let (l, prev) = self.undo.pop()?;
        self.redo.push((l.clone(), std::mem::replace(cur, prev)));
        Some(l)
    }
    pub fn redo(&mut self, cur: &mut AssFile) -> Option<String> {
        let (l, next) = self.redo.pop()?;
        self.undo.push((l.clone(), std::mem::replace(cur, next)));
        Some(l)
    }
    pub fn can_undo(&self) -> bool { !self.undo.is_empty() }
    pub fn can_redo(&self) -> bool { !self.redo.is_empty() }
    pub fn undo_label(&self) -> Option<&str> { self.undo.last().map(|x| x.0.as_str()) }
}

cleantags_version = "1.302"

ktag = "\\[kK][fo]?[%d.]+"

--[[ The main function that performs the cleaning up
Takes: text
Returns: cleaned up text
]]
function cleantags(text)
	--[[ Combine adjacent override override blocks into one ]]
	function combineadjacentnotks(block1, block2)
		if string.find(block1, ktag) and string.find(block2, ktag) then
			-- if both adjacent override blocks have \k , let them be
			return "{" .. block1 .. "}" .. string.char(1) .. "{" .. block2 .. "}" -- char(1) prevents infinite loop
		else
			-- either one or both override blocks don't have \k , so combine them into one override block
			return "{" .. block1 .. block2 .. "}"
		end
	end
	repeat
		if aegisub.progress.is_cancelled() then return end
		text, replaced = string.gsub(text,"{(.-)}{(.-)}", combineadjacentnotks)
	until replaced == 0
	text = string.gsub(text, string.char(1), "") -- removes all char(1) we inserted

	--[[ Move first \k tag in override blocks to the front ]]
	text = string.gsub(text, "{([^{}]-)(" .. ktag .. ")(.-)}", "{%2%1%3}") 

	--[[ For some reasons if one override block has more than one \k tag, 
	push those to behind the first \k tag (which has been pushed to front already) ]]
	repeat
		if aegisub.progress.is_cancelled() then return end
		text, replaced = string.gsub(text, "{([^{}]-)(" .. ktag .. ")(\\[^kK][^}]-)(" .. ktag .. ")(.-)}", "{%1%2%4%3%5}")
	until replaced == 0
				
	--[[ Move to the front all tags that affect the whole line (i.e. not affected by their positions in the line) ]]
	local linetags = ""
	function first(pattern)
		local p_s, _, p_tag = string.find(text, pattern)
		if p_s then
			text = string.gsub(text, pattern, "")
			linetags = linetags .. p_tag				
		end
	end
	function firstoftwo(pattern1, pattern2)
		local p1_s, _, p1_tag = string.find(text, pattern1)
		local p2_s, _, p2_tag = string.find(text, pattern2)
		text = string.gsub(text, pattern1, "")
		text = string.gsub(text, pattern2, "")
		if p1_s and (not p2_s or p1_s < p2_s) then
			linetags = linetags .. p1_tag
		elseif p2_s then
			linetags = linetags .. p2_tag				
		end
	end
	-- \an or \a
	first("(\\an?%d+)")
	-- \org
	first("(\\org%([^,%)]*,[^,%)]*%))")
	-- \move and \pos (the first one wins)
	firstoftwo("(\\move%([^,%)]*,[^,%)]*,[^,%)]*,[^,%)]*%))", "(\\pos%([^,%)]*,[^,%)]*%))")
	-- \fade and \fad (the first one wins)
	firstoftwo("(\\fade%([^,%)]*,[^,%)]*,[^,%)]*,[^,%)]*,[^,%)]*,[^,%)]*,[^,%)]*%))", "(\\fad%([^,%)]*,[^,%)]*%))")
	-- integrate
	if string.len(linetags) > 0 then
		if string.sub(text, 1, 1) == "{" then
			text = "{" .. linetags .. string.sub(text, 2)
		else
			text = "{" .. linetags .. "}" .. text
		end
	end

	--[[ Remove any spaces within parentheses within override blocks except for \clip tags ]]
	local comb = function(a,b,c,d,e)
		if (c ~= "\\clip" and c ~= "\\iclip") or d:sub(-1):find("[,%({]") or e:sub(1,1):find("[,%)}]") then return a..b..d..e
		else return a..b..d..string.char(2)..e end
	end
    repeat
        text, replaced2 = string.gsub(text, "({[^}\\]*)([^}%s]*(\\[^%(}\\%s]*))%s*(%([^%s%)}]*)%s+([^}]*)", comb)
    until replaced2 == 0
    text, _ = text:gsub(string.char(2)," ")
		
	--[[ Remove all empty override blocks ==> {} ]]
	text = string.gsub(text, "{%s*}", "")

	--[[ Finally, return the cleaned up text ]]
	return text
end

-- Collect styles and metadata from the subs
function karaskel.collect_head(subs, generate_furigana)
	local meta = {
		-- X and Y script resolution
		res_x = 0, res_y = 0,
		-- Aspect ratio correction factor for video/script resolution mismatch
		video_x_correct_factor = 1.0
	}
	local styles = { n = 0 }
	local toinsert = {}
	local first_style_line = nil
	
	if not karaskel.furigana_scale then
		karaskel.furigana_scale = 0.5
	end
	
	-- First pass: collect all existing styles and get resolution info
	for i, l in ipairs(subs) do
		if aegisub.progress.is_cancelled() then error("User cancelled") end
		
		if l.class == "style" then
			if not first_style_line then
				first_style_line = i
			end
			-- Store styles into the style table
			styles.n = styles.n + 1
			styles[styles.n] = l
			styles[l.name] = l
			l.margin_v = l.margin_t -- convenience
			
			-- And also generate furigana styles if wanted
			if generate_furigana and not l.name:match("furigana") then
				aegisub.debug.out(5, "Creating furigana style for style: %s\n", l.name)
				local fs = table.copy(l)
				fs.fontsize = l.fontsize * karaskel.furigana_scale
				fs.outline = l.outline * karaskel.furigana_scale
				fs.shadow = l.shadow * karaskel.furigana_scale
				fs.name = l.name .. "-furigana"
				
				table.insert(toinsert, fs) -- queue to insert in file
			end
			
		elseif l.class == "info" then
			-- Also look for script resolution
			local k = l.key:lower()
			meta[k] = l.value
		else
			break
		end
	end
	
	if first_style_line == nil then
		error("Karaskel error: No styles were found in the file, bug?!")
	end
	
	-- Second pass: insert all toinsert styles that don't already exist
	for i = 1, #toinsert do
		if not styles[toinsert[i].name] then
			-- Insert into styles table
			styles.n = styles.n + 1
			styles[styles.n] = toinsert[i]
			styles[toinsert[i].name] = toinsert[i]
			-- And subtitle file
			subs[-first_style_line] = toinsert[i]
		end
	end
	
	-- Fix resolution data
	meta.res_x, meta.res_y = subs.script_resolution()
	
	local video_x, video_y = aegisub.video_size()
	if video_y then
		-- Correction factor for TextSub weirdness when render resolution does
		-- not match script resolution. Text pixels are considered square in
		-- render resolution rather than in script resolution, which is
		-- logically inconsistent. Correct for that.
		meta.video_x_correct_factor =
			(video_y / video_x) / (meta.res_y / meta.res_x)
	end
	aegisub.debug.out(4, "Karaskel: Video X correction factor = %f\n\n", meta.video_x_correct_factor)
	
	return meta, styles
end


-- Pre-process line, determining stripped text, karaoke data and splitting off furigana data
-- Modifies the object passed for line
function karaskel.preproc_line_text(meta, styles, line)
	-- Assume line is class=dialogue
	local kara = aegisub.parse_karaoke_data(line)
	line.kara = { n = 0 }
	line.furi = { n = 0 }
	
	line.text_stripped = ""
	line.duration = line.end_time - line.start_time
	
	local worksyl = { highlights = {n=0}, furi = {n=0} }
	local cur_inline_fx = ""
	for i = 0, #kara do
		local syl = kara[i]
		
		-- Detect any inline-fx tags
		local inline_fx = syl.text:match("%{.*\\%-([^}\\]+)")
		if inline_fx then
			cur_inline_fx = inline_fx
		end
		
		-- Strip spaces (only basic ones, no fullwidth etc.)
		local prespace, syltext, postspace = syl.text_stripped:match("^([ \t]*)(.-)([ \t]*)$")
		
		-- See if we've broken a (possible) multi-hl stretch
		-- If we did it's time for a new worksyl (though never for the zero'th syllable)
		local prefix = syltext:sub(1,unicode.charwidth(syltext,1))
		if prefix ~= "#" and prefix ~= "＃" and i > 0 then
			line.kara[line.kara.n] = worksyl
			line.kara.n = line.kara.n + 1
			worksyl = { highlights = {n=0}, furi = {n=0} }
		end

		-- Add highlight data
		local hl = {
			start_time = syl.start_time,
			end_time = syl.end_time,
			duration = syl.duration
		}
		worksyl.highlights.n = worksyl.highlights.n + 1
		worksyl.highlights[worksyl.highlights.n] = hl
		
		-- Detect furigana (both regular and fullwidth pipes work)
		-- Furigana is stored independently from syllables
		if syltext:find("|") or syltext:find("｜") then
			-- Replace fullwidth pipes, they aren't regex friendly
			syltext = syltext:gsub("｜", "|")
			-- Get before/after pipe text
			local maintext, furitext = syltext:match("^(.-)|(.-)$")
			syltext = maintext
			
			local furi = { }
			furi.syl = worksyl
			
			-- Magic happens here
			-- isbreak = Don't join this furi visually with previous furi, even if their main texts are adjacent
			-- spillback = Allow this furi text to spill over the left edge of the main text
			-- (Furi is always allowed to spill over the right edge of main text.)
			local prefix = furitext:sub(1,unicode.charwidth(furitext,1))
			if prefix == "!" or prefix == "！" then
				furi.isbreak = true
				furi.spillback = false
			elseif prefix == "<" or prefix == "＜" then
				furi.isbreak = true
				furi.spillback = true
			else
				furi.isbreak = false
				furi.spillback = false
			end
			-- Remove the prefix character from furitext, if there was one
			if furi.isbreak then
				furitext = furitext:sub(unicode.charwidth(furitext,1)+1)
			end
			
			-- Some of these may seem superfluous, but a furi should ideally have the same "interface" as a syllable
			furi.start_time = syl.start_time
			furi.end_time = syl.end_time
			furi.duration = syl.duration
			furi.kdur = syl.duration / 10
			furi.text = furitext
			furi.text_stripped = furitext
			furi.text_spacestripped = furitext
			furi.line = line
			furi.tag = syl.tag
			furi.inline_fx = cur_inline_fx
			furi.i = line.kara.n
			furi.prespace = ""
			furi.postspace = ""
			furi.highlights = { n=1, [1]=hl }
			furi.isfuri = true
			
			line.furi.n = line.furi.n + 1
			line.furi[line.furi.n] = furi
			worksyl.furi.n = worksyl.furi.n + 1
			worksyl.furi[worksyl.furi.n] = furi
		end
		
		-- Syllables that aren't part of a multi-highlight generate a new output-syllable
		if not worksyl.text or (prefix ~= "#" and prefix ~= "＃") then
			-- Update stripped line-text
			line.text_stripped = line.text_stripped .. prespace .. syltext .. postspace
			
			-- Copy data from syl to worksyl
			worksyl.text = syl.text
			worksyl.duration = syl.duration
			worksyl.kdur = syl.duration / 10
			worksyl.start_time = syl.start_time
			worksyl.end_time = syl.end_time
			worksyl.tag = syl.tag
			worksyl.line = line
			
			-- And add new data to worksyl
			worksyl.i = line.kara.n
			worksyl.text_stripped = prespace .. syltext .. postspace -- be sure to include the spaces so the original line can be built from text_stripped
			worksyl.inline_fx = cur_inline_fx
			worksyl.text_spacestripped = syltext
			worksyl.prespace = prespace
			worksyl.postspace = postspace
		else
			-- This is just an extra highlight
			worksyl.duration = worksyl.duration + syl.duration
			worksyl.kdur = worksyl.kdur + syl.duration / 10
			worksyl.end_time = syl.end_time
		end
	end

	-- Add the last syllable
	line.kara[line.kara.n] = worksyl
	-- But don't increment n here, n should be the highest syllable index! (The zero'th syllable doesn't count.)
end


-- Pre-calculate sizing information for the given line, no layouting is done
-- Modifies the object passed for line
function karaskel.preproc_line_size(meta, styles, line)
	if not line.kara then
		karaskel.preproc_line_text(meta, styles, line)
	end
	
	-- Add style information
	if styles[line.style] then
		line.styleref = styles[line.style]
	else
		aegisub.debug.out(2, "WARNING: Style not found: " .. line.style .. "\n")
		line.styleref = styles[1]
	end
	
	-- Calculate whole line sizing
	line.width, line.height, line.descent, line.extlead = aegisub.text_extents(line.styleref, line.text_stripped)
	line.width = line.width * meta.video_x_correct_factor

	-- Calculate syllable sizing
	for s = 0, line.kara.n do
		local syl = line.kara[s]
		syl.style = line.styleref
		syl.width, syl.height = aegisub.text_extents(syl.style, syl.text_spacestripped)
		syl.width = syl.width * meta.video_x_correct_factor
		syl.prespacewidth = aegisub.text_extents(syl.style, syl.prespace) * meta.video_x_correct_factor
		syl.postspacewidth = aegisub.text_extents(syl.style, syl.postspace) * meta.video_x_correct_factor
	end
	
	-- Calculate furigana sizing
	if styles[line.style .. "-furigana"] then
		line.furistyle = styles[line.style .. "-furigana"]
	else
		aegisub.debug.out(4, "No furigana style defined for style '%s'\n", line.style)
		line.furistyle = false
	end
	if line.furistyle then
		for f = 1, line.furi.n do
			local furi = line.furi[f]
			furi.style = line.furistyle
			furi.width, furi.height = aegisub.text_extents(furi.style, furi.text)
			furi.width = furi.width * meta.video_x_correct_factor
			furi.prespacewidth = 0
			furi.postspacewidth = 0
		end
	end
end


-- Layout a line, including furigana layout
-- Modifies the object passed for line
function karaskel.preproc_line_pos(meta, styles, line)
	if not line.styleref then
		karaskel.preproc_line_size(meta, styles, line)
	end
	
	-- Syllable layouting must be done before the rest, since furigana layout may change the total width of the line
	if line.furistyle then
		karaskel.do_furigana_layout(meta, styles, line)
	else
		karaskel.do_basic_layout(meta, styles, line)
	end

	-- Effective margins
	line.margin_v = line.margin_t
	line.eff_margin_l = ((line.margin_l > 0) and line.margin_l) or line.styleref.margin_l
	line.eff_margin_r = ((line.margin_r > 0) and line.margin_r) or line.styleref.margin_r
	line.eff_margin_t = ((line.margin_t > 0) and line.margin_t) or line.styleref.margin_t
	line.eff_margin_b = ((line.margin_b > 0) and line.margin_b) or line.styleref.margin_b
	line.eff_margin_v = ((line.margin_v > 0) and line.margin_v) or line.styleref.margin_v
	-- And positioning
	if line.styleref.align == 1 or line.styleref.align == 4 or line.styleref.align == 7 then
		-- Left aligned
		line.left = line.eff_margin_l
		line.center = line.left + line.width / 2
		line.right = line.left + line.width
		line.x = line.left
		line.halign = "left"
	elseif line.styleref.align == 2 or line.styleref.align == 5 or line.styleref.align == 8 then
		-- Centered
		line.left = (meta.res_x - line.eff_margin_l - line.eff_margin_r - line.width) / 2 + line.eff_margin_l
		line.center = line.left + line.width / 2
		line.right = line.left + line.width
		line.x = line.center
		line.halign = "center"
	elseif line.styleref.align == 3 or line.styleref.align == 6 or line.styleref.align == 9 then
		-- Right aligned
		line.left = meta.res_x - line.eff_margin_r - line.width
		line.center = line.left + line.width / 2
		line.right = line.left + line.width
		line.x = line.right
		line.halign = "right"
	end
	line.hcenter = line.center
	if line.styleref.align >=1 and line.styleref.align <= 3 then
		-- Bottom aligned
		line.bottom = meta.res_y - line.eff_margin_b
		line.middle = line.bottom - line.height / 2
		line.top = line.bottom - line.height
		line.y = line.bottom
		line.valign = "bottom"
	elseif line.styleref.align >= 4 and line.styleref.align <= 6 then
		-- Mid aligned
		line.top = (meta.res_y - line.eff_margin_t - line.eff_margin_b - line.height) / 2 + line.eff_margin_t
		line.middle = line.top + line.height / 2
		line.bottom = line.top + line.height
		line.y = line.middle
		line.valign = "middle"
	elseif line.styleref.align >= 7 and line.styleref.align <= 9 then
		-- Top aligned
		line.top = line.eff_margin_t
		line.middle = line.top + line.height / 2
		line.bottom = line.top + line.height
		line.y = line.top
		line.valign = "top"
	end
	line.vcenter = line.middle
end


-- Do simple syllable layouting (no furigana)
function karaskel.do_basic_layout(meta, styles, line)
	local curx = 0
	for i = 0, line.kara.n do
		local syl = line.kara[i]
		syl.left = curx + syl.prespacewidth
		syl.center = syl.left + syl.width / 2
		syl.right = syl.left + syl.width
		curx = curx + syl.prespacewidth + syl.width + syl.postspacewidth
	end
end


-- Do advanced furigana layout algorithm
function karaskel.do_furigana_layout(meta, styles, line)
	-- Start by building layout groups
	-- Two neighboring syllables with furigana that join together are part of the same layout group
	-- A forced split creates a new layout group
	local lgroups = {}
	-- Start-sentinel
	local lgsentinel = {basewidth=0, furiwidth=0, syls={}, furi={}, spillback=false, left=0, right=0}
	table.insert(lgroups, lgsentinel)
	-- Create groups
	local last_had_furi = false
	local lg = { basewidth=0, furiwidth=0, syls={}, furi={}, spillback=false }
	for s = 0, line.kara.n do
		local syl = line.kara[s]
		-- Furigana-less syllables always generate a new layout group
		-- So do furigana-endowed syllables that are marked as split
		-- But if current lg has no width (usually only first) don't create a new
		aegisub.debug.out(5, "syl.furi.n=%d, isbreak=%s, last_had_furi=%s, lg.basewidth=%d\n", syl.furi.n, syl.furi.n > 0 and syl.furi[1].isbreak and "y" or "n", last_had_furi and "y" or "n", lg.basewidth)
		if (syl.furi.n == 0 or syl.furi[1].isbreak or not last_had_furi) and lg.basewidth > 0 then
			aegisub.debug.out(5, "Inserting layout group, basewidth=%d, furiwidth=%d, isbreak=%s\n", lg.basewidth, lg.furiwidth, syl.furi.n > 0 and syl.furi[1].isbreak and "y" or "n")
			table.insert(lgroups, lg)
			lg = { basewidth=0, furiwidth=0, syls={}, furi={}, spillback=false }
			last_had_furi = false
		end
		
		-- Add this syllable to lg
		lg.basewidth = lg.basewidth + syl.prespacewidth + syl.width + syl.postspacewidth
		table.insert(lg.syls, syl)
		aegisub.debug.out(5, "\tAdding syllable to layout group: '%s', width=%d, isbreak=%s\n", syl.text_stripped, syl.width, syl.furi.n > 0 and syl.furi[1].isbreak and "y" or "n")
		
		-- Add this syllable's furi to lg
		for f = 1, syl.furi.n do
			local furi = syl.furi[f]
			lg.furiwidth = lg.furiwidth + furi.width
			lg.spillback = lg.spillback or furi.spillback
			table.insert(lg.furi, furi)
			aegisub.debug.out(5, "\tAdding furigana to layout group: %s (width=%d)\n", furi.text, furi.width)
			last_had_furi = true
		end
	end
	-- Insert last lg
	aegisub.debug.out(5, "Inserting layout group, basewidth=%d, furiwidth=%d\n", lg.basewidth, lg.furiwidth)
	table.insert(lgroups, lg)
	-- And end-sentinel
	table.insert(lgroups, lgsentinel)

	aegisub.debug.out(5, "\nProducing layout from %d layout groups\n", #lgroups-1)
	-- Layout the groups at macro-level
	-- Skip sentinel at ends in loop
	local curx = 0
	for i = 2, #lgroups-1 do
		local lg = lgroups[i]
		local prev = lgroups[i-1]
		aegisub.debug.out(5, "Layout group, nsyls=%d, nfuri=%d, syl1text='%s', basewidth=%f furiwidth=%f, ", #lg.syls, #lg.furi, lg.syls[1] and lg.syls[1].text or "", lg.basewidth, lg.furiwidth)
		
		-- Three cases: No furigana, furigana smaller than base and furigana larger than base
		if lg.furiwidth == 0 then
			-- Here wa can basically just place the base text
			lg.left = curx
			lg.right = lg.left + lg.basewidth
			-- If there was any spillover from a previous group, add it to here
			if prev.rightspill  and prev.rightspill > 0 then
				aegisub.debug.out(5, "eat rightspill=%f, ", prev.rightspill)
				lg.leftspill = 0
				lg.rightspill = prev.rightspill - lg.basewidth
				prev.rightspill = 0
			end
			curx = curx + lg.basewidth
		elseif lg.furiwidth <= lg.basewidth then
			-- If there was any rightspill from previous group, we have to stay 100% clear of that
			if prev.rightspill and prev.rightspill > 0 then
				aegisub.debug.out(5, "skip rightspill=%f, ", prev.rightspill)
				curx = curx + prev.rightspill
				prev.rightspill = 0
			end
			lg.left = curx
			lg.right = lg.left + lg.basewidth
			curx = curx + lg.basewidth
			-- Negative spill here
			lg.leftspill = (lg.furiwidth - lg.basewidth) / 2
			lg.rightspill = lg.leftspill
		else
			-- Furigana is wider than base, we'll have to spill in some direction
			if prev.rightspill and prev.rightspill > 0 then
				aegisub.debug.out(5, "skip rightspill=%f, ", prev.rightspill)
				curx = curx + prev.rightspill
				prev.rightspill = 0
			end
			-- Do we spill only to the right or in both directions?
			if lg.spillback then
				-- Both directions
				lg.leftspill = (lg.furiwidth - lg.basewidth) / 2
				lg.rightspill = lg.leftspill
				aegisub.debug.out(5, "spill left=%f right=%f, ", lg.leftspill, lg.rightspill)
				-- If there was any furigana or spill on previous syllable we can't overlap it
				if prev.rightspill then
					lg.left = curx + lg.leftspill
				else
					lg.left = curx
				end
			else
				-- Only to the right
				lg.leftspill = 0
				lg.rightspill = lg.furiwidth - lg.basewidth
				aegisub.debug.out(5, "spill right=%f, ", lg.rightspill)
				lg.left = curx
			end
			lg.right = lg.left + lg.basewidth
			curx = lg.right
		end
		aegisub.debug.out(5, "left=%f, right=%f\n", lg.left, lg.right)
	end
	
	-- Now the groups are layouted, so place the individual syllables/furigana
	for i, lg in ipairs(lgroups) do
		local basecenter = (lg.left + lg.right) / 2 -- centered furi is centered over this
		local curx = lg.left -- base text is placed from here on
		-- Place base syllables
		for s, syl in ipairs(lg.syls) do
			syl.left = curx + syl.prespacewidth
			syl.center = syl.left + syl.width/2
			syl.right = syl.left + syl.width
			curx = syl.right + syl.postspacewidth
		end
		if curx > line.width then line.width = curx end
		-- Place furigana
		if lg.furiwidth < lg.basewidth or lg.spillback then
			-- Center over group
			curx = lg.left + (lg.basewidth - lg.furiwidth) / 2
		else
			-- Left aligned
			curx = lg.left
		end
		for f, furi in ipairs(lg.furi) do
			furi.left = curx
			furi.center = furi.left + furi.width/2
			furi.right = furi.left + furi.width
			curx = furi.right
		end
	end
end


-- Precalc some info on a line
-- Modifies the line parameter
function karaskel.preproc_line(subs, meta, styles, line)
	-- subs parameter is never used and probably won't ever be
	-- (it wouldn't be fun if some lines suddenly changed index here)

	karaskel.preproc_line_pos(meta, styles, line)
end


-- An actual "skeleton" function
-- Parses the first word out of the Effect field of each dialogue line and runs "fx_"..effect on that line
-- Lines with empty Effect field run fx_none
-- Lines with unimplemented effects are left alone
-- If the effect function returns true, the original line is kept in output,
-- otherwise the original line is converted to a comment
-- General prototype of an fx function: function(subs, meta, styles, line, fxdata)
-- fxdata are extra data after the effect name in the Effect field
local fx_library_registered = false
function karaskel.use_fx_library_furi(use_furigana, macrotoo)
	local function fx_library_main(subs)
		aegisub.progress.task("Collecting header info")
		meta, styles = karaskel.collect_head(subs, use_furigana)
		
		aegisub.progress.task("Processing subs")
		local i, maxi = 1, #subs
		while i <= maxi do
			aegisub.progress.set(i/maxi*100)
			local l = subs[i]
			
			if l.class == "dialogue" then
				aegisub.progress.task(l.text)
				karaskel.preproc_line(subs, meta, styles, l)
				local keep = true
				local fx, fxdata = string.headtail(l.effect)
				if fx == "" then fx = "none" end
				if _G["fx_" .. fx] then
					-- note to casual readers: _G is a special global variable that points to the global environment
					-- specifically, _G["_G"] == _G
					keep = _G["fx_" .. fx](subs, meta, styles, l, fxdata)
				end
				if not keep then
					l = subs[i]
					l.comment = true
					subs[i] = l
				end
			end
			
			i = i + 1
		end
	end

	if fx_library_registered then return end
	aegisub.register_filter(script_name or "fx_library", script_description or "Apply karaoke effects (fx_library skeleton)", 2000, fx_library_main)
	
	if macrotoo then
		local function fxlibmacro(subs)
			fx_library_main(subs)
			aegisub.set_undo_point(script_name or "karaoke effect")
		end
		aegisub.register_macro(script_name or "fx_library", script_description or "Apply karaoke effects (fx_library skeleton)", fxlibmacro)
	end
end
function karaskel.use_fx_library(macrotoo)
	return karaskel.use_fx_library_furi(false, macrotoo)
end


-- A skeleton that approximately simulates the Auto3 "advanced" one.
-- Build a Auto3-like list of dialogue lines and also add linked list refs to lines.
-- Call user-defined do_line function for each line, if it exists.
-- The default do_line function will call the do_syllable function for each line,
-- if the function exists.
-- The function names called are constant.
local classic_adv_registered = false
function karaskel.use_classic_adv(use_furigana, macrotoo)
	local function classic_adv_main(subs)
		
		local function default_do_syllable(subs, meta, styles, lines, line, syl)
			-- do nothing
		end
	
		local sylfunc = (type(_G.do_syllable)=="function" and _G.do_syllable) or default_do_syllable
		local furifunc = (type(_G.do_furigana)=="function" and _G.do_furigana) or default_do_syllable

		local function default_do_line(subs, meta, styles, lines, line)
			for i = 0, line.kara.n do
				sylfunc(subs, meta, styles, lines, line, line.kara[i])
			end
			if use_furigana then
				for i = 0, line.furi.n do
					furifunc(subs, meta, styles, lines, line, line.furi[i])
				end
			end
		end
		
		aegisub.progress.task("Collecting header info")
		local meta, styles = karaskel.collect_head(subs, use_furigana)
		
		-- Collect lines
		aegisub.progress.task("Collecting subtitle lines")
		local lines = { n=0 }
		local prevline = nil
		local i = 1
		local curorgline, maxorglines = 1, #subs
		while i <= #subs do
			aegisub.progress.set(curorgline/maxorglines*100)
			local l = subs[i]
			if l.class == "dialogue" then
				-- Link prev of this one
				karaskel.preproc_line(subs, meta, styles, l)
				l.prev = prevline
				l.next = nil
				-- Line next of prev one
				if prevline then
					prevline.next = l
				end
				-- Insert into array
				lines.n = lines.n + 1
				lines[lines.n] = l
				-- Update prev
				prevline = l
				-- Delete from file
				subs[i] = nil
			else
				-- Only increase for non-dialogue lines
				-- (Dialogue lines are deleted, so every other lines moves one down)
				 i = i + 1
			end
			curorgline = curorgline + 1
		end
		
		aegisub.progress.task("Processing subtitles")
		local linefunc = default_do_line
		if type(_G.do_line)=="function" then
			linefunc = function(subs, meta, styles, lines, line)
				return _G.do_line(subs, meta, styles, lines, line, default_do_line)
			end
		end
		for i = 1, lines.n do
			aegisub.progress.set(i/lines.n*100)
			linefunc(subs, meta, styles, lines, lines[i])
		end
		
		aegisub.progress.task("Finished")
		aegisub.progress.set(100)
	end
	
	if classic_adv_registered then return end
	aegisub.register_filter(script_name or "classic_adv", script_description or "Apply karaoke effects (classic_adv skeleton)", 2000, classic_adv_main)
	
	if macrotoo then
		local function classic_adv_macro(subs)
			classic_adv_main(subs)
			aegisub.set_undo_point(script_name or "karaoke effect")
		end
		aegisub.register_macro(script_name or "classic_adv", script_description or "Apply karaoke effects (classic_adv skeleton)", classic_adv_macro)
	end
end

-- Minimal utf8 library (Lua 5.3 API subset) for Lua 5.1
local utf8 = {}
utf8.charpattern = "[\0-\127\194-\244][\128-\191]*"
function utf8.char(...)
  local t = {}
  for i, c in ipairs({ ... }) do
    if c < 0x80 then t[i] = string.char(c)
    elseif c < 0x800 then t[i] = string.char(0xC0 + math.floor(c / 64), 0x80 + c % 64)
    elseif c < 0x10000 then t[i] = string.char(0xE0 + math.floor(c / 4096), 0x80 + math.floor(c / 64) % 64, 0x80 + c % 64)
    else t[i] = string.char(0xF0 + math.floor(c / 262144), 0x80 + math.floor(c / 4096) % 64, 0x80 + math.floor(c / 64) % 64, 0x80 + c % 64) end
  end
  return table.concat(t)
end
function utf8.len(s, i, j)
  i = i or 1; j = j or #s
  local n = 0
  for p = i, j do local b = s:byte(p); if b < 0x80 or b >= 0xC0 then n = n + 1 end end
  return n
end
function utf8.codepoint(s, i, j)
  i = i or 1; j = j or i
  local out = {}
  local p = i
  while p <= j do
    local b = s:byte(p)
    local c, n
    if b < 0x80 then c, n = b, 1
    elseif b < 0xE0 then c, n = (b - 0xC0) * 64 + (s:byte(p + 1) - 0x80), 2
    elseif b < 0xF0 then c, n = (b - 0xE0) * 4096 + (s:byte(p + 1) - 0x80) * 64 + (s:byte(p + 2) - 0x80), 3
    else c, n = (b - 0xF0) * 262144 + (s:byte(p + 1) - 0x80) * 4096 + (s:byte(p + 2) - 0x80) * 64 + (s:byte(p + 3) - 0x80), 4 end
    out[#out + 1] = c; p = p + n
  end
  return unpack(out)
end
function utf8.codes(s)
  local p = 1
  return function()
    if p > #s then return nil end
    local c = utf8.codepoint(s, p)
    local b = s:byte(p)
    local n = b < 0x80 and 1 or b < 0xE0 and 2 or b < 0xF0 and 3 or 4
    local pos = p
    p = p + n
    return pos, c
  end
end
function utf8.offset(s, n, i)
  i = i or (n > 0 and 1 or #s + 1)
  if n > 0 then
    local p = i
    while n > 1 and p <= #s do p = p + 1; while p <= #s and s:byte(p) >= 0x80 and s:byte(p) < 0xC0 do p = p + 1 end; n = n - 1 end
    return p
  end
  return i
end
return utf8

-- OsioSub util.lua : compatible with Aegisub's util.lua
local util = {}

function util.copy(t)
  local r = {}
  for k, v in pairs(t) do r[k] = v end
  return r
end

function util.deep_copy(t)
  local seen = {}
  local function c(o)
    if type(o) ~= "table" then return o end
    if seen[o] then return seen[o] end
    local r = {}
    seen[o] = r
    for k, v in pairs(o) do r[c(k)] = c(v) end
    return setmetatable(r, getmetatable(o))
  end
  return c(t)
end

function util.clamp(v, lo, hi) return math.max(lo, math.min(hi, v)) end
function util.min(a, b) return a < b and a or b end
function util.max(a, b) return a > b and a or b end

function util.ass_color(r, g, b)
  return string.format("&H%02X%02X%02X&", util.clamp(math.floor(b + 0.5), 0, 255), util.clamp(math.floor(g + 0.5), 0, 255), util.clamp(math.floor(r + 0.5), 0, 255))
end
function util.ass_alpha(a) return string.format("&H%02X&", util.clamp(math.floor(a + 0.5), 0, 255)) end
function util.ass_style_color(r, g, b, a)
  return string.format("&H%02X%02X%02X%02X", util.clamp(math.floor((a or 0) + 0.5), 0, 255), util.clamp(math.floor(b + 0.5), 0, 255), util.clamp(math.floor(g + 0.5), 0, 255), util.clamp(math.floor(r + 0.5), 0, 255))
end

function util.extract_color(s)
  local a, b, g, r = 0, 0, 0, 0
  local alpha = s:match("^&H(%x%x)&$")
  if alpha then return tonumber(alpha, 16), 0, 0, 0 end
  local hex = s:match("^&H(%x+)&?$")
  if hex then
    hex = string.rep("0", 8 - #hex) .. hex
    a, b, g, r = hex:match("(%x%x)(%x%x)(%x%x)(%x%x)")
    return tonumber(r, 16), tonumber(g, 16), tonumber(b, 16), tonumber(a, 16)
  end
  local n = s:match("^(%d+)$")
  if n then
    n = tonumber(n)
    return n % 256, math.floor(n / 256) % 256, math.floor(n / 65536) % 256, 0
  end
  return 0, 0, 0, 0
end
function util.alpha_from_style(s) local _, _, _, a = util.extract_color(s); return util.ass_alpha(a) end
function util.color_from_style(s) local r, g, b = util.extract_color(s); return util.ass_color(r, g, b) end

function util.HSV_to_RGB(H, S, V)
  H = H % 360
  local c = V * S / 255
  local h = H / 60
  local x = c * (1 - math.abs(h % 2 - 1))
  local r, g, b = 0, 0, 0
  if h < 1 then r, g, b = c, x, 0 elseif h < 2 then r, g, b = x, c, 0 elseif h < 3 then r, g, b = 0, c, x
  elseif h < 4 then r, g, b = 0, x, c elseif h < 5 then r, g, b = x, 0, c else r, g, b = c, 0, x end
  local m = V - c
  return math.floor(r + m + 0.5), math.floor(g + m + 0.5), math.floor(b + m + 0.5)
end
function util.HSL_to_RGB(H, S, L)
  H = H % 360
  local s, l = S / 255, L / 255
  local c = (1 - math.abs(2 * l - 1)) * s
  local h = H / 60
  local x = c * (1 - math.abs(h % 2 - 1))
  local r, g, b = 0, 0, 0
  if h < 1 then r, g, b = c, x, 0 elseif h < 2 then r, g, b = x, c, 0 elseif h < 3 then r, g, b = 0, c, x
  elseif h < 4 then r, g, b = 0, x, c elseif h < 5 then r, g, b = x, 0, c else r, g, b = c, 0, x end
  local m = l - c / 2
  return math.floor((r + m) * 255 + 0.5), math.floor((g + m) * 255 + 0.5), math.floor((b + m) * 255 + 0.5)
end
function util.RGB_to_HSV(r, g, b)
  local mx, mn = math.max(r, g, b), math.min(r, g, b)
  local d = mx - mn
  local h = 0
  if d ~= 0 then
    if mx == r then h = ((g - b) / d) % 6 elseif mx == g then h = (b - r) / d + 2 else h = (r - g) / d + 4 end
    h = h * 60
  end
  local s = mx == 0 and 0 or d / mx * 255
  return math.floor(h + 0.5), math.floor(s + 0.5), mx
end
function util.RGB_to_HSL(r, g, b)
  local mx, mn = math.max(r, g, b), math.min(r, g, b)
  local d = (mx - mn) / 255
  local l = (mx + mn) / 510
  local h = 0
  if d ~= 0 then
    local dd = mx - mn
    if mx == r then h = ((g - b) / dd) % 6 elseif mx == g then h = (b - r) / dd + 2 else h = (r - g) / dd + 4 end
    h = h * 60
  end
  local s = d == 0 and 0 or d / (1 - math.abs(2 * l - 1))
  return math.floor(h + 0.5), math.floor(s * 255 + 0.5), math.floor(l * 255 + 0.5)
end

function util.interpolate(pct, a, b) return a + (b - a) * pct end
function util.interpolate_color(pct, c1, c2)
  local r1, g1, b1 = util.extract_color(c1)
  local r2, g2, b2 = util.extract_color(c2)
  return util.ass_color(util.interpolate(pct, r1, r2), util.interpolate(pct, g1, g2), util.interpolate(pct, b1, b2))
end
function util.interpolate_alpha(pct, a1, a2)
  local _, _, _, x = util.extract_color(a1)
  local _, _, _, y = util.extract_color(a2)
  return util.ass_alpha(util.interpolate(pct, x, y))
end

function util.fix_fontname(name)
  if name:sub(1, 1) == "@" then return name:sub(2) end
  return name
end

function util.uuid()
  local t = {}
  for i = 1, 16 do t[i] = math.random(0, 255) end
  t[7] = t[7] % 16 + 64; t[9] = t[9] % 64 + 128
  return string.format("%02x%02x%02x%02x-%02x%02x-%02x%02x-%02x%02x-%02x%02x%02x%02x%02x%02x", unpack(t))
end

function util.trim(s) return (s:gsub("^%s+", ""):gsub("%s+$", "")) end
function util.headtail(s)
  local a, b = s:match("^%s*(%S+)%s*(.-)%s*$")
  if not a then return "", "" end
  return a, b
end
function util.words(s)
  return function()
    local w
    w, s = s:match("^%s*(%S+)%s*(.*)$")
    return w
  end
end

//! Real font metrics (system fonts) for `aegisub.text_extents`, GDI/VSFilter-style:
//! font size maps to the cell height (ascent+descent), no kerning.
use fontdb::{Database, Family, Query, Stretch, Style as FStyle, Weight};
use osiosub_core::ass::Style;
use std::sync::{Mutex, OnceLock};

fn db() -> &'static Mutex<Database> {
    static DB: OnceLock<Mutex<Database>> = OnceLock::new();
    DB.get_or_init(|| {
        let mut d = Database::new();
        d.load_system_fonts();
        for dir in ["fonts", "automation/fonts", "."] {
            if std::path::Path::new(dir).is_dir() { d.load_fonts_dir(dir); }
        }
        Mutex::new(d)
    })
}

/// Add a font directory (e.g. the folder next to the subtitle file).
pub fn add_font_dir(p: &std::path::Path) { db().lock().unwrap().load_fonts_dir(p); }

pub fn has_font(name: &str) -> bool {
    let d = db().lock().unwrap();
    d.query(&Query { families: &[Family::Name(name)], ..Default::default() }).is_some()
}

/// Returns (width, height, descent, external_leading) or None if the font can't be found.
pub fn extents(style: &Style, text: &str) -> Option<(f64, f64, f64, f64)> {
    let d = db().lock().unwrap();
    let name = style.fontname.trim_start_matches('@');
    let q = Query {
        families: &[Family::Name(name), Family::SansSerif],
        weight: if style.bold { Weight::BOLD } else { Weight::NORMAL },
        stretch: Stretch::Normal,
        style: if style.italic { FStyle::Italic } else { FStyle::Normal },
    };
    let id = d.query(&q)?;
    d.with_face_data(id, |data, idx| {
        let face = ttf_parser::Face::parse(data, idx).ok()?;
        let upm = face.units_per_em() as f64;
        let (asc, desc) = match face.tables().os2 {
            Some(os2) => (os2.windows_ascender() as f64, -(os2.windows_descender() as f64)),
            None => (face.ascender() as f64, -(face.descender() as f64)),
        };
        let cell = (asc + desc).max(1.0);
        let scale = style.fontsize / cell;
        let _ = upm;
        let mut w = 0.0;
        let mut n = 0usize;
        for c in text.chars() {
            if c == '\n' { continue; }
            let adv = face.glyph_index(c).and_then(|g| face.glyph_hor_advance(g)).unwrap_or((upm * 0.5) as u16) as f64;
            w += adv * scale;
            n += 1;
        }
        w = w * style.scale_x / 100.0 + style.spacing * n as f64;
        let lg = face.line_gap() as f64 * scale;
        Some((w, style.fontsize * style.scale_y / 100.0, desc * scale * style.scale_y / 100.0, lg))
    })?
}

//! Interface between the Lua runtime and the application (dialogs, metrics, video).
use osiosub_core::ass::Style;
use std::collections::BTreeMap;

#[derive(Clone, Debug, PartialEq)]
pub enum DlgVal { Str(String), Num(f64), Bool(bool) }

#[derive(Clone, Debug, Default)]
pub struct DialogControl {
    pub class: String,
    pub name: String,
    pub x: i32, pub y: i32, pub width: i32, pub height: i32,
    pub label: String,
    pub text: String,
    pub hint: String,
    pub value: Option<DlgVal>,
    pub min: Option<f64>, pub max: Option<f64>, pub step: Option<f64>,
    pub items: Vec<String>,
}

#[derive(Clone, Debug, Default)]
pub struct DialogSpec {
    pub controls: Vec<DialogControl>,
    pub buttons: Vec<String>,
}

#[derive(Clone, Debug)]
pub struct DialogResult {
    /// Pressed button label; `None` = cancelled.
    pub button: Option<String>,
    pub values: BTreeMap<String, DlgVal>,
}

pub trait Host {
    /// Show a dialog. Default: "press first button with the defaults".
    fn dialog(&mut self, spec: &DialogSpec) -> DialogResult {
        let mut values = BTreeMap::new();
        for c in &spec.controls {
            if c.name.is_empty() { continue; }
            let v = match c.class.as_str() {
                "checkbox" => Some(c.value.clone().unwrap_or(DlgVal::Bool(false))),
                "dropdown" => Some(c.value.clone().unwrap_or_else(|| DlgVal::Str(c.items.first().cloned().unwrap_or_default()))),
                "label" => None,
                "intedit" | "floatedit" | "slider" => Some(c.value.clone().unwrap_or(DlgVal::Num(c.min.unwrap_or(0.0)))),
                _ => Some(c.value.clone().unwrap_or_else(|| DlgVal::Str(c.text.clone()))),
            };
            if let Some(v) = v { values.insert(c.name.clone(), v); }
        }
        let button = spec.buttons.first().cloned().or(Some("OK".into()));
        DialogResult { button, values }
    }
    /// Returns (width, height, descent, external_leading) in script pixels.
    fn text_extents(&self, style: &Style, text: &str) -> (f64, f64, f64, f64) {
        crate::fonts::extents(style, text).unwrap_or_else(|| approx_extents(style, text))
    }
    fn log(&mut self, msg: &str) { eprint!("{}", msg); }
    fn video_size(&self) -> Option<(i32, i32)> { None }
    fn fps(&self) -> Option<f64> { None }
    fn keyframes(&self) -> Vec<i64> { vec![] }
    fn clipboard_get(&self) -> Option<String> { None }
    fn clipboard_set(&mut self, _s: &str) -> bool { false }
    fn progress(&mut self, _percent: f64, _task: &str, _title: &str) {}
}

pub struct DefaultHost;
impl Host for DefaultHost {}

/// Rough metrics when no font engine is available.
pub fn approx_extents(style: &Style, text: &str) -> (f64, f64, f64, f64) {
    let fs = style.fontsize;
    let mut w = 0.0;
    for c in text.chars() {
        let f = match c {
            ' ' => 0.28, 'i' | 'l' | 'j' | '.' | ',' | '\'' | '!' | ':' | ';' | '|' => 0.26,
            'm' | 'w' | 'M' | 'W' => 0.85,
            c if c.is_uppercase() => 0.66,
            c if (c as u32) > 0x2E80 => 1.0,
            _ => 0.52,
        };
        w += fs * f * if style.bold { 1.06 } else { 1.0 };
    }
    w = w * style.scale_x / 100.0 + style.spacing * text.chars().count() as f64;
    (w, fs * style.scale_y / 100.0, fs * 0.2, 0.0)
}

//! Flattened file view as exposed to Aegisub scripts, and Lua table conversion.
use mlua::{Lua, Result, Table, Value};

use osiosub_core::color::Color;

#[derive(Clone, Debug)]
pub enum Line {
    Info(String, String),
    Style(Style),
    Event(Event),
}

pub fn flatten(f: &AssFile) -> Vec<Line> {
    let mut v = Vec::with_capacity(f.info.len() + f.styles.len() + f.events.len());
    for (k, val) in &f.info { v.push(Line::Info(k.clone(), val.clone())); }
    for s in &f.styles { v.push(Line::Style(s.clone())); }
    for e in &f.events { v.push(Line::Event(e.clone())); }
    v
}

/// Rebuild a file from the flat list, keeping non-script-visible parts of `base`.
pub fn unflatten(lines: &[Line], base: &AssFile) -> AssFile {
    let mut f = AssFile { garbage: base.garbage.clone(), extra: base.extra.clone(), ..Default::default() };
    for l in lines {
        match l {
            Line::Info(k, v) => f.info.push((k.clone(), v.clone())),
            Line::Style(s) => f.styles.push(s.clone()),
            Line::Event(e) => f.events.push(e.clone()),
        }
    }
    f
}

fn col(c: Color) -> String { format!("&H{:08X}&", c.0) }

fn preload(lua: &Lua, name: &str, src: &'static str) -> Result<()> {
    let pkg: Table = lua.globals().get("package")?;
    let pre: Table = pkg.get("preload")?;
    let nm = name.to_string();
    pre.set(name, lua.create_function(move |lua, _: mlua::MultiValue| -> Result<Value> {
        lua.load(src).set_name(format!("={}", nm)).eval::<Value>()
    })?)?;
    Ok(())
}

pub fn install(lua: &Lua) -> Result<()> {
    preload(lua, "util", UTIL)?;
    preload(lua, "aegisub.util", "return require('util')")?;
    preload(lua, "utf8", UTF8)?;
    preload(lua, "aegisub.utf8", "return require('utf8')")?;

    // ---- unicode ----
    let u = lua.create_table()?;
    u.set("len", lua.create_function(|_, s: mlua::String| Ok(String::from_utf8_lossy(&s.as_bytes()).chars().count()))?)?;
    u.set("to_upper", lua.create_function(|_, s: String| Ok(s.to_uppercase()))?)?;
    u.set("to_lower", lua.create_function(|_, s: String| Ok(s.to_lowercase()))?)?;
    u.set("to_fold_case", lua.create_function(|_, s: String| Ok(s.to_lowercase()))?)?;
    u.set("codepoint", lua.create_function(|_, (s, pos): (mlua::String, Option<usize>)| {
        let b = s.as_bytes();
        let p = pos.unwrap_or(1).max(1) - 1;
        Ok(String::from_utf8_lossy(b.get(p..).unwrap_or(&[])).chars().next().map(|c| c as u32).unwrap_or(0))
    })?)?;
    // number of bytes of the UTF-8 character starting at byte position `pos` (1-based)
    u.set("charwidth", lua.create_function(|_, (s, pos): (mlua::String, Option<usize>)| {
        let b = s.as_bytes();
        let p = pos.unwrap_or(1).max(1) - 1;
        Ok(match b.get(p) { Some(&c) if c >= 0xF0 => 4, Some(&c) if c >= 0xE0 => 3, Some(&c) if c >= 0xC0 => 2, Some(_) => 1, None => 0 })
    })?)?;
    u.set("chars", lua.create_function(|lua, s: String| {
        let v: Vec<String> = s.chars().map(|c| c.to_string()).collect();
        let mut i = 0usize;
        lua.create_function_mut(move |_, ()| { i += 1; Ok(v.get(i - 1).cloned()) })
    })?)?;
    lua.globals().set("unicode", u)?;

    // ---- re (Boost.Regex-like subset on top of Rust regex) ----
    let re = lua.create_table()?;
    fn flags(f: Option<Value>) -> (bool, bool) {
        // returns (ignore_case, extended); flags: re.ICASE=1, re.NOSUB, re.EXTENDED...
        match f { Some(Value::Integer(i)) => (i & 1 != 0, i & 2 != 0), Some(Value::Number(n)) => ((n as i64) & 1 != 0, (n as i64) & 2 != 0), _ => (false, false) }
    }
    fn build(pat: &str, f: Option<Value>) -> std::result::Result<regex::Regex, mlua::Error> {
        let (ic, ext) = flags(f);
        RegexBuilder::new(pat).case_insensitive(ic).ignore_whitespace(ext).build().map_err(|e| mlua::Error::runtime(e.to_string()))
    }
    re.set("ICASE", 1)?; re.set("NOSUB", 4)?; re.set("EXTENDED", 2)?; re.set("NO_MOD_M", 0)?;
    re.set("find", lua.create_function(|lua, (s, pat, f): (String, String, Option<Value>)| {
        let r = build(&pat, f)?;
        let out = lua.create_table()?;
        let mut n = 0;
        for c in r.captures_iter(&s) {
            let m = c.get(0).unwrap();
            let t = lua.create_table()?;
            t.set("str", m.as_str())?; t.set("first", s[..m.start()].chars().count() + 1)?; t.set("last", s[..m.end()].chars().count())?;
            n += 1; out.set(n, t)?;
            for g in 1..c.len() {
                if let Some(g) = c.get(g) {
                    let t = lua.create_table()?;
                    t.set("str", g.as_str())?; t.set("first", s[..g.start()].chars().count() + 1)?; t.set("last", s[..g.end()].chars().count())?;
                    n += 1; out.set(n, t)?;
                }
            }
            // Aegisub's re.find returns only the first match with sub-captures following; stop at first
            break;
        }
        Ok(if n == 0 { Value::Nil } else { Value::Table(out) })
    })?)?;
    re.set("match", lua.create_function(|lua, (s, pat, f): (String, String, Option<Value>)| {
        let r = build(&pat, f)?;
        let out = lua.create_table()?;
        let mut n = 0;
        if let Some(c) = r.captures(&s) {
            for g in 0..c.len() {
                if let Some(g) = c.get(g) {
                    let t = lua.create_table()?;
                    t.set("str", g.as_str())?; t.set("first", s[..g.start()].chars().count() + 1)?; t.set("last", s[..g.end()].chars().count())?;
                    n += 1; out.set(n, t)?;
                }
            }
        }
        Ok(if n == 0 { Value::Nil } else { Value::Table(out) })
    })?)?;
    re.set("sub", lua.create_function(|_, (s, pat, rep, count, f): (String, String, String, Option<i64>, Option<Value>)| {
        let r = build(&pat, f)?;
        // convert Boost/ECMAScript style \1 and $1 -> ${1}
        let conv = regex::Regex::new(r"\\(\d)").unwrap().replace_all(&rep, "$${$1}").into_owned();
        let limit = count.unwrap_or(0).max(0) as usize;
        Ok(r.replacen(&s, limit, conv.as_str()).into_owned())
    })?)?;
    re.set("gsub", lua.create_function(|_, (s, pat, rep, f): (String, String, String, Option<Value>)| {
        let r = build(&pat, f)?;
        let conv = regex::Regex::new(r"\\(\d)").unwrap().replace_all(&rep, "$${$1}").into_owned();
        Ok(r.replace_all(&s, conv.as_str()).into_owned())
    })?)?;
    re.set("split", lua.create_function(|lua, (s, pat): (String, String)| {
        let r = build(&pat, None)?;
        let t = lua.create_table()?;
        for (i, p) in r.split(&s).enumerate() { t.set(i + 1, p)?; }
        Ok(t)
    })?)?;
    lua.globals().set("re", re)?;
    // make `require "re"` / `require "unicode"` work like in Aegisub
    let pkg: Table = lua.globals().get("package")?;
    let loaded: Table = pkg.get("loaded")?;
    loaded.set("re", lua.globals().get::<Value>("re")?)?;
    loaded.set("unicode", lua.globals().get::<Value>("unicode")?)?;
    loaded.set("aegisub.unicode", lua.globals().get::<Value>("unicode")?)?;
    loaded.set("aegisub.re", lua.globals().get::<Value>("re")?)?;
    // clipboard module backed by aegisub.clipboard
    lua.load("package.loaded['aegisub.clipboard'] = aegisub.clipboard").exec()?;
    let _: Option<Function> = None;
    lua.load("utf8 = require('utf8')").exec()?;

-- aegisub.parse_karaoke_data(line): syllable table indexed from 0 (0 = text before the first \k tag)
function aegisub.parse_karaoke_data(line)
  local text, out, idx, t0 = line.text, {}, 0, 0
  local cur = { text = "", dur = 0, tag = "k" }
  local function push()
    local plain = cur.text:gsub("%b{}", "")
    local d = cur.dur * 10
    out[idx] = { duration = d, start_time = t0, end_time = t0 + d, tag = cur.tag, text = cur.text, text_stripped = plain }
    idx = idx + 1; t0 = t0 + d
  end
  local pos = 1
  while true do
    local bs, be = text:find("%b{}", pos)
    if not bs then cur.text = cur.text .. text:sub(pos); break end
    cur.text = cur.text .. text:sub(pos, bs - 1)
    local block = text:sub(bs, be)
    local a, b, tag, dur = block:find("\\([kK][fo]?)(%d+)")
    if a then
      push()
      local rest = block:sub(1, a - 1) .. block:sub(b + 1)
      cur = { text = (rest == "{}") and "" or rest, dur = tonumber(dur), tag = tag:lower() }
    else
      cur.text = cur.text .. block
    end
    pos = be + 1
  end
  push()
  return out
end
"#).exec()?;
    // Aegisub's `subs` honours ipairs (LuaJIT/5.2 semantics); stock Lua 5.1 does not.
    lua.load(r#"
local _ipairs = ipairs
function ipairs(t)
  if type(t) == "userdata" then
    return function(o, i) i = i + 1; if i <= #o then return i, o[i] end end, t, 0
  end
  return _ipairs(t)
end
"#).exec()?;
    Ok(())
}

fn idx(v: &Value) -> Option<i64> {
    match v { Value::Integer(i) => Some(*i as i64), Value::Number(n) => Some(*n as i64), _ => None }
}

impl UserData for Subs {
    fn add_methods<M: UserDataMethods<Self>>(m: &mut M) {
        m.add_meta_method(MetaMethod::Len, |_, this, ()| Ok(this.0.borrow().lines.len()));
        m.add_meta_method(MetaMethod::Index, |lua, this, key: Value| -> LResult<Value> {
            if let Some(i) = idx(&key) {
                let sh = this.0.borrow();
                if i < 1 || i as usize > sh.lines.len() { return Err(mlua::Error::runtime(format!("Requested out-of-range line from subs file: {}", i))); }
                return Ok(Value::Table(to_table(lua, &sh.lines[i as usize - 1])?));
            }
            let name = match &key { Value::String(s) => s.to_str()?.to_string(), _ => return Ok(Value::Nil) };
            let rc = this.0.clone();
            let f: Function = match name.as_str() {
                "n" => return Ok(Value::Integer(this.0.borrow().lines.len() as _)),
                "append" => lua.create_function(move |_, args: Variadic<Table>| {
                    let mut sh = rc.borrow_mut();
                    for t in args.iter() { sh.lines.push(from_table(t)?); }
                    Ok(())
                })?,
                "insert" => lua.create_function(move |_, (at, args): (i64, Variadic<Table>)| {
                    let mut sh = rc.borrow_mut();
                    let mut pos = (at.max(1) as usize - 1).min(sh.lines.len());
                    for t in args.iter() { let l = from_table(t)?; sh.lines.insert(pos, l); pos += 1; }
                    Ok(())
                })?,
                "delete" => lua.create_function(move |_, args: Variadic<i64>| {
                    let mut sh = rc.borrow_mut();
                    let mut v: Vec<i64> = args.iter().cloned().collect();
                    v.sort_unstable(); v.dedup();
                    for i in v.into_iter().rev() {
                        if i >= 1 && (i as usize) <= sh.lines.len() { sh.lines.remove(i as usize - 1); }
                    }
                    Ok(())
                })?,
                "deleterange" => lua.create_function(move |_, (a, b): (i64, i64)| {
                    let mut sh = rc.borrow_mut();
                    let (a, b) = (a.max(1) as usize, (b.max(0) as usize).min(sh.lines.len()));
                    if a <= b { sh.lines.drain(a - 1..b); }
                    Ok(())
                })?,
                "script_resolution" => lua.create_function(move |_, ()| {
                    let sh = rc.borrow();
                    let mut x: Option<i32> = None; let mut y: Option<i32> = None;
                    for l in &sh.lines { if let Line::Info(k, v) = l {
                        if k.eq_ignore_ascii_case("PlayResX") { x = v.trim().parse().ok(); }
                        if k.eq_ignore_ascii_case("PlayResY") { y = v.trim().parse().ok(); }
                    } }
                    Ok(match (x, y) { (Some(x), Some(y)) => (x, y), (Some(x), None) => (x, x * 3 / 4), (None, Some(y)) => (y * 4 / 3, y), _ => (384, 288) })
                })?,
                "SetUndoPoint" => lua.create_function(|_, _: MultiValue| Ok(()))?,
                _ => return Ok(Value::Nil),
            };
            Ok(Value::Function(f))
        });
        m.add_meta_method(MetaMethod::NewIndex, |_, this, (key, val): (Value, Value)| {
            let Some(i) = idx(&key) else { return Err(mlua::Error::runtime("subs: integer index expected")) };
            let mut sh = this.0.borrow_mut();
            if let Value::Table(t) = val {
                let l = from_table(&t)?;
                if i >= 1 && (i as usize) <= sh.lines.len() { sh.lines[i as usize - 1] = l; }
                else if i == 0 || i as usize == sh.lines.len() + 1 { sh.lines.push(l); }                                // subs[0] = line : append
                else if i < 0 {                                                      // subs[-n] = line : insert before n
                    let p = ((-i) as usize - 1).min(sh.lines.len());
                    sh.lines.insert(p, l);
                } else { return Err(mlua::Error::runtime(format!("subs: line {} out of range", i))); }
            } else if i >= 1 && (i as usize) <= sh.lines.len() {
                sh.lines.remove(i as usize - 1);                                    // subs[i] = nil : delete
            }
            Ok(())
        });
    }
}

fn dlg_val(v: &Value) -> Option<DlgVal> {
    Some(match v {
        Value::Boolean(b) => DlgVal::Bool(*b),
        Value::Integer(i) => DlgVal::Num(*i as f64),
        Value::Number(n) => DlgVal::Num(*n),
        Value::String(s) => DlgVal::Str(s.to_str().ok()?.to_string()),
        _ => return None,
    })
}
fn parse_dialog(cfg: &Table, buttons: Option<Table>) -> LResult<DialogSpec> {
    let mut spec = DialogSpec::default();
    for pair in cfg.sequence_values::<Table>() {
        let t = pair?;
        let g = |k: &str| -> Option<String> { match t.get::<Value>(k).ok()? { Value::String(s) => Some(s.to_str().ok()?.to_string()), Value::Integer(i) => Some(i.to_string()), Value::Number(n) => Some(n.to_string()), _ => None } };
        let gn = |k: &str| -> Option<f64> { match t.get::<Value>(k).ok()? { Value::Integer(i) => Some(i as f64), Value::Number(n) => Some(n), _ => None } };
        let mut c = DialogControl {
            class: g("class").unwrap_or_default(), name: g("name").unwrap_or_default(),
            x: gn("x").unwrap_or(0.0) as i32, y: gn("y").unwrap_or(0.0) as i32,
            width: gn("width").unwrap_or(1.0) as i32, height: gn("height").unwrap_or(1.0) as i32,
            label: g("label").unwrap_or_default(), text: g("text").unwrap_or_default(), hint: g("hint").unwrap_or_default(),
            min: gn("min"), max: gn("max"), step: gn("step"), ..Default::default()
        };
        if let Ok(Value::Table(items)) = t.get::<Value>("items") {
            for s in items.sequence_values::<String>() { c.items.push(s?); }
        }
        let val = t.get::<Value>("value")?;
        c.value = dlg_val(&val);
        if c.class == "dropdown" && c.value.is_none() { c.value = None; }
        if matches!(c.class.as_str(), "edit" | "textbox") && c.value.is_none() { c.value = Some(DlgVal::Str(c.text.clone())); }
        spec.controls.push(c);
    }
    spec.buttons = match buttons {
        Some(b) => b.sequence_values::<String>().collect::<LResult<Vec<_>>>()?,
        None => vec!["OK".into(), "Cancel".into()],
    };
    Ok(spec)
}

impl ScriptRuntime {
    pub fn new(host: Box<dyn Host>) -> LResult<Self> {
        let lua = Lua::new();
        let sh = Rc::new(RefCell::new(Shared {
            lines: vec![], base: AssFile::default(), host, log: String::new(), entries: vec![],
            cur_script: String::new(), cancel_flag: false, props: (0.0, 0.0),
        }));
        let rt = ScriptRuntime { lua, sh, script_dirs: vec![] };
        rt.install()?;
        Ok(rt)
    }

    fn install(&self) -> LResult<()> {
        let lua = &self.lua;
        let g = lua.globals();
        let au = lua.create_table()?;
        let sh = self.sh.clone();

        // register_macro(name, description, process, validate, is_active)
        {
            let sh = sh.clone();
            au.set("register_macro", lua.create_function(move |lua, (name, desc, process, validate, active): (String, Option<String>, Function, Option<Function>, Option<Function>)| {
                let mut s = sh.borrow_mut();
                let script = s.cur_script.clone();
                s.entries.push(Entry {
                    info: MacroInfo { name, description: desc.unwrap_or_default(), kind: Kind::Macro, script },
                    process: lua.create_registry_value(process)?,
                    validate: validate.map(|f| lua.create_registry_value(f)).transpose()?,
                    is_active: active.map(|f| lua.create_registry_value(f)).transpose()?,
                });
                Ok(())
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("register_filter", lua.create_function(move |lua, (name, desc, _prio, process, _cfg): (String, Option<String>, Option<i64>, Function, Option<Function>)| {
                let mut s = sh.borrow_mut();
                let script = s.cur_script.clone();
                s.entries.push(Entry {
                    info: MacroInfo { name, description: desc.unwrap_or_default(), kind: Kind::Filter, script },
                    process: lua.create_registry_value(process)?, validate: None, is_active: None,
                });
                Ok(())
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("cancel", lua.create_function(move |_, ()| -> LResult<()> {
                sh.borrow_mut().cancel_flag = true;
                Err(mlua::Error::runtime("__aegisub_cancel__"))
            })?)?;
        }
        // log([level,] fmt, ...)
        let logf = {
            let sh = sh.clone();
            lua.create_function(move |lua, args: MultiValue| {
                let mut v: Vec<Value> = args.into_iter().collect();
                if matches!(v.first(), Some(Value::Integer(_)) | Some(Value::Number(_))) && v.len() >= 2 { v.remove(0); }
                let fmt: Function = lua.globals().get::<Table>("string")?.get("format")?;
                let s: String = if v.len() > 1 { fmt.call(MultiValue::from_iter(v))? } else {
                    match v.first() { Some(Value::String(s)) => s.to_str()?.to_string(), Some(Value::Integer(i)) => i.to_string(), Some(Value::Number(n)) => n.to_string(), _ => String::new() }
                };
                let mut sh = sh.borrow_mut();
                sh.log.push_str(&s);
                sh.host.log(&s);
                Ok(())
            })?
        };
        au.set("log", logf.clone())?;
        let dbg = lua.create_table()?;
        dbg.set("out", logf)?;
        au.set("debug", dbg)?;

        // progress
        let pr = lua.create_table()?;
        for name in ["set", "task", "title"] {
            let sh = sh.clone();
            let n = name.to_string();
            pr.set(name, lua.create_function(move |_, a: MultiValue| {
                let mut s = sh.borrow_mut();
                match (n.as_str(), a.iter().next()) {
                    ("set", Some(Value::Number(p))) => s.host.progress(*p, "", ""),
                    ("set", Some(Value::Integer(p))) => s.host.progress(*p as f64, "", ""),
                    ("task", Some(Value::String(t))) => { let t = t.to_str()?.to_string(); s.host.progress(-1.0, &t, "") }
                    ("title", Some(Value::String(t))) => { let t = t.to_str()?.to_string(); s.host.progress(-1.0, "", &t) }
                    _ => {}
                }
                Ok(())
            })?)?;
        }
        pr.set("is_cancelled", lua.create_function(|_, ()| Ok(false))?)?;
        au.set("progress", pr)?;

        // dialog
        let dl = lua.create_table()?;
        {
            let sh = sh.clone();
            dl.set("display", lua.create_function(move |lua, (cfg, buttons, _ids): (Table, Option<Table>, Option<Table>)| {
                let spec = parse_dialog(&cfg, buttons)?;
                let res = sh.borrow_mut().host.dialog(&spec);
                let out = lua.create_table()?;
                for (k, v) in &res.values {
                    match v {
                        DlgVal::Str(s) => out.set(k.as_str(), s.as_str())?,
                        DlgVal::Num(n) => out.set(k.as_str(), *n)?,
                        DlgVal::Bool(b) => out.set(k.as_str(), *b)?,
                    }
                }
                let btn: Value = match res.button { Some(b) => Value::String(lua.create_string(&b)?), None => Value::Boolean(false) };
                Ok((btn, out))
            })?)?;
        }
        dl.set("open", lua.create_function(|_, _: MultiValue| Ok(Value::Nil))?)?;
        dl.set("save", lua.create_function(|_, _: MultiValue| Ok(Value::Nil))?)?;
        au.set("dialog", dl)?;

        // text_extents(style_table, text)
        {
            let sh = sh.clone();
            au.set("text_extents", lua.create_function(move |_, (st, text): (Table, String)| {
                let style = match from_table(&{ st.set("class", "style")?; st })? { Line::Style(s) => s, _ => unreachable!() };
                let (w, h, d, e) = sh.borrow().host.text_extents(&style, &text);
                Ok((w, h, d, e))
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("video_size", lua.create_function(move |_, ()| {
                Ok(match sh.borrow().host.video_size() { Some((w, h)) => (Some(w), Some(h), Some(0), Some(1)), None => (None, None, None, None) })
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("frame_from_ms", lua.create_function(move |_, ms: f64| {
                Ok(sh.borrow().host.fps().map(|f| osiosub_core::time::FrameRate::new(f).frame_from_ms(ms as i64)))
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("ms_from_frame", lua.create_function(move |_, fr: f64| {
                Ok(sh.borrow().host.fps().map(|f| osiosub_core::time::FrameRate::new(f).ms_from_frame(fr as i64)))
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("keyframes", lua.create_function(move |lua, ()| {
                let t = lua.create_table()?;
                for (i, k) in sh.borrow().host.keyframes().iter().enumerate() { t.set(i + 1, *k)?; }
                Ok(t)
            })?)?;
        }
        {
            let sh = sh.clone();
            au.set("project_properties", lua.create_function(move |lua, ()| {
                let t = lua.create_table()?;
                let s = sh.borrow();
                let (rx, ry) = s.base.play_res();
                t.set("video_zoom", 1.0)?; t.set("ar_mode", 0)?; t.set("ar_value", 0.0)?;
                t.set("script_resolution_x", rx)?; t.set("script_resolution_y", ry)?;
                t.set("automation_scripts", "")?; t.set("export_encoding", "UTF-8")?;
                let _ = s.props;
                Ok(t)
            })?)?;
        }
        au.set("decode_path", lua.create_function(|_, p: String| Ok(p.replace("?user", ".").replace("?data", ".").replace("?temp", "/tmp")))?)?;
        au.set("file_name", lua.create_function(|_, ()| Ok(Value::Nil))?)?;
        au.set("lua_supported_version", lua.create_function(|_, _: MultiValue| Ok(true))?)?;
        au.set("gettext", lua.create_function(|_, s: String| Ok(s))?)?;
        au.set("get_audio_selection", lua.create_function(|_, ()| Ok(Value::Nil))?)?;
        au.set("set_undo_point", lua.create_function(|_, _: MultiValue| Ok(()))?)?;

            cb.set("get", lua.create_function(move |_, ()| Ok(sh2.borrow().host.clipboard_get()))?)?;
            cb.set("set", lua.create_function(move |_, s: String| Ok(sh.borrow_mut().host.clipboard_set(&s)))?)?;
            au.set("clipboard", cb)?;
        }
        g.set("aegisub", au)?;
        g.set("tr", lua.create_function(|_, s: String| Ok(s))?)?;
        modules::install(lua)?;

        // include(name): script dirs (package.path), then the bundled unmodified Aegisub include files
        let include = lua.create_function(move |lua, name: String| -> LResult<MultiValue> {
            let pkg: Table = lua.globals().get("package")?;
            let path: String = pkg.get("path")?;
            let base = name.strip_suffix(".lua").unwrap_or(&name).to_string();
            let mut src: Option<(String, String)> = None;
            for pat in path.split(';') {
                if pat.is_empty() { continue; }
                let cand = pat.replace('?', &base.replace('.', "/"));
                if let Ok(bytes) = std::fs::read(&cand) { src = Some((cand, String::from_utf8_lossy(&bytes).trim_start_matches('\u{feff}').to_string())); break; }
            }
            if src.is_none() {
                if let Some(e) = modules::embedded_include(&format!("{}.lua", base)) { src = Some((format!("{}.lua", base), e.trim_start_matches('\u{feff}').to_string())); }
            }
            let Some((chunk, code)) = src else { return Err(mlua::Error::runtime(format!("Lua include not found: {}", name))) };
            lua.load(code).set_name(format!("@{}", chunk)).call::<MultiValue>(())
        })?;
        g.set("include", include)?;
        Ok(())
    }

    fn set_search_path(&self, extra: &Path) -> LResult<()> {
        let pkg: Table = self.lua.globals().get("package")?;
        let mut p = String::new();
        let mut dirs = vec![extra.to_path_buf()];
        dirs.extend(self.script_dirs.iter().cloned());
        for d in dirs {
            let d = d.to_string_lossy().replace('\\', "/");
            p.push_str(&format!("{d}/?.lua;{d}/?/init.lua;{d}/?/?.lua;"));
        }
        let old: String = pkg.get("path")?;
        pkg.set("path", format!("{}{}", p, old))
    }

    /// Load a .lua/.moon-free script file and register its macros. Returns names registered.
    pub fn load_file(&mut self, path: &Path) -> Result<Vec<MacroInfo>, String> {
        let src = std::fs::read(path).map_err(|e| format!("{}: {}", path.display(), e))?;
        let src = String::from_utf8_lossy(&src).trim_start_matches('\u{feff}').to_string();
        let dir = path.parent().unwrap_or(Path::new(".")).to_path_buf();
        self.set_search_path(&dir).map_err(|e| e.to_string())?;
        self.load_source(&src, &path.to_string_lossy())
    }

    pub fn load_source(&mut self, src: &str, chunk: &str) -> Result<Vec<MacroInfo>, String> {
        let before = self.sh.borrow().entries.len();
        self.sh.borrow_mut().cur_script = chunk.to_string();
        // Make `include`d module state fresh per script is not required; globals like script_name are read after exec.
        self.lua.load(src).set_name(format!("@{}", chunk)).exec().map_err(|e| e.to_string())?;
        let s = self.sh.borrow();
        Ok(s.entries[before..].iter().map(|e| e.info.clone()).collect())
    }

    pub fn macros(&self) -> Vec<MacroInfo> { self.sh.borrow().entries.iter().map(|e| e.info.clone()).collect() }

    fn sync_in(&self, file: &AssFile) {
        let mut s = self.sh.borrow_mut();
        s.lines = flatten(file);
        s.base = file.clone();
        s.log.clear();
        s.cancel_flag = false;
    }

    fn to_sub_index(file: &AssFile, ev: usize) -> i64 { (file.info.len() + file.styles.len() + ev + 1) as i64 }

    pub fn validate(&self, i: usize, file: &AssFile, selection: &[usize], active: usize) -> bool {
        self.sync_in(file);
        let sh = self.sh.borrow();
        let Some(e) = sh.entries.get(i) else { return false };
        let Some(vk) = &e.validate else { return true };
        let Ok(f) = self.lua.registry_value::<Function>(vk) else { return true };
        let subs = match self.lua.create_userdata(Subs(self.sh.clone())) { Ok(s) => s, Err(_) => return true };
        let sel = self.lua.create_sequence_from(selection.iter().map(|&x| Self::to_sub_index(file, x))).unwrap();
        drop(sh);
        f.call::<bool>((subs, sel, Self::to_sub_index(file, active))).unwrap_or(true)
    }

    /// Run macro `i` against `file`. `selection`/`active` are 0-based event indices.
    pub fn run(&self, i: usize, file: &AssFile, selection: &[usize], active: usize) -> MacroResult {
        self.sync_in(file);
        let mut res = MacroResult::default();
        let (pk, kind) = {
            let sh = self.sh.borrow();
            match sh.entries.get(i) { Some(e) => (self.lua.registry_value::<Function>(&e.process), e.info.kind), None => { res.error = Some("no such macro".into()); return res; } }
        };
        let f = match pk { Ok(f) => f, Err(e) => { res.error = Some(e.to_string()); return res; } };
        let subs = match self.lua.create_userdata(Subs(self.sh.clone())) { Ok(s) => s, Err(e) => { res.error = Some(e.to_string()); return res; } };
        let n_head = file.info.len() + file.styles.len();
        let sel: Vec<i64> = selection.iter().map(|&x| Self::to_sub_index(file, x)).collect();
        let sel_t = self.lua.create_sequence_from(sel).unwrap();
        let ret: LResult<MultiValue> = match kind {
            Kind::Macro => f.call((subs.clone(), sel_t, Self::to_sub_index(file, active))),
            Kind::Filter => {
                let cfg = self.lua.create_table().unwrap();
                f.call((subs.clone(), cfg))
            }
        };
        match ret {
            Ok(vals) => {
                let mut it = vals.into_iter();
                if let Some(Value::Table(t)) = it.next() {
                    let sel: Vec<usize> = t.sequence_values::<i64>().filter_map(|v| v.ok()).filter(|&v| v as usize > n_head).map(|v| v as usize - n_head - 1).collect();
                    res.selection = Some(sel);
                    if let Some(a) = it.next().as_ref().and_then(idx) { if a as usize > n_head { res.active = Some(a as usize - n_head - 1); } }
                }
            }
            Err(e) => {
                let msg = e.to_string();
                if msg.contains("__aegisub_cancel__") || self.sh.borrow().cancel_flag { res.cancelled = true; }
                else { res.error = Some(msg); }
            }
        }
        let sh = self.sh.borrow();
        res.log = sh.log.clone();
        if !res.cancelled && res.error.is_none() {
            let mut out = unflatten(&sh.lines, &sh.base);
            // an empty style list would be invalid
            if out.styles.is_empty() { out.styles.push(Default::default()); }
            res.file = Some(out);
        }
        res
    }

    /// Evaluate a snippet (for tests / REPL).
    pub fn eval_string(&self, code: &str) -> Result<String, String> {
        let v: Value = self.lua.load(code).eval().map_err(|e| e.to_string())?;
        Ok(match v { Value::String(s) => s.to_str().map(|s| s.to_string()).unwrap_or_default(), Value::Integer(i) => i.to_string(), Value::Number(n) => n.to_string(), Value::Boolean(b) => b.to_string(), Value::Nil => "nil".into(), _ => format!("{:?}", v) })
    }
}

//! Audio decoding to waveform peaks (pure Rust via symphonia; ffmpeg fallback when installed).
use std::fs::File;
use std::path::Path;
use symphonia::core::audio::SampleBuffer;
use symphonia::core::codecs::DecoderOptions;
use symphonia::core::errors::Error as SymErr;
use symphonia::core::formats::FormatOptions;
use symphonia::core::io::MediaSourceStream;
use symphonia::core::meta::MetadataOptions;
use symphonia::core::probe::Hint;

/// Peak envelope with a fixed resolution of `PEAKS_PER_SEC` buckets per second.
#[derive(Clone, Debug, Default)]
pub struct AudioPeaks {
    pub sample_rate: u32,
    pub min: Vec<f32>,
    pub max: Vec<f32>,
}

pub const PEAKS_PER_SEC: usize = 200; // 5 ms buckets

impl AudioPeaks {
    pub fn duration_ms(&self) -> i64 { (self.min.len() * 1000 / PEAKS_PER_SEC) as i64 }
    /// (min,max) over [start_ms, end_ms)
    pub fn range(&self, start_ms: i64, end_ms: i64) -> (f32, f32) {
        let a = ((start_ms.max(0) as usize) * PEAKS_PER_SEC / 1000).min(self.min.len());
        let b = (((end_ms.max(0) as usize) * PEAKS_PER_SEC + 999) / 1000).clamp(a, self.min.len());
        let mut lo = 0f32; let mut hi = 0f32;
        for i in a..b { lo = lo.min(self.min[i]); hi = hi.max(self.max[i]); }
        (lo, hi)
    }
}

struct Acc { rate: u32, per_bucket: f64, pos: f64, cur_min: f32, cur_max: f32, out: AudioPeaks, have: bool }
impl Acc {
    fn new(rate: u32) -> Self { Acc { rate, per_bucket: rate as f64 / PEAKS_PER_SEC as f64, pos: 0.0, cur_min: 0.0, cur_max: 0.0, out: AudioPeaks { sample_rate: rate, ..Default::default() }, have: false } }
    fn push(&mut self, v: f32) {
        self.cur_min = self.cur_min.min(v); self.cur_max = self.cur_max.max(v); self.have = true;
        self.pos += 1.0;
        if self.pos >= self.per_bucket {
            self.pos -= self.per_bucket;
            self.out.min.push(self.cur_min); self.out.max.push(self.cur_max);
            self.cur_min = 0.0; self.cur_max = 0.0; self.have = false;
        }
    }
    fn finish(mut self) -> AudioPeaks { if self.have { self.out.min.push(self.cur_min); self.out.max.push(self.cur_max); } let _ = self.rate; self.out }
}

pub fn decode_peaks(path: &Path, progress: &mut dyn FnMut(f32)) -> Result<AudioPeaks, String> {
    let file = File::open(path).map_err(|e| format!("{}: {e}", path.display()))?;
    let mss = MediaSourceStream::new(Box::new(file), Default::default());
    let mut hint = Hint::new();
    if let Some(ext) = path.extension().and_then(|e| e.to_str()) { hint.with_extension(ext); }
    let probed = symphonia::default::get_probe().format(&hint, mss, &FormatOptions::default(), &MetadataOptions::default()).map_err(|e| format!("format: {e}"))?;
    let mut format = probed.format;
    let track = format.tracks().iter().find(|t| t.codec_params.codec != symphonia::core::codecs::CODEC_TYPE_NULL).ok_or("no audio track")?.clone();
    let mut decoder = symphonia::default::get_codecs().make(&track.codec_params, &DecoderOptions::default()).map_err(|e| format!("codec: {e}"))?;
    let rate = track.codec_params.sample_rate.ok_or("unknown sample rate")?;
    let total = track.codec_params.n_frames;
    let mut acc = Acc::new(rate);
    let mut buf: Option<SampleBuffer<f32>> = None;
    let mut done = 0u64;
    loop {
        let packet = match format.next_packet() {
            Ok(p) => p,
            Err(SymErr::IoError(_)) | Err(SymErr::ResetRequired) => break,
            Err(e) => return Err(e.to_string()),
        };
        if packet.track_id() != track.id { continue; }
        match decoder.decode(&packet) {
            Ok(decoded) => {
                let spec = *decoded.spec();
                let ch = spec.channels.count().max(1);
                if buf.as_ref().map_or(true, |b| b.capacity() < decoded.capacity() * ch) { buf = Some(SampleBuffer::new(decoded.capacity() as u64, spec)); }
                let b = buf.as_mut().unwrap();
                b.copy_interleaved_ref(decoded);
                for frame in b.samples().chunks(ch) { acc.push(frame.iter().sum::<f32>() / ch as f32); }
                done += (b.samples().len() / ch) as u64;
                if let Some(t) = total { if done % 65536 < 4096 { progress((done as f32 / t as f32).min(1.0)); } }
            }
            Err(SymErr::DecodeError(_)) => continue,
            Err(e) => return Err(e.to_string()),
        }
    }
    progress(1.0);
    Ok(acc.finish())
}

/// Synthetic peaks for tests / demos.
pub fn synth(seconds: usize) -> AudioPeaks {
    let n = seconds * PEAKS_PER_SEC;
    let mut p = AudioPeaks { sample_rate: 48000, ..Default::default() };
    for i in 0..n {
        let t = i as f32 / PEAKS_PER_SEC as f32;
        let env = ((t * 1.3).sin() * 0.5 + 0.5) * (0.4 + 0.6 * ((t * 7.0).sin().abs()));
        p.max.push(env); p.min.push(-env * 0.9);
    }
    p
}

/// Decode via the `ffmpeg` binary (handles Opus/AC3/DTS/any container). Mono 8 kHz is plenty for a waveform.
pub fn decode_peaks_ffmpeg(path: &Path) -> Result<AudioPeaks, String> {
    use std::io::Read;
    use std::process::{Command, Stdio};
    let mut child = Command::new("ffmpeg")
        .args(["-v", "error", "-i"]).arg(path)
        .args(["-vn", "-sn", "-ac", "1", "-ar", "8000", "-f", "f32le", "-"])
        .stdout(Stdio::piped()).stderr(Stdio::null()).spawn().map_err(|e| format!("ffmpeg: {e}"))?;
    let mut out = child.stdout.take().unwrap();
    let mut acc = Acc::new(8000);
    let mut buf = vec![0u8; 1 << 16];
    let mut carry: Vec<u8> = Vec::new();
    loop {
        let n = out.read(&mut buf).map_err(|e| e.to_string())?;
        if n == 0 { break; }
        carry.extend_from_slice(&buf[..n]);
        let usable = carry.len() / 4 * 4;
        for c in carry[..usable].chunks_exact(4) { acc.push(f32::from_le_bytes([c[0], c[1], c[2], c[3]])); }
        carry.drain(..usable);
    }
    let _ = child.wait();
    let p = acc.finish();
    if p.min.is_empty() { Err("ffmpeg produced no audio".into()) } else { Ok(p) }
}

/// Best-effort loader: symphonia first, ffmpeg second.
pub fn load_audio(path: &Path, progress: &mut dyn FnMut(f32)) -> Result<AudioPeaks, String> {
    match decode_peaks(path, progress) {
        Ok(p) if !p.min.is_empty() => Ok(p),
        first => decode_peaks_ffmpeg(path).map_err(|e| format!("{} / {}", first.err().unwrap_or_default(), e)),
    }
}

#[derive(Clone, Debug, Default)]
pub struct VideoInfo { pub width: i32, pub height: i32, pub fps: f64, pub duration_ms: i64 }

pub fn probe_video(path: &Path) -> Result<VideoInfo, String> {
    use std::process::Command;
    let out = Command::new("ffprobe")
        .args(["-v", "error", "-select_streams", "v:0", "-show_entries", "stream=width,height,r_frame_rate:format=duration", "-of", "default=nw=1"])
        .arg(path).output().map_err(|e| format!("ffprobe: {e}"))?;
    let s = String::from_utf8_lossy(&out.stdout);
    let mut v = VideoInfo::default();
    for l in s.lines() {
        if let Some((k, val)) = l.split_once('=') {
            match k {
                "width" => v.width = val.trim().parse().unwrap_or(0),
                "height" => v.height = val.trim().parse().unwrap_or(0),
                "r_frame_rate" => { if let Some((a, b)) = val.split_once('/') { let (a, b): (f64, f64) = (a.parse().unwrap_or(0.0), b.parse().unwrap_or(1.0)); if b != 0.0 { v.fps = a / b; } } }
                "duration" => v.duration_ms = (val.trim().parse::<f64>().unwrap_or(0.0) * 1000.0) as i64,
                _ => {}
            }
        }
    }
    if v.width == 0 { return Err("no video stream".into()); }
    Ok(v)
}

/// Render one frame with the subtitles burnt in by libass (through ffmpeg). Returns (w, h, RGBA).
pub fn render_frame(video: &Path, ass_text: &str, at_ms: i64, out_w: i32, src: &VideoInfo, fonts_dir: Option<&Path>) -> Result<(i32, i32, Vec<u8>), String> {
    use std::process::{Command, Stdio};
    use std::io::Read;
    static N: std::sync::atomic::AtomicUsize = std::sync::atomic::AtomicUsize::new(0);
    let n = N.fetch_add(1, std::sync::atomic::Ordering::Relaxed);
    let tmp = std::env::temp_dir().join(format!("osiosub_prev_{}_{}.ass", std::process::id(), n));
    std::fs::write(&tmp, ass_text).map_err(|e| e.to_string())?;
    let out_h = ((src.height as f64 * out_w as f64 / src.width.max(1) as f64) / 2.0).round() as i32 * 2;
    let esc = |p: &Path| p.to_string_lossy().replace('\\', "/").replace(':', "\\:").replace('\'', "\\'");
    let mut vf = format!("ass='{}'", esc(&tmp));
    if let Some(d) = fonts_dir { vf = format!("ass='{}':fontsdir='{}'", esc(&tmp), esc(d)); }
    vf.push_str(&format!(",scale={}:{}", out_w, out_h));
    let ss = format!("{:.3}", at_ms.max(0) as f64 / 1000.0);
    let mut child = Command::new("ffmpeg").args(["-v", "error", "-copyts", "-ss", &ss, "-i"]).arg(video)
        .args(["-vf", &vf, "-frames:v", "1", "-an", "-sn", "-f", "rawvideo", "-pix_fmt", "rgba", "-"])
        .stdout(Stdio::piped()).stderr(Stdio::piped()).spawn().map_err(|e| format!("ffmpeg: {e}"))?;
    let mut buf = Vec::new();
    child.stdout.take().unwrap().read_to_end(&mut buf).map_err(|e| e.to_string())?;
    let mut err = String::new();
    if let Some(mut e) = child.stderr.take() { let _ = e.read_to_string(&mut err); }
    let _ = child.wait();
    let _ = std::fs::remove_file(&tmp);
    if buf.len() < (out_w * out_h * 4) as usize { return Err(format!("no frame ({})", err.lines().next().unwrap_or(""))); }
    buf.truncate((out_w * out_h * 4) as usize);
    Ok((out_w, out_h, buf))
}
