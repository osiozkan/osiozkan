# Osisub kullanım kılavuzu

## Kurulum
```
pip install -e .          # lupa, PySide6-Essentials, numpy, spylls
sudo apt install ffmpeg hunspell-tr   # video/ses/önizleme ve Türkçe yazım denetimi (isteğe bağlı ama önerilir)
osisub-gui dosya.ass      # veya: python -m osisub dosya.ass
```

## Ekran düzeni
Üstte **önizleme** (libass ile gerçek ASS render) ve **düzenleme paneli**, ortada **dalga formu**, altta **satır tablosu**.
Önizleme: seçilen satırın zamanında kare + altyazı. Video açılmamışsa koyu zemin üzerinde çizilir.

## Kısayollar
| Tuş | İş |
|---|---|
| Ctrl+N / O / S / Shift+S | Yeni / Aç / Kaydet / Farklı kaydet (kaydederken `.bak` yedeği alınır; 2 dk'da bir otomatik kayıt `~/.osisub/autosave`) |
| Ctrl+Z / Ctrl+Y | Geri al / Yinele |
| Ctrl+Enter | Satır ekle · Ctrl+D çoğalt · Ctrl+Del sil · Ctrl+M birleştir · Ctrl+B imleçten böl |
| Ctrl+F | Bul/değiştir · Ctrl+G satıra git · Ctrl+Shift+A desene göre seç |
| Ctrl+P | Seçili satırı çal · Ctrl+Space videoyu oynat/durdur · Esc durdur |
| Alt+←/→ | Bir kare geri/ileri |
| Ctrl+1 / Ctrl+2 | Başlangıç / bitişi oynatma konumuna ata · Ctrl+3 bitişi ata ve sonraki satıra geç |
| Ctrl+L | Önizlemede etkileşim (typesetting) aç/kapat |
| F7 | Kalite kontrol (CPS, satır uzunluğu, çakışma, süre, stil, etiket) · F8 yazım denetimi |

## Dalga formu
Fare tekeri: kaydır · Ctrl+tekerlek: yakınlaştır · tıkla: konum · aktif satırın sarı sınırlarını sürükle: zamanlama ·
karaoke satırında turkuaz hece sınırlarını sürükle: `\k` süreleri (toplam sabit kalır). Yeşil kesik çizgiler anahtar karelerdir.

## Typesetting
Typesetting menüsünden mod seç (`\pos`, `\org`, `\move` iki tıklama, `\clip`/`\iclip` sürükle), önizlemede tıkla/sürükle;
etiket satırın ilk bloğuna yazılır.

## Lua otomasyonu (Aegisub uyumlu)
Betikler `~/.osisub/automation/autoload`, `~/.aegisub/automation/autoload`, `./automation/autoload` ve Tercihler'deki ek
klasörden yüklenir; include klasörleri aynı mantıkla (`include("karaskel.lua")`, `require "ILL.ILL"` vb.). Otomasyon menüsünden
çalıştırın; diyaloglar Qt formu olarak açılır, ilerleme penceresi iptal destekler. Komut satırı:
```
osisub macros betik.lua
osisub run betik.lua giris.ass -o cikis.ass -m 0 -s 1-5
```
Gerçek Aegisub `kara-templater`, `cleantags`, `strip-tags` betikleri değiştirilmeden çalışır.

## Diğer
Çözünürlük yeniden örnekleme, font denetimi/gömme, stil içe aktarma, zamanlama son işlemcisi, otomatik `\k`, lead-in/out,
İE notlarını silme, bozuk karakter onarımı (`Ã¼`→`ü`), SRT/VTT/TXT dışa aktarım (Farklı kaydet).

# Osisub — proje notları (her gece oturumunun hafızası)

Hedef: Aegisub'ın tüm yeteneklerini + Subtitle Edit'in iyi özelliklerini taşıyan, anime altyazı/typesetting/karaoke
odaklı, Aegisub **Lua otomasyon betikleriyle uyumlu**, hızlı ve kolay arayüzlü bir araç.

> Not: Bu depo (`osiozkan/osiozkan`) GitHub profil deposudur; kök `README.md` profil sayfasıdır ve
> dokunulmaz. Proje dokümanları `docs/` altındadır.

## Mimari
```
osisub/
  core/        ass.py (Document/Style/Event, kayıpsız parse+yaz) · timeutil · tags · tools (zamanlama, metin, QC) · history (undo)
  formats/     SRT / WebVTT / TXT <-> Document, kodlama tespiti (UTF-8/BOM/cp1254…)
  automation/  runtime.py (lupa/LuaJIT) + lua/prelude.lua (aegisub.*, subs proxy, re, unicode, util)
               lua/include/{karaskel,utils,unicode}.lua  → include("karaskel.lua") gerçek Aegisub gibi çalışır
  media.py     ffmpeg/ffprobe: probe, kare yakalama (+libass ile ASS render), ses tepe değerleri, anahtar kareler
  gui/         PySide6: app.py (MainWindow), models, dialogs, widgets (Preview, Waveform)
  cli.py       osisub convert|macros|run|check|shift
tests/         pytest (core, lua, gui[offscreen])
```
Önemli tasarım kararları
- Dahili zaman = tamsayı ms; ASS yazarken centisaniyeye yuvarlanır.
- Lua: **LuaJIT 2.1** (Aegisub ile aynı). `subs` bir `newproxy` userdata'sı: `#subs`, `subs[i]`, `subs[-i]=` (araya ekle),
  `subs.insert/append/delete/deleterange/script_resolution`, `ipairs(subs)` desteklenir. Her betik kendi ortamında (env) çalışır.
- Satır tabloları Aegisub ile aynı alanlar: class/section/start_time/end_time/margin_t/margin_b/text/extra …
  Stil renkleri `color1..4`. Seçim indeksleri global satır numarasıdır (info+style+event, 1-tabanlı).
- Diyaloglar: `Engine.dialog_handler`; GUI'de Qt formu (`AutomationDialog`), başsız modda varsayılanlar ve ilk düğme.
- Önizleme: ffmpeg `ass` filtresi (libass) → gerçek ASS render. Video yoksa koyu zemin üzerine render.
- Gerçek Aegisub `kara-templater.lua`, `cleantags`, `strip-tags` vb. değiştirilmeden çalıştırıldı (uyumluluk testi; telifli
  dosyalar depoda tutulmaz, `tests/` yalnızca kendi betiklerimizi içerir).

-- cleantags.lua: minimal tag cleaner (Osisub). Merges adjacent override blocks and drops empty ones.
function cleantags(text)
  local prev
  repeat
    prev = text
    text = text:gsub("}{", "")
  until text == prev
  text = text:gsub("{}", "")
  return text
end
return cleantags

-- karaskel.lua: karaoke skeleton helpers (Osisub implementation, API compatible with Aegisub's karaskel).
karaskel = karaskel or {}
local karaskel = karaskel

function karaskel.collect_head(subs, generate_furigana)
  local meta = { res_x = 0, res_y = 0, video_x_correct_factor = 1.0 }
  local styles = { n = 0 }
  local toinsert = {}
  local first_style_line
  if not karaskel.furigana_scale then karaskel.furigana_scale = 0.5 end

  for i = 1, #subs do
    if aegisub.progress.is_cancelled() then error("User cancelled") end
    local l = subs[i]
    if l.class == "style" then
      first_style_line = first_style_line or i
      styles.n = styles.n + 1
      styles[styles.n] = l
      styles[l.name] = l
      l.margin_v = l.margin_t
      if generate_furigana and not l.name:match("furigana") then
        local fs = table.copy(l)
        fs.fontsize = l.fontsize * karaskel.furigana_scale
        fs.outline = l.outline * karaskel.furigana_scale
        fs.shadow = l.shadow * karaskel.furigana_scale
        fs.name = l.name .. "-furigana"
        toinsert[#toinsert + 1] = fs
      end
    elseif l.class == "info" then
      meta[l.key:lower()] = l.value
    else
      break
    end
  end
  if not first_style_line then error("Karaskel error: No styles were found in the file, bug?!") end

  for i = 1, #toinsert do
    if not styles[toinsert[i].name] then
      styles.n = styles.n + 1
      styles[styles.n] = toinsert[i]
      styles[toinsert[i].name] = toinsert[i]
      subs[-first_style_line] = toinsert[i]
    end
  end

  meta.res_x, meta.res_y = subs.script_resolution()
  local vx, vy = aegisub.video_size()
  if vy then
    meta.video_x_correct_factor = (vy / vx) / (meta.res_y / meta.res_x)
  end
  return meta, styles
end

function karaskel.preproc_line_text(meta, styles, line)
  local kara = aegisub.parse_karaoke_data(line)
  line.kara = { n = 0 }
  line.furi = { n = 0 }
  line.text_stripped = ""
  line.duration = line.end_time - line.start_time

  local worksyl = { highlights = { n = 0 }, furi = { n = 0 } }
  local cur_inline_fx = ""
  for i = 0, kara.n do
    local syl = kara[i]
    local fx = syl.text:match("%{.*\\%-([^}\\]+)")
    if fx then cur_inline_fx = fx end
    local prespace, syltext, postspace = syl.text_stripped:match("^([ \t]*)(.-)([ \t]*)$")
    local prefix = syltext:sub(1, unicode.charwidth(syltext, 1))
    local is_hl = (prefix == "#" or prefix == "＃")
    if not is_hl and i > 0 then
      line.kara[line.kara.n] = worksyl
      line.kara.n = line.kara.n + 1
      worksyl = { highlights = { n = 0 }, furi = { n = 0 } }
    end
    local hl = { start_time = syl.start_time, end_time = syl.end_time, duration = syl.duration }
    worksyl.highlights.n = worksyl.highlights.n + 1
    worksyl.highlights[worksyl.highlights.n] = hl

    if syltext:find("|", 1, true) or syltext:find("｜", 1, true) then
      syltext = syltext:gsub("｜", "|")
      local maintext, furitext = syltext:match("^(.-)|(.-)$")
      syltext = maintext
      local furi = { syl = worksyl }
      local fp = furitext:sub(1, unicode.charwidth(furitext, 1))
      if fp == "!" or fp == "！" then furi.isbreak, furi.spillback = true, false
      elseif fp == "<" or fp == "＜" then furi.isbreak, furi.spillback = true, true
      else furi.isbreak, furi.spillback = false, false end
      if furi.isbreak then furitext = furitext:sub(unicode.charwidth(furitext, 1) + 1) end
      furi.start_time, furi.end_time, furi.duration = syl.start_time, syl.end_time, syl.duration
      furi.kdur = syl.duration / 10
      furi.text, furi.text_stripped, furi.text_spacestripped = furitext, furitext, furitext
      furi.line, furi.tag, furi.inline_fx = line, syl.tag, cur_inline_fx
      furi.i = line.kara.n
      furi.prespace, furi.postspace = "", ""
      furi.highlights = { n = 1, [1] = hl }
      furi.isfuri = true
      line.furi.n = line.furi.n + 1
      line.furi[line.furi.n] = furi
      worksyl.furi.n = worksyl.furi.n + 1
      worksyl.furi[worksyl.furi.n] = furi
    end

    if not worksyl.text or not is_hl then
      line.text_stripped = line.text_stripped .. prespace .. syltext .. postspace
      worksyl.text = syl.text
      worksyl.duration = syl.duration
      worksyl.kdur = syl.duration / 10
      worksyl.start_time, worksyl.end_time = syl.start_time, syl.end_time
      worksyl.tag = syl.tag
      worksyl.line = line
      worksyl.i = line.kara.n
      worksyl.text_stripped = prespace .. syltext .. postspace
      worksyl.inline_fx = cur_inline_fx
      worksyl.text_spacestripped = syltext
      worksyl.prespace, worksyl.postspace = prespace, postspace
    else
      worksyl.duration = worksyl.duration + syl.duration
      worksyl.kdur = worksyl.kdur + syl.duration / 10
      worksyl.end_time = syl.end_time
    end
  end
  line.kara[line.kara.n] = worksyl
end

function karaskel.preproc_line_size(meta, styles, line)
  if not line.kara then karaskel.preproc_line_text(meta, styles, line) end
  if styles[line.style] then
    line.styleref = styles[line.style]
  else
    aegisub.debug.out(2, "WARNING: Style not found: " .. line.style .. "\n")
    line.styleref = styles[1]
  end
  line.width, line.height, line.descent, line.extlead = aegisub.text_extents(line.styleref, line.text_stripped)
  line.width = line.width * meta.video_x_correct_factor
  for s = 0, line.kara.n do
    local syl = line.kara[s]
    syl.style = line.styleref
    syl.width, syl.height = aegisub.text_extents(syl.style, syl.text_spacestripped)
    syl.width = syl.width * meta.video_x_correct_factor
    syl.prespacewidth = aegisub.text_extents(syl.style, syl.prespace) * meta.video_x_correct_factor
    syl.postspacewidth = aegisub.text_extents(syl.style, syl.postspace) * meta.video_x_correct_factor
  end
  line.furistyle = styles[line.style .. "-furigana"] or false
  if line.furistyle then
    for f = 1, line.furi.n do
      local furi = line.furi[f]
      furi.style = line.furistyle
      furi.width, furi.height = aegisub.text_extents(furi.style, furi.text)
      furi.width = furi.width * meta.video_x_correct_factor
      furi.prespacewidth, furi.postspacewidth = 0, 0
    end
  end
end

function karaskel.do_basic_layout(meta, styles, line)
  local curx = 0
  for i = 0, line.kara.n do
    local syl = line.kara[i]
    curx = curx + syl.prespacewidth
    syl.left = curx
    syl.center = curx + syl.width / 2
    syl.right = curx + syl.width
    curx = curx + syl.width + syl.postspacewidth
  end
  line.width = curx
end

-- Furigana layout: syllable positions are computed like the basic layout, and each furigana is
-- centred above its base syllable (spilling to the right is allowed).
function karaskel.do_furigana_layout(meta, styles, line)
  karaskel.do_basic_layout(meta, styles, line)
  for f = 1, line.furi.n do
    local furi = line.furi[f]
    local base = furi.syl
    furi.left = base.center - furi.width / 2
    furi.center = base.center
    furi.right = furi.left + furi.width
    if furi.left < base.left and not furi.spillback then furi.left = base.left; furi.right = furi.left + furi.width; furi.center = furi.left + furi.width / 2 end
  end
end

function karaskel.preproc_line_pos(meta, styles, line)
  if not line.styleref then karaskel.preproc_line_size(meta, styles, line) end
  if line.furistyle then karaskel.do_furigana_layout(meta, styles, line)
  else karaskel.do_basic_layout(meta, styles, line) end

  local sr = line.styleref
  line.margin_v = line.margin_t
  line.eff_margin_l = (line.margin_l > 0) and line.margin_l or sr.margin_l
  line.eff_margin_r = (line.margin_r > 0) and line.margin_r or sr.margin_r
  line.eff_margin_t = (line.margin_t > 0) and line.margin_t or sr.margin_t
  line.eff_margin_b = (line.margin_b > 0) and line.margin_b or sr.margin_b
  line.eff_margin_v = (line.margin_v > 0) and line.margin_v or sr.margin_v
  local a = sr.align
  if a == 1 or a == 4 or a == 7 then
    line.left = line.eff_margin_l
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.left
    line.halign = "left"
  elseif a == 2 or a == 5 or a == 8 then
    line.left = (meta.res_x - line.eff_margin_l - line.eff_margin_r - line.width) / 2 + line.eff_margin_l
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.center
    line.halign = "center"
  else
    line.left = meta.res_x - line.eff_margin_r - line.width
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.right
    line.halign = "right"
  end
  line.hcenter = line.center
  if a >= 1 and a <= 3 then
    line.bottom = meta.res_y - line.eff_margin_b
    line.middle = line.bottom - line.height / 2
    line.top = line.bottom - line.height
    line.y = line.bottom
    line.valign = "bottom"
  elseif a >= 4 and a <= 6 then
    line.top = (meta.res_y - line.eff_margin_t - line.eff_margin_b - line.height) / 2 + line.eff_margin_t
    line.middle = line.top + line.height / 2
    line.bottom = line.top + line.height
    line.y = line.middle
    line.valign = "middle"
  else
    line.top = line.eff_margin_t

-- karaskel.lua: karaoke skeleton helpers (Osisub implementation, API compatible with Aegisub's karaskel).
karaskel = karaskel or {}
local karaskel = karaskel

function karaskel.collect_head(subs, generate_furigana)
  local meta = { res_x = 0, res_y = 0, video_x_correct_factor = 1.0 }
  local styles = { n = 0 }
  local toinsert = {}
  local first_style_line
  if not karaskel.furigana_scale then karaskel.furigana_scale = 0.5 end

  for i = 1, #subs do
    if aegisub.progress.is_cancelled() then error("User cancelled") end
    local l = subs[i]
    if l.class == "style" then
      first_style_line = first_style_line or i
      styles.n = styles.n + 1
      styles[styles.n] = l
      styles[l.name] = l
      l.margin_v = l.margin_t
      if generate_furigana and not l.name:match("furigana") then
        local fs = table.copy(l)
        fs.fontsize = l.fontsize * karaskel.furigana_scale
        fs.outline = l.outline * karaskel.furigana_scale
        fs.shadow = l.shadow * karaskel.furigana_scale
        fs.name = l.name .. "-furigana"
        toinsert[#toinsert + 1] = fs
      end
    elseif l.class == "info" then
      meta[l.key:lower()] = l.value
    else
      break
    end
  end
  if not first_style_line then error("Karaskel error: No styles were found in the file, bug?!") end

  for i = 1, #toinsert do
    if not styles[toinsert[i].name] then
      styles.n = styles.n + 1
      styles[styles.n] = toinsert[i]
      styles[toinsert[i].name] = toinsert[i]
      subs[-first_style_line] = toinsert[i]
    end
  end

  meta.res_x, meta.res_y = subs.script_resolution()
  local vx, vy = aegisub.video_size()
  if vy then
    meta.video_x_correct_factor = (vy / vx) / (meta.res_y / meta.res_x)
  end
  return meta, styles
end

function karaskel.preproc_line_text(meta, styles, line)
  local kara = aegisub.parse_karaoke_data(line)
  line.kara = { n = 0 }
  line.furi = { n = 0 }
  line.text_stripped = ""
  line.duration = line.end_time - line.start_time

  local worksyl = { highlights = { n = 0 }, furi = { n = 0 } }
  local cur_inline_fx = ""
  for i = 0, kara.n do
    local syl = kara[i]
    local fx = syl.text:match("%{.*\\%-([^}\\]+)")
    if fx then cur_inline_fx = fx end
    local prespace, syltext, postspace = syl.text_stripped:match("^([ \t]*)(.-)([ \t]*)$")
    local prefix = syltext:sub(1, unicode.charwidth(syltext, 1))
    local is_hl = (prefix == "#" or prefix == "＃")
    if not is_hl and i > 0 then
      line.kara[line.kara.n] = worksyl
      line.kara.n = line.kara.n + 1
      worksyl = { highlights = { n = 0 }, furi = { n = 0 } }
    end
    local hl = { start_time = syl.start_time, end_time = syl.end_time, duration = syl.duration }
    worksyl.highlights.n = worksyl.highlights.n + 1
    worksyl.highlights[worksyl.highlights.n] = hl

    if syltext:find("|", 1, true) or syltext:find("｜", 1, true) then
      syltext = syltext:gsub("｜", "|")
      local maintext, furitext = syltext:match("^(.-)|(.-)$")
      syltext = maintext
      local furi = { syl = worksyl }
      local fp = furitext:sub(1, unicode.charwidth(furitext, 1))
      if fp == "!" or fp == "！" then furi.isbreak, furi.spillback = true, false
      elseif fp == "<" or fp == "＜" then furi.isbreak, furi.spillback = true, true
      else furi.isbreak, furi.spillback = false, false end
      if furi.isbreak then furitext = furitext:sub(unicode.charwidth(furitext, 1) + 1) end
      furi.start_time, furi.end_time, furi.duration = syl.start_time, syl.end_time, syl.duration
      furi.kdur = syl.duration / 10
      furi.text, furi.text_stripped, furi.text_spacestripped = furitext, furitext, furitext
      furi.line, furi.tag, furi.inline_fx = line, syl.tag, cur_inline_fx
      furi.i = line.kara.n
      furi.prespace, furi.postspace = "", ""
      furi.highlights = { n = 1, [1] = hl }
      furi.isfuri = true
      line.furi.n = line.furi.n + 1
      line.furi[line.furi.n] = furi
      worksyl.furi.n = worksyl.furi.n + 1
      worksyl.furi[worksyl.furi.n] = furi
    end

    if not worksyl.text or not is_hl then
      line.text_stripped = line.text_stripped .. prespace .. syltext .. postspace
      worksyl.text = syl.text
      worksyl.duration = syl.duration
      worksyl.kdur = syl.duration / 10
      worksyl.start_time, worksyl.end_time = syl.start_time, syl.end_time
      worksyl.tag = syl.tag
      worksyl.line = line
      worksyl.i = line.kara.n
      worksyl.text_stripped = prespace .. syltext .. postspace
      worksyl.inline_fx = cur_inline_fx
      worksyl.text_spacestripped = syltext
      worksyl.prespace, worksyl.postspace = prespace, postspace
    else
      worksyl.duration = worksyl.duration + syl.duration
      worksyl.kdur = worksyl.kdur + syl.duration / 10
      worksyl.end_time = syl.end_time
    end
  end
  line.kara[line.kara.n] = worksyl
end

function karaskel.preproc_line_size(meta, styles, line)
  if not line.kara then karaskel.preproc_line_text(meta, styles, line) end
  if styles[line.style] then
    line.styleref = styles[line.style]
  else
    aegisub.debug.out(2, "WARNING: Style not found: " .. line.style .. "\n")
    line.styleref = styles[1]
  end
  line.width, line.height, line.descent, line.extlead = aegisub.text_extents(line.styleref, line.text_stripped)
  line.width = line.width * meta.video_x_correct_factor
  for s = 0, line.kara.n do
    local syl = line.kara[s]
    syl.style = line.styleref
    syl.width, syl.height = aegisub.text_extents(syl.style, syl.text_spacestripped)
    syl.width = syl.width * meta.video_x_correct_factor
    syl.prespacewidth = aegisub.text_extents(syl.style, syl.prespace) * meta.video_x_correct_factor
    syl.postspacewidth = aegisub.text_extents(syl.style, syl.postspace) * meta.video_x_correct_factor
  end
  line.furistyle = styles[line.style .. "-furigana"] or false
  if line.furistyle then
    for f = 1, line.furi.n do
      local furi = line.furi[f]
      furi.style = line.furistyle
      furi.width, furi.height = aegisub.text_extents(furi.style, furi.text)
      furi.width = furi.width * meta.video_x_correct_factor
      furi.prespacewidth, furi.postspacewidth = 0, 0
    end
  end
end

function karaskel.do_basic_layout(meta, styles, line)
  local curx = 0
  for i = 0, line.kara.n do
    local syl = line.kara[i]
    curx = curx + syl.prespacewidth
    syl.left = curx
    syl.center = curx + syl.width / 2
    syl.right = curx + syl.width
    curx = curx + syl.width + syl.postspacewidth
  end
  line.width = curx
end

-- Furigana layout: syllable positions are computed like the basic layout, and each furigana is
-- centred above its base syllable (spilling to the right is allowed).
function karaskel.do_furigana_layout(meta, styles, line)
  karaskel.do_basic_layout(meta, styles, line)
  for f = 1, line.furi.n do
    local furi = line.furi[f]
    local base = furi.syl
    furi.left = base.center - furi.width / 2
    furi.center = base.center
    furi.right = furi.left + furi.width
    if furi.left < base.left and not furi.spillback then furi.left = base.left; furi.right = furi.left + furi.width; furi.center = furi.left + furi.width / 2 end
  end
end

function karaskel.preproc_line_pos(meta, styles, line)
  if not line.styleref then karaskel.preproc_line_size(meta, styles, line) end
  if line.furistyle then karaskel.do_furigana_layout(meta, styles, line)
  else karaskel.do_basic_layout(meta, styles, line) end

  local sr = line.styleref
  line.margin_v = line.margin_t
  line.eff_margin_l = (line.margin_l > 0) and line.margin_l or sr.margin_l
  line.eff_margin_r = (line.margin_r > 0) and line.margin_r or sr.margin_r
  line.eff_margin_t = (line.margin_t > 0) and line.margin_t or sr.margin_t
  line.eff_margin_b = (line.margin_b > 0) and line.margin_b or sr.margin_b
  line.eff_margin_v = (line.margin_v > 0) and line.margin_v or sr.margin_v
  local a = sr.align
  if a == 1 or a == 4 or a == 7 then
    line.left = line.eff_margin_l
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.left
    line.halign = "left"
  elseif a == 2 or a == 5 or a == 8 then
    line.left = (meta.res_x - line.eff_margin_l - line.eff_margin_r - line.width) / 2 + line.eff_margin_l
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.center
    line.halign = "center"
  else
    line.left = meta.res_x - line.eff_margin_r - line.width
    line.center = line.left + line.width / 2
    line.right = line.left + line.width
    line.x = line.right
    line.halign = "right"
  end
  line.hcenter = line.center
  if a >= 1 and a <= 3 then
    line.bottom = meta.res_y - line.eff_margin_b
    line.middle = line.bottom - line.height / 2
    line.top = line.bottom - line.height
    line.y = line.bottom
    line.valign = "bottom"
  elseif a >= 4 and a <= 6 then
    line.top = (meta.res_y - line.eff_margin_t - line.eff_margin_b - line.height) / 2 + line.eff_margin_t
    line.middle = line.top + line.height / 2
    line.bottom = line.top + line.height
    line.y = line.middle
    line.valign = "middle"
  else
    line.top = line.eff_margin_t
    line.middle = line.top + line.height / 2
    line.bottom = line.top + line.height
    line.y = line.top
    line.valign = "top"
  end
  line.vcenter = line.middle
end

-- Python host functions are reachable through the global __host table.
local host = __host
local _G = _G

local function fmt(f, ...)
  if select("#", ...) == 0 then return tostring(f) end
  local ok, r = pcall(string.format, f, ...)
  if ok then return r end
  return tostring(f)

----------------------------------------------------------------------
-- subtitle container (userdata so that '#subs' and index metamethods work)
----------------------------------------------------------------------
local function shallow(t)
  local c = {}
  for k, v in pairs(t) do c[k] = v end
  return c
end

local raw_ipairs = ipairs
ipairs = function(t)
  local m = getmetatable(t)
  if type(t) == "userdata" and m and m.__ipairs then return m.__ipairs(t) end
  return raw_ipairs(t)
end

local function make_subs(lines, selected_ids)
  local proxy = newproxy(true)
  local mt = getmetatable(proxy)
  local methods = {}

  local function chk(i, lo, hi)
    if type(i) ~= "number" or i ~= math.floor(i) or i < lo or i > hi then
      error(string.format("Attempt to access subtitle line %s, but only 1-%d exist", tostring(i), #lines), 3)
    end
  end

  local function norm(l)
    if type(l) ~= "table" then error("Attempt to insert non-table value as subtitle line", 3) end
    local c = shallow(l)
    if c.class == "dialogue" then
      c.section = c.section or "[Events]"
      c.comment = c.comment or false
      c.layer = c.layer or 0
      c.start_time = c.start_time or 0
      c.end_time = c.end_time or 0
      c.style = c.style or "Default"
      c.actor = c.actor or ""
      c.margin_l = c.margin_l or 0
      c.margin_r = c.margin_r or 0
      c.margin_t = c.margin_t or c.margin_v or 0
      c.margin_b = c.margin_b or c.margin_t
      c.effect = c.effect or ""
      c.text = c.text or ""
      c.extra = c.extra or {}
    end
    return c
  end

  function methods.insert(i, ...)
    local n = select("#", ...)
    chk(i, 1, #lines + 1)
    for k = 1, n do
      local l = norm((select(k, ...)))
      table.insert(lines, i + k - 1, l)
    end
  end
  function methods.append(...)
    for k = 1, select("#", ...) do table.insert(lines, norm((select(k, ...)))) end
  end
  function methods.delete(...)
    local seen, idx = {}, {}
    for _, i in ipairs({...}) do if not seen[i] then seen[i] = true; idx[#idx + 1] = i end end
    table.sort(idx, function(a, b) return a > b end)
    for _, i in ipairs(idx) do chk(i, 1, #lines); table.remove(lines, i) end
  end
  function methods.deleterange(a, b)
    chk(a, 1, #lines); chk(b, 1, #lines)
    if a > b then a, b = b, a end
    for i = b, a, -1 do table.remove(lines, i) end
  end
  function methods.script_resolution()
    local x, y = host.script_resolution()
    return x, y
  end

  mt.__len = function() return #lines end
  mt.__index = function(_, k)
    if type(k) == "number" then
      if k < 0 then error("Attempt to read subtitle line at negative index", 2) end
      chk(k, 1, #lines)
      local l = shallow(lines[k])
      if l.extra then l.extra = shallow(l.extra) end
      return l
    elseif k == "n" then
      return #lines
    end
    return methods[k]
  end
  mt.__newindex = function(_, k, v)
    if type(k) ~= "number" then error("Cannot set non-numeric subtitle index", 2) end
    if k < 0 then
      -- negative index: insert before line -k
      local at = -k
      chk(at, 1, #lines + 1)
      table.insert(lines, at, norm(v))
    elseif k == 0 then
      table.insert(lines, #lines + 1, norm(v))
    else
      chk(k, 1, #lines)
      if v == nil then table.remove(lines, k) else lines[k] = norm(v) end
    end
  end
  mt.__ipairs = function()
    local i = 0
    return function() i = i + 1; if i <= #lines then return i, mt.__index(nil, i) end end
  end
  mt.__tostring = function() return "SubtitleFile" end
  return proxy
end

local unicode = {}
local function utf8len(c)
  local b = c:byte(1)
  if not b then return 0 end
  if b < 0x80 then return 1 elseif b >= 0xF0 then return 4 elseif b >= 0xE0 then return 3 elseif b >= 0xC0 then return 2 end
  return 1
end
function unicode.charwidth(s, i)
  i = i or 1
  local b = s:byte(i)
  if not b then return 0 end
  return utf8len(s:sub(i, i))
end
function unicode.chars(s)
  local i = 1
  return function()
    if i > #s then return nil end
    local n = utf8len(s:sub(i, i))
    local c = s:sub(i, i + n - 1)
    i = i + n
    return c
  end
end
function unicode.len(s) local n = 0 for _ in unicode.chars(s) do n = n + 1 end return n end
function unicode.codepoint(s)
  local b1, b2, b3, b4 = s:byte(1, 4)
  if not b1 then return nil end
  if b1 < 0x80 then return b1
  elseif b1 < 0xE0 then return (b1 - 0xC0) * 64 + (b2 - 0x80)
  elseif b1 < 0xF0 then return (b1 - 0xE0) * 4096 + (b2 - 0x80) * 64 + (b3 - 0x80)
  else return (b1 - 0xF0) * 262144 + (b2 - 0x80) * 4096 + (b3 - 0x80) * 64 + (b4 - 0x80) end
end
function unicode.to_upper(s) return host.str_upper(s) end
function unicode.to_lower(s) return host.str_lower(s) end
function unicode.to_fold_case(s) return host.str_lower(s) end

-- regex module (Perl-like, backed by Python re)
----------------------------------------------------------------------
local re = { ICASE = 1, NOSUB = 2, NO_MOD_M = 4, MOD_S = 8, MOD_M = 16, NOT_BOL = 32, NOT_EOL = 64 }
local Regex = {}
Regex.__index = Regex
function re.compile(pat, flags)
  local id = host.re_compile(pat, flags or 0)
  return setmetatable({ id = id }, Regex)
end
local function wrap_matches(m)
  if not m then return nil end
  return m
end
function Regex:find(str) return host.re_find(self.id, str) end
function Regex:gfind(str)
  local res = host.re_find(self.id, str) or {}
  local i = 0
  return function() i = i + 1; return res[i] end
end
function Regex:match(str) return host.re_find(self.id, str, true) end
function Regex:sub(str, repl, max) return host.re_sub(self.id, str, repl, max or 0) end
function Regex:gsub(str, repl, max) return host.re_sub(self.id, str, repl, max or 0) end

local util = {}
function util.copy(t)
  local c = {}
  for k, v in pairs(t) do c[k] = v end
  return c
end
function util.deep_copy(t, seen)
  if type(t) ~= "table" then return t end
  seen = seen or {}
  if seen[t] then return seen[t] end
  local c = {}
  seen[t] = c
  for k, v in pairs(t) do c[util.deep_copy(k, seen)] = util.deep_copy(v, seen) end
  return setmetatable(c, getmetatable(t))
end
function util.clamp(v, lo, hi) return math.min(math.max(v, lo), hi) end
function util.interpolate(pct, a, b)
  if pct <= 0 then return a elseif pct >= 1 then return b end
  return pct * (b - a) + a
end
local function c8(v) return math.min(255, math.max(0, math.floor(v + 0.5))) end
function util.ass_alpha(a) return string.format("&H%02X&", c8(a)) end
function util.ass_color(r, g, b) return string.format("&H%02X%02X%02X&", c8(b), c8(g), c8(r)) end
function util.ass_style_color(r, g, b, a) return string.format("&H%02X%02X%02X%02X", c8(a or 0), c8(b), c8(g), c8(r)) end
function util.extract_color(s)
  local a, b, g, r
  local hex = s:match("^&?[Hh](%x+)&?$") or s:match("^&[Hh](%x+)")
  if hex then
    if #hex <= 2 then return tonumber(hex, 16) end
    while #hex < 8 do hex = "0" .. hex end
    a, b, g, r = hex:match("^(%x%x)(%x%x)(%x%x)(%x%x)$")
    if a then return tonumber(r, 16), tonumber(g, 16), tonumber(b, 16), tonumber(a, 16) end
  end
  r, g, b = s:match("^#(%x%x)(%x%x)(%x%x)$")
  if r then return tonumber(r, 16), tonumber(g, 16), tonumber(b, 16), 0 end
  return 0, 0, 0, 0
end
function util.alpha_from_style(s) local _, _, _, a = util.extract_color(s) return util.ass_alpha(a) end
function util.color_from_style(s) local r, g, b = util.extract_color(s) return util.ass_color(r, g, b) end
function util.interpolate_color(pct, c1, c2)
  local r1, g1, b1 = util.extract_color(c1)
  local r2, g2, b2 = util.extract_color(c2)
  local f = function(a, b) return math.floor(util.interpolate(pct, a, b) + 0.5) end
  return util.ass_color(f(r1, r2), f(g1, g2), f(b1, b2))
end
function util.interpolate_alpha(pct, a1, a2)
  local x = util.extract_color(a1)
  local y = util.extract_color(a2)
  return util.ass_alpha(math.floor(util.interpolate(pct, x, y) + 0.5))
end
function util.HSV_to_RGB(H, S, V)
  H = (H % 360) / 60
  local i = math.floor(H)
  local f = H - i
  local p, q, t = V * (1 - S), V * (1 - S * f), V * (1 - S * (1 - f))
  local r, g, b
  if i == 0 then r, g, b = V, t, p elseif i == 1 then r, g, b = q, V, p
  elseif i == 2 then r, g, b = p, V, t elseif i == 3 then r, g, b = p, q, V
  elseif i == 4 then r, g, b = t, p, V else r, g, b = V, p, q end
  return math.floor(r * 255 + 0.5), math.floor(g * 255 + 0.5), math.floor(b * 255 + 0.5)
end
function util.RGB_to_HSV(r, g, b)
  r, g, b = r / 255, g / 255, b / 255
  local mx, mn = math.max(r, g, b), math.min(r, g, b)
  local d = mx - mn
  local h = 0
  if d ~= 0 then
    if mx == r then h = ((g - b) / d) % 6 elseif mx == g then h = (b - r) / d + 2 else h = (r - g) / d + 4 end
    h = h * 60
  end
  return h, (mx == 0) and 0 or d / mx, mx
end
function util.HSL_to_RGB(H, S, L)
  H = (H % 360) / 360
  local function hue(p, q, t)
    if t < 0 then t = t + 1 elseif t > 1 then t = t - 1 end
    if t < 1 / 6 then return p + (q - p) * 6 * t elseif t < 1 / 2 then return q
    elseif t < 2 / 3 then return p + (q - p) * (2 / 3 - t) * 6 end
    return p
  end
  local r, g, b
  if S == 0 then r, g, b = L, L, L else
    local q = (L < 0.5) and L * (1 + S) or L + S - L * S
    local p = 2 * L - q
    r, g, b = hue(p, q, H + 1 / 3), hue(p, q, H), hue(p, q, H - 1 / 3)
  end
  return math.floor(r * 255 + 0.5), math.floor(g * 255 + 0.5), math.floor(b * 255 + 0.5)
end
function util.RGB_to_HSL(r, g, b)
  r, g, b = r / 255, g / 255, b / 255
  local mx, mn = math.max(r, g, b), math.min(r, g, b)
  local l = (mx + mn) / 2
  if mx == mn then return 0, 0, l end
  local d = mx - mn
  local s = (l > 0.5) and d / (2 - mx - mn) or d / (mx + mn)
  local h
  if mx == r then h = (g - b) / d + ((g < b) and 6 or 0) elseif mx == g then h = (b - r) / d + 2 else h = (r - g) / d + 4 end
  return h * 60, s, l
end

-- karaoke parsing (aegisub.parse_karaoke_data)
----------------------------------------------------------------------
local function parse_karaoke_data(line)
  local text = line.text
  local syls = {}
  local cur = { duration = 0, tag = "", text = "", text_stripped = "", start_time = 0, end_time = 0, line = line }
  local function flush(final)
    cur.end_time = cur.start_time + cur.duration
    syls[#syls + 1] = cur
  end
  local pos = 1
  local t = 0
  local function add_text(s)
    cur.text = cur.text .. s
    cur.text_stripped = cur.text_stripped .. s
  end
  while pos <= #text do
    local a, b = text:find("{[^}]*}", pos)
    if not a then add_text(text:sub(pos)); break end
    if a > pos then add_text(text:sub(pos, a - 1)) end
    local block = text:sub(a + 1, b - 1)
    -- split block on karaoke tags
    local rest = block
    local first = true
    local kept = ""
    local function emit_kept()
      if kept ~= "" then cur.text = cur.text .. "{" .. kept .. "}"; kept = "" end
    end
    local p = 1
    local seg_start = 1
    local any = false
    while true do
      local ka, kb, ktag, kval = rest:find("\\([kK][fo]?)(%-?%d+)", p)
      if not ka then break end
      any = true
      kept = kept .. rest:sub(seg_start, ka - 1)
      emit_kept()
      -- finish current syllable if it has any content or a previous k tag
      if #syls > 0 or cur.text ~= "" or cur.tag ~= "" or true then
        flush()
        t = t + cur.duration
      end
      cur = { duration = tonumber(kval) * 10, tag = (ktag == "K") and "kf" or ktag, text = "", text_stripped = "", start_time = t, end_time = t, line = line }
      seg_start = kb + 1
      p = kb + 1
    end
    kept = kept .. rest:sub(seg_start)
    if kept ~= "" then cur.text = cur.text .. "{" .. kept .. "}" end
    pos = b + 1
  end
  flush()
  -- if the first syllable (index 0) has no text and zero duration it is still kept as kara[0]
  local out = {}
  for i, s in ipairs(syls) do
    s.i = i - 1
    out[i - 1] = s
  end
  out.n = #syls - 1
  return out
end

local function find_file(name, script)
  name = name:gsub("\\", "/")
  local function try(p)
    local f = io.open(p, "rb")
    if f then f:close() return p end
  end
  if name:match("^/") or name:match("^%a:[\\/]") then return try(name) end
  if script and script.dir then
    local p = try(script.dir .. "/" .. name)
    if p then return p end
  end
  for _, d in ipairs(include_dirs) do
    local p = try(d .. "/" .. name)
    if p then return p end
  end
end

local function load_into(path, env)
  local f, err = io.open(path, "rb")
  if not f then error("Could not open " .. path, 3) end
  local src = f:read("*a")
  f:close()
  if src:sub(1, 3) == "\239\187\191" then src = src:sub(4) end
  local chunk, e = loadstring(src, "@" .. path)
  if not chunk then error(e, 0) end
  setfenv(chunk, env)
  return chunk
end

local function new_script(path)
  local script = { path = path, dir = path:match("^(.*)[/\\][^/\\]*$") or ".", macros = {}, filters = {}, loaded = {} }
  local env = setmetatable({}, { __index = _G })
  env._G = env
  env.aegisub = make_aegisub(script)
  env.unicode = unicode
  env.re = re
  install_utils_globals(env)
  env.include = function(name)
    local p = find_file(name, script)
    if not p then
      local b = builtin_includes[name]
      if b then return b(env) end
      error("Lua include not found: " .. name, 2)
    end
    if script.loaded[p] then return end
    script.loaded[p] = true
    local chunk = load_into(p, env)
    return chunk()
  end
  env.require = function(name)
    local b = builtin_includes[name]
    if b == nil and package.preload[name] == nil and package.loaded[name] == nil then
      local file = name:gsub("%.", "/") .. ".lua"
      local p = find_file(file, script) or find_file(name .. "/init.lua", script) or find_file(name:gsub("%.", "/") .. "/init.lua", script)
      if p and not package.loaded[p] then
        local chunk = load_into(p, env)
        local r = chunk(name)
        package.loaded[p] = (r == nil) and true or r
        return package.loaded[p]
      elseif p then return package.loaded[p] end
    end
    if b then return b(env) end
    return require(name)
  end
  script.env = env
  return script
end

function O.load_script(path)
  local script = new_script(path)
  scripts[#scripts + 1] = script
  local ok, err = pcall(function()
    local chunk = load_into(path, script.env)
    chunk()
  end)
  if not ok then
    if type(err) == "table" then err = err.message or "error" end
    script.error = tostring(err)
  end
  local e = script.env
  script.name = e.script_name or path:match("([^/\\]+)$")
  script.description = e.script_description or ""
  script.author = e.script_author or ""
  script.version = e.script_version or ""
  script.namespace = e.script_namespace or ""
  return script
end

-- classic karaskel-style entry points of old scripts (version 3 'process_lines' etc.) are not supported.

local function run_guarded(fn, ...)
  local res = { xpcall(fn, function(e)
    if type(e) == "table" and e.__cancel then return e end
    return { message = tostring(e), trace = debug.traceback(tostring(e), 2) }
  end, ...) }
  return res
end

local function selection_array(sel)
  local t = {}
  for i = 1, #sel do t[i] = sel[i] end
  return t
end

function O.make_subs(lines) return make_subs(lines) end

-- returns ok, selection(table|nil), active(number|nil), err(table|nil)
function O.run_macro(m, lines, selection, active)
  local subs = make_subs(lines)
  local sel = selection_array(selection)
  local res = run_guarded(m.process, subs, sel, active)
  if not res[1] then
    local e = res[2]
    if e.__cancel then return false, nil, nil, "cancelled" end
    return false, nil, nil, e.trace or e.message
  end
  local newsel, newactive = res[2], res[3]
  if type(newsel) == "table" then
    -- Aegisub accepts a table of indices; may return (sel, active) or only active
    local t = {}
    for i = 1, #newsel do t[i] = newsel[i] end
    newsel = t
  elseif type(newsel) == "number" then
    newactive = newsel
    newsel = nil
  else
    newsel = nil
  end
  return true, newsel, newactive
end

function O.validate_macro(m, lines, selection, active)
  if not m.validate then return true, "" end
  local subs = make_subs(lines)
  local res = run_guarded(m.validate, subs, selection_array(selection), active)
  if not res[1] then return false, "" end
  return res[2] and true or false, res[3] or ""
end

function O.run_filter(f, lines, config)
  local subs = make_subs(lines)
  local res = run_guarded(f.process, subs, config or {})
  if not res[1] then
    local e = res[2]
    if e.__cancel then return false, "cancelled" end
    return false, e.trace or e.message
  end
  return true
end

function O.filter_config(f, lines, old)
  if not f.config then return nil end
  local subs = make_subs(lines)
  local res = run_guarded(f.config, subs, old or {})
  if not res[1] then return nil end
  return res[2]
end

return O

# ------------------------------------------------------------------ text measurement
class TextMeasurer:
    """Measure text extents for a style (script-resolution pixels)."""

    def __init__(self) -> None:
        self._qt = None
        self._cache: dict = {}

    def _init_qt(self):
        if self._qt is not None:
            return self._qt
        try:
            from PySide6.QtGui import QGuiApplication, QFont, QFontMetricsF  # noqa
            if QGuiApplication.instance() is None:
                os.environ.setdefault("QT_QPA_PLATFORM", "offscreen")
                self._app = QGuiApplication([])
            self._qt = (QFont, QFontMetricsF)
        except Exception:
            self._qt = False
        return self._qt

    def measure(self, st: dict, text: str) -> tuple[float, float, float, float]:
        fontname = st.get("fontname", "Arial")
        size = float(st.get("fontsize", 40) or 40)
        bold, italic = bool(st.get("bold")), bool(st.get("italic"))
        sx = float(st.get("scale_x", 100) or 100) / 100.0
        sy = float(st.get("scale_y", 100) or 100) / 100.0
        spacing = float(st.get("spacing", 0) or 0)
        key = (fontname, size, bold, italic, text, sx, sy, spacing)
        if key in self._cache:
            return self._cache[key]
        qt = self._init_qt()
        if qt:
            QFont, QFontMetricsF = qt
            f = QFont(fontname)
            f.setPixelSize(max(1, int(round(size))))
            f.setBold(bold)
            f.setItalic(italic)
            fm = QFontMetricsF(f)
            w = fm.horizontalAdvance(text) if text else 0.0
            h = fm.height()
            d = fm.descent()
            el = fm.leading()
        else:
            w = len(text) * size * 0.5
            h, d, el = size * 1.2, size * 0.2, 0.0
        n = len(text)
        res = (w * sx + spacing * n, h * sy, d * sy, el * sy)
        self._cache[key] = res
        return res

    # ---- host bridge
    def _build_host(self) -> None:
        rt = self.rt
        L = self

        def log(level, msg):
            m = _s(msg)
            L.log.append((int(level), m))
            if L.log_handler:
                L.log_handler(int(level), m)

        def regex_flags(f):
            f = int(f or 0)
            fl = _re.UNICODE
            if f & 1:
                fl |= _re.I
            if not f & 4:
                pass
            if f & 8:
                fl |= _re.S
            if f & 16:
                fl |= _re.M
            return fl

        posix = {"alpha": "a-zA-Z", "digit": "0-9", "alnum": "a-zA-Z0-9", "upper": "A-Z", "lower": "a-z",
                 "space": r"\s", "punct": r"!-/:-@\[-`{-~", "xdigit": "0-9a-fA-F", "word": r"\w"}

        def translate(p):
            p = _re.sub(r"\[:(\w+):\]", lambda m: posix.get(m.group(1), m.group(0)), p)
            p = p.replace("(?<", "(?P<") if _re.search(r"\(\?<[A-Za-z]", p) else p
            return p.replace("\\<", r"\b").replace("\\>", r"\b").replace("\\h", "[ \\t]")

        def re_compile(pat, flags):
            try:
                L._regexes.append(_re.compile(translate(_s(pat)), regex_flags(flags)))
            except _re.error as e:
                raise RuntimeError(f"regex error: {e}")
            return len(L._regexes)

        def byte_pos(s, ci):
            return len(s[:ci].encode("utf-8"))

        def mk_match(s, m):
            groups = [m] if m is not None else []
            tbl = []
            for gi in range(0, (m.re.groups or 0) + 1):
                if m.start(gi) < 0:
                    tbl.append({b"str": b"", b"first": 0, b"last": 0})
                    continue
                tbl.append({b"str": _b(m.group(gi)), b"first": byte_pos(s, m.start(gi)) + 1,
                            b"last": byte_pos(s, m.end(gi))})
            return tbl

        def to_lua_matches(tbls):
            return rt.table_from([rt.table_from([rt.table_from(d) for d in t]) for t in tbls])

        def re_find(rid, s, first_only=False):
            rx = L._regexes[int(rid) - 1]
            st = _s(s)
            res = []
            for m in rx.finditer(st):
                res.append(mk_match(st, m))
                if first_only:
                    break
            if not res:
                return None
            if first_only:
                return rt.table_from([rt.table_from(d) for d in res[0]])
            # Aegisub returns a flat array of matches: list of {str,first,last}
            return rt.table_from([rt.table_from(t[0]) for t in res])

        def expand(r, m):
            out, i = [], 0
            while i < len(r):
                c = r[i]
                if c in "$\\" and i + 1 < len(r):
                    n = r[i + 1]
                    if n.isdigit():
                        j = i + 1
                        while j < len(r) and r[j].isdigit() and j - i <= 2:
                            j += 1
                        g = int(r[i + 1:j])
                        out.append((m.group(g) or "") if g <= (m.re.groups or 0) else "")
                        i = j
                        continue
                    if c == "$" and n == "&":
                        out.append(m.group(0)); i += 2; continue
                    if c == "\\":
                        out.append(n); i += 2; continue
                out.append(c); i += 1
            return "".join(out)

        def re_sub(rid, s, repl, mx):
            rx = L._regexes[int(rid) - 1]
            st = _s(s)
            if callable(repl) or not isinstance(repl, (bytes, str)):
                def fn(m):
                    mt = mk_match(st, m)
                    tbl = dict(mt[0])
                    for gi, g in enumerate(mt[1:], 1):
                        tbl[gi] = rt.table_from(g)
                    return _s(repl(rt.table_from(tbl)))
                return _b(rx.sub(fn, st, count=int(mx or 0)))
            rs = _s(repl)
            return _b(rx.sub(lambda m: expand(rs, m), st, count=int(mx or 0)))

        def re_split(rid, s):
            rx = L._regexes[int(rid) - 1]
            return rt.table_from([_b(x or "") for x in rx.split(_s(s))][:: rx.groups + 1])

        def style_to_dict(t):
            d = {}
            for k, v in t.items():
                d[_s(k)] = _s(v) if isinstance(v, bytes) else v
            return d

        def text_extents(style, text):
            w, h, d, e = L.measurer.measure(style_to_dict(style), _s(text))
            return w, h, d, e

        def dialog(dlg, buttons, ids):
            controls = [from_lua(dlg[i]) for i in range(1, len(dlg) + 1)]
            btns = [from_lua(b) for b in (list(buttons.values()) if buttons is not None else [])] or ["OK", "Cancel"]
            idsd = from_lua(ids) if ids is not None else {}
            if L.dialog_handler:
                button, results = L.dialog_handler(controls, btns, idsd)
            else:
                button, results = headless_dialog(controls, btns, idsd)
            if button is False or button is None:
                return False, None
            out = {}
            for k, v in (results or {}).items():
                out[_b(k)] = _b(v) if isinstance(v, str) else v
            return (_b(button) if isinstance(button, str) else button), rt.table_from(out)

        def file_dialog(kind, *args):
            if L.file_dialog_handler:
                r = L.file_dialog_handler(kind, [from_lua(a) for a in args])
                return _b(r) if isinstance(r, str) else (rt.table_from([_b(x) for x in r]) if r else None)
            return None

        def script_resolution():
            if L._doc is None:
                return 384, 288
            return L._doc.res

        def progress_set(v):
            if L.progress_handler:
                L.progress_handler("set", float(v))

        def progress_task(s):
            if L.progress_handler:
                L.progress_handler("task", _s(s))

        def progress_title(s):
            if L.progress_handler:
                L.progress_handler("title", _s(s))

        def video_size():
            if L.video_res:
                return L.video_res[0], L.video_res[1]
            return None

        def keyframes():
            return rt.table_from(list(L.keyframe_list))

        def audio_selection():
            return L.audio_sel if L.audio_sel else (None, None)

        def project_properties():
            return rt.table_from({_b(k): _b(v) if isinstance(v, str) else v for k, v in L.project_props.items()})

        def decode_path(p):
            p = _s(p)
            for tag, val in (("?script", os.path.dirname(L._doc.filename) if (L._doc and L._doc.filename) else "?script"),
                             ("?data", os.path.expanduser("~/.osisub")),
                             ("?user", os.path.expanduser("~/.osisub")),
                             ("?temp", os.environ.get("TMPDIR", "/tmp"))):
                if p.startswith(tag):
                    p = val + p[len(tag):]
            return _b(p)

        def file_name():
            if L._doc and L._doc.filename:
                return _b(os.path.basename(L._doc.filename))
            return None

        def clip_get():
            return _b(L.clipboard_text)

        def clip_set(s):
            L.clipboard_text = _s(s)

        funcs = dict(
            log=log, re_compile=re_compile, re_find=re_find, re_sub=re_sub, re_split=re_split,
            text_extents=text_extents, dialog=dialog, file_dialog=file_dialog,
            script_resolution=script_resolution, progress_set=progress_set, progress_task=progress_task,
            progress_title=progress_title, progress_cancelled=lambda: L.cancel_flag,
            video_size=video_size, keyframes=keyframes, audio_selection=audio_selection,
            project_properties=project_properties, decode_path=decode_path, file_name=file_name,
            clipboard_get=clip_get, clipboard_set=clip_set,
            frame_from_ms=lambda ms: L.fps.ms_to_frame(int(ms)) if L.video_res else None,
            ms_from_frame=lambda f: L.fps.frame_to_ms(int(f)) if L.video_res else None,
            str_upper=lambda s: _b(_s(s).upper()), str_lower=lambda s: _b(_s(s).lower()),
            undo_point=lambda d: L.undo_points.append(_s(d)),
        )
        self._host_funcs = {k.encode(): v for k, v in funcs.items()}

    def _load_prelude(self):
        self.rt.globals()[b"__host"] = self.rt.table_from(self._host_funcs)
        src = open(os.path.join(LUA_DIR, "prelude.lua"), "rb").read()
        return self.rt.execute(src)

    # ---- scripts
    def load_script(self, path: str) -> Script:
        lua_script = self.lua.load_script(_b(os.path.abspath(path)))
        s = Script(path=path, lua=lua_script)
        s.name = _s(lua_script[b"name"])
        s.description = _s(lua_script[b"description"])
        s.author = _s(lua_script[b"author"])
        s.version = _s(lua_script[b"version"])
        s.error = _s(lua_script[b"error"]) if lua_script[b"error"] else ""
        for i, m in lua_script[b"macros"].items():
            s.macros.append(Macro(s, int(i), _s(m[b"name"]), _s(m[b"description"]), m))
        for i, m in lua_script[b"filters"].items():
            s.filters.append(Macro(s, int(i), _s(m[b"name"]), _s(m[b"description"]), m, "filter",
                                   int(m[b"priority"] or 0)))
        self.scripts.append(s)
        return s

    def load_dir(self, directory: str) -> list[Script]:
        out = []
        if not os.path.isdir(directory):
            return out
        for fn in sorted(os.listdir(directory)):
            p = os.path.join(directory, fn)
            if os.path.isfile(p) and fn.lower().endswith(".lua"):
                out.append(self.load_script(p))
            elif os.path.isdir(p):
                for cand in (fn + ".lua", "init.lua"):
                    if os.path.isfile(os.path.join(p, cand)):
                        out.append(self.load_script(os.path.join(p, cand)))
                        break
        return out

    # ---- document <-> lines
    def _lines_from_doc(self, doc: Document):
        rt = self.rt
        lines = []
        for k, v in doc.info:
            if k == "":
                continue
            lines.append(rt.table_from({b"class": b"info", b"section": b"[Script Info]", b"key": _b(k),
                                        b"value": _b(v), b"raw": _b(f"{k}: {v}")}))
        for st in doc.styles:
            lines.append(rt.table_from(self._style_to_table(st)))
        for ev in doc.events:
            lines.append(rt.table_from(self._event_to_table(ev)))
        return lines

    @staticmethod
    def _style_to_table(st: Style) -> dict:
        return {
            b"class": b"style", b"section": b"[V4+ Styles]", b"name": _b(st.name), b"fontname": _b(st.fontname),
            b"fontsize": st.fontsize, b"color1": _b(st.primary if st.primary.endswith("&") is False else st.primary),
            b"color2": _b(st.secondary), b"color3": _b(st.outline_c), b"color4": _b(st.back),
            b"bold": st.bold, b"italic": st.italic, b"underline": st.underline, b"strikeout": st.strikeout,
            b"scale_x": st.scale_x, b"scale_y": st.scale_y, b"spacing": st.spacing, b"angle": st.angle,
            b"borderstyle": st.border_style, b"outline": st.outline, b"shadow": st.shadow, b"align": st.align,
            b"margin_l": st.margin_l, b"margin_r": st.margin_r, b"margin_t": st.margin_v, b"margin_b": st.margin_v,
            b"encoding": st.encoding, b"relative_to": 2,
        }

    @staticmethod
    def _event_to_table(ev: Event) -> dict:
        return {
            b"class": b"dialogue", b"section": b"[Events]", b"comment": ev.comment, b"layer": ev.layer,
            b"start_time": ev.start, b"end_time": ev.end, b"style": _b(ev.style), b"actor": _b(ev.actor),
            b"margin_l": ev.margin_l, b"margin_r": ev.margin_r, b"margin_t": ev.margin_v, b"margin_b": ev.margin_v,
            b"effect": _b(ev.effect), b"text": _b(ev.text),
        }

    def _doc_from_lines(self, lines, base: Document) -> Document:
        doc = Document()
        doc.filename = base.filename
        doc.garbage = list(base.garbage)
        doc.attachments = list(base.attachments)
        doc.extra_sections = list(base.extra_sections)
        # preserve comment-only info lines from the base document
        comments = [(k, v) for k, v in base.info if k == ""]
        n = len(lines)
        for i in range(1, n + 1):
            t = lines[i - 1]
            cls = _s(t[b"class"])
            if cls == "info":
                doc.info.append((_s(t[b"key"]), _s(t[b"value"])))
            elif cls == "style":
                doc.styles.append(self._style_from_table(t))
            elif cls == "dialogue":
                doc.events.append(self._event_from_table(t))
        doc.info = comments + doc.info
        return doc

    @staticmethod
    def _style_from_table(t) -> Style:
        g = lambda k, d=None: t[k] if t[k] is not None else d
        s = Style()
        s.name = _s(g(b"name", b"Default"))
        s.fontname = _s(g(b"fontname", b"Arial"))
        s.fontsize = _num(g(b"fontsize", 48))
        s.primary = _norm_color(_s(g(b"color1", b"&H00FFFFFF")))
        s.secondary = _norm_color(_s(g(b"color2", b"&H000000FF")))
        s.outline_c = _norm_color(_s(g(b"color3", b"&H00000000")))
        s.back = _norm_color(_s(g(b"color4", b"&H00000000")))
        s.bold, s.italic = bool(g(b"bold", False)), bool(g(b"italic", False))
        s.underline, s.strikeout = bool(g(b"underline", False)), bool(g(b"strikeout", False))
        s.scale_x, s.scale_y = _num(g(b"scale_x", 100)), _num(g(b"scale_y", 100))
        s.spacing, s.angle = _num(g(b"spacing", 0)), _num(g(b"angle", 0))
        s.border_style = int(_num(g(b"borderstyle", 1)))
        s.outline, s.shadow = _num(g(b"outline", 2)), _num(g(b"shadow", 2))
        s.align = int(_num(g(b"align", 2)))
        s.margin_l, s.margin_r = int(_num(g(b"margin_l", 10))), int(_num(g(b"margin_r", 10)))
        s.margin_v = int(_num(g(b"margin_t", g(b"margin_v", 10))))
        s.encoding = int(_num(g(b"encoding", 1)))
        return s

    @staticmethod
    def _event_from_table(t) -> Event:
        g = lambda k, d=None: t[k] if t[k] is not None else d
        e = Event()
        e.comment = bool(g(b"comment", False))
        e.layer = int(_num(g(b"layer", 0)))
        e.start, e.end = int(round(_num(g(b"start_time", 0)))), int(round(_num(g(b"end_time", 0))))
        e.style = _s(g(b"style", b"Default"))
        e.actor = _s(g(b"actor", b""))
        e.margin_l, e.margin_r = int(_num(g(b"margin_l", 0))), int(_num(g(b"margin_r", 0)))
        e.margin_v = int(_num(g(b"margin_t", g(b"margin_v", 0))))
        e.effect = _s(g(b"effect", b""))
        e.text = _s(g(b"text", b""))
        return e

    def _lua_array(self, items):
        return self.rt.table_from(items)

    # ---- running
    def _run(self, doc: Document, selection: list[int], active: int, fn):
        self._doc = doc
        self.cancel_flag = False
        self.log = []
        # selection is given in 1-based global line indices: events follow info+styles
        offset = len([1 for k, _ in doc.info if k != ""]) + len(doc.styles)
        lines = self._lines_from_doc(doc)
        lua_lines = self.lua.new_lines()
        for i, l in enumerate(lines, 1):
            lua_lines[i] = l
        sel = self.lua.new_lines()
        for i, x in enumerate(selection, 1):
            sel[i] = offset + x + 1
        act = offset + (active if active is not None else (selection[0] if selection else 0)) + 1
        return fn(lua_lines, sel, act, offset)

    def run_macro(self, macro: Macro, doc: Document, selection: Optional[list[int]] = None,
                  active: Optional[int] = None) -> RunResult:
        selection = list(selection or [])

        def go(lua_lines, sel, act, offset):
            r = self.lua.run_macro(macro.lua, lua_lines, sel, act)
            r = tuple(r) if isinstance(r, tuple) else (r,)
            ok, newsel, newact, err = (r + (None,) * 4)[:4]
            return ok, newsel, newact, err, lua_lines, offset

        ok, newsel, newact, err, lua_lines, offset = self._run(doc, selection, active, go)
        res = RunResult(ok=bool(ok), log=list(self.log))
        if not ok:
            res.error = _s(err)
            res.cancelled = res.error == "cancelled"
            return res
        newdoc = self._doc_from_lines([lua_lines[i] for i in range(1, len(lua_lines) + 1)], doc)
        new_offset = len([1 for k, _ in newdoc.info if k != ""]) + len(newdoc.styles)
        res.document = newdoc
        if newsel is not None:
            res.selection = [int(newsel[i]) - 1 - new_offset for i in range(1, len(newsel) + 1)
                             if 0 <= int(newsel[i]) - 1 - new_offset < len(newdoc.events)]
        else:
            res.selection = None
        if newact is not None:
            a = int(newact) - 1 - new_offset
            res.active = a if 0 <= a < len(newdoc.events) else None
        return res

    def validate_macro(self, macro: Macro, doc: Document, selection: Optional[list[int]] = None,
                       active: Optional[int] = None) -> bool:
        if macro.lua[b"validate"] is None:
            return True

        def go(lua_lines, sel, act, offset):
            return self.lua.validate_macro(macro.lua, lua_lines, sel, act)

        r = self._run(doc, list(selection or []), active, go)
        return bool(r[0] if isinstance(r, tuple) else r)

    def run_filter(self, flt: Macro, doc: Document, config: Optional[dict] = None) -> RunResult:
        def go(lua_lines, sel, act, offset):
            cfg = self.rt.table_from({_b(k): (_b(v) if isinstance(v, str) else v) for k, v in (config or {}).items()})
            r = self.lua.run_filter(flt.lua, lua_lines, cfg)
            r = tuple(r) if isinstance(r, tuple) else (r,)
            ok, err = (r + (None,) * 2)[:2]
            return ok, err, lua_lines

        ok, err, lua_lines = self._run(doc, [], 0, go)
        res = RunResult(ok=bool(ok), log=list(self.log))
        if not ok:
            res.error = _s(err)
            return res
        res.document = self._doc_from_lines([lua_lines[i] for i in range(1, len(lua_lines) + 1)], doc)
        return res


def from_lua(v: Any) -> Any:
    """Recursively convert lupa objects to Python values."""
    if isinstance(v, bytes):
        return v.decode("utf-8", "replace")
    if v is None or isinstance(v, (int, float, bool)):
        return v
    if hasattr(v, "items"):
        d = {}
        for k, x in v.items():
            d[from_lua(k)] = from_lua(x)
        return d
    return v


def _norm_color(v: str) -> str:
    m = _re.match(r"^\s*&?[Hh]?([0-9A-Fa-f]{1,8})&?\s*$", v)
    return "&H" + (m.group(1).zfill(8) if m else "00FFFFFF").upper()


def _color_result(cls: str, v: str) -> str:
    """Normalise a colour string to what Aegisub returns for the control class."""
    m = _re.match(r"^&?[Hh]?([0-9A-Fa-f]{1,8})&?$", v.strip())
    if not m:
        h = _re.match(r"^#([0-9A-Fa-f]{6})$", v.strip())
        hx = ("00" + h.group(1)[4:6] + h.group(1)[2:4] + h.group(1)[0:2]) if h else "00000000"
    else:
        hx = m.group(1).zfill(8)
        if cls == "alpha" and len(m.group(1)) <= 2:
            hx = m.group(1).zfill(2) + "000000"
    if cls == "alpha":
        return "&H%s&" % hx[0:2]
    if cls == "color":
        return "&H%s&" % hx[2:8]
    return "&H" + hx


def headless_dialog(controls: list[dict], buttons: list, ids: dict):
    """Non-interactive dialog: accept defaults and press the first (OK) button."""
    results = {}
    for c in controls:
        name = c.get("name")
        if not name:
            continue
        cls = c.get("class")
        if cls in ("color", "coloralpha", "alpha"):
            results[name] = _color_result(cls, str(c.get("value", c.get("text", "&H00FFFFFF"))))
        elif cls in ("edit", "textbox"):
            results[name] = c.get("text", c.get("value", ""))
        elif cls in ("intedit", "floatedit", "checkbox", "dropdown"):
            v = c.get("value")
            if v is None:
                if cls == "checkbox":
                    v = False
                elif cls == "dropdown":
                    items = c.get("items") or {}
                    v = items[min(items)] if items else ""
                else:
                    v = c.get("min", 0) if cls != "floatedit" else 0
            results[name] = v
    first = buttons[0] if buttons else "OK"
    ok_id = ids.get("ok") if isinstance(ids, dict) else None
    return (ok_id or first), results

def _parse_range(s: str | None, n: int):
    if not s:
        return None
    out = []
    for part in s.split(","):
        if "-" in part:
            a, b = part.split("-", 1)
            out.extend(range(int(a) - 1, int(b)))
        else:
            out.append(int(part) - 1)
    return [i for i in out if 0 <= i < n]


def _engine(args):
    from .automation import Engine
    inc = [d for d in (args.include or [])]
    for env in ("OSISUB_INCLUDE",):
        if os.environ.get(env):
            inc += os.environ[env].split(os.pathsep)
    return Engine(include_dirs=inc, log_handler=lambda lvl, m: sys.stderr.write(m))


def cmd_convert(a):
    save_any(load_any(a.input), a.output)


def cmd_macros(a):
    eng = _engine(a)
    s = eng.load_script(a.script)
    if s.error:
        print("ERROR:", s.error, file=sys.stderr)
        return 1
    print(f"{s.name} v{s.version} by {s.author}")
    for i, m in enumerate(s.macros):
        print(f"  macro {i}: {m.name} - {m.description}")
    for i, f in enumerate(s.filters):
        print(f"  filter {i}: {f.name} (prio {f.priority}) - {f.description}")
    return 0


def cmd_run(a):
    eng = _engine(a)
    s = eng.load_script(a.script)
    if s.error:
        print("ERROR:", s.error, file=sys.stderr)
        return 1
    doc = load_any(a.input)
    sel = _parse_range(a.select, len(doc.events)) or []
    if a.filter is not None:
        res = eng.run_filter(s.filters[a.filter], doc)
    else:
        m = s.macros[a.macro]
        res = eng.run_macro(m, doc, sel, sel[0] if sel else 0)
    if not res.ok:
        print("FAILED:", res.error, file=sys.stderr)
        return 2
    save_any(res.document, a.output or a.input)
    return 0


def cmd_check(a):
    doc = load_any(a.input)
    issues = tools.check(doc, max_cps=a.cps, max_cpl=a.cpl)
    for i in issues:
        print(f"{i.index + 1:5d} [{i.kind}] {i.message}")
    print(f"{len(issues)} issue(s) in {len(doc.events)} lines")
    return 1 if issues else 0

"""ASS/SSA document model, parser and writer (lossless for unknown sections)."""
from __future__ import annotations
import re
from dataclasses import dataclass, field, replace
from typing import Optional
from .timeutil import parse_ass_time, format_ass_time

STYLE_FIELDS = [
    "Name", "Fontname", "Fontsize", "PrimaryColour", "SecondaryColour", "OutlineColour",
    "BackColour", "Bold", "Italic", "Underline", "StrikeOut", "ScaleX", "ScaleY", "Spacing",
    "Angle", "BorderStyle", "Outline", "Shadow", "Alignment", "MarginL", "MarginR", "MarginV",
    "Encoding",
]
DEFAULT_STYLE_FORMAT = ", ".join(STYLE_FIELDS)
EVENT_FORMAT = "Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text"


@dataclass
class Style:
    name: str = "Default"
    fontname: str = "Arial"
    fontsize: float = 48
    primary: str = "&H00FFFFFF"
    secondary: str = "&H000000FF"
    outline_c: str = "&H00000000"
    back: str = "&H00000000"
    bold: bool = False
    italic: bool = False
    underline: bool = False
    strikeout: bool = False
    scale_x: float = 100
    scale_y: float = 100
    spacing: float = 0
    angle: float = 0
    border_style: int = 1
    outline: float = 2
    shadow: float = 2
    align: int = 2
    margin_l: int = 10
    margin_r: int = 10
    margin_v: int = 10
    encoding: int = 1

    @staticmethod
    def _num(v: str) -> float:
        try:
            f = float(v)
            return int(f) if f == int(f) else f
        except ValueError:
            return 0

    @classmethod
    def from_fields(cls, fmt: list[str], vals: list[str]) -> "Style":
        d = {k.strip().lower(): v.strip() for k, v in zip(fmt, vals)}
        n = cls._num
        def b(k):
            return n(d.get(k, "0")) != 0
        s = cls()
        s.name = d.get("name", "Default")
        s.fontname = d.get("fontname", "Arial")
        s.fontsize = n(d.get("fontsize", "48"))
        s.primary = d.get("primarycolour", s.primary)
        s.secondary = d.get("secondarycolour", s.secondary)
        s.outline_c = d.get("outlinecolour", d.get("tertiarycolour", s.outline_c))
        s.back = d.get("backcolour", s.back)
        s.bold, s.italic, s.underline, s.strikeout = b("bold"), b("italic"), b("underline"), b("strikeout")
        s.scale_x, s.scale_y = n(d.get("scalex", "100")), n(d.get("scaley", "100"))
        s.spacing, s.angle = n(d.get("spacing", "0")), n(d.get("angle", "0"))
        s.border_style = int(n(d.get("borderstyle", "1")))
        s.outline, s.shadow = n(d.get("outline", "2")), n(d.get("shadow", "2"))
        s.align = int(n(d.get("alignment", "2")))
        s.margin_l, s.margin_r = int(n(d.get("marginl", "10"))), int(n(d.get("marginr", "10")))
        s.margin_v = int(n(d.get("marginv", "10")))
        s.encoding = int(n(d.get("encoding", "1")))
        return s

    def to_line(self) -> str:
        def fb(v):
            return "-1" if v else "0"
        def fn(v):
            return str(int(v)) if float(v) == int(v) else repr(float(v))
        parts = [self.name, self.fontname, fn(self.fontsize), self.primary, self.secondary,
                 self.outline_c, self.back, fb(self.bold), fb(self.italic), fb(self.underline),
                 fb(self.strikeout), fn(self.scale_x), fn(self.scale_y), fn(self.spacing),
                 fn(self.angle), str(self.border_style), fn(self.outline), fn(self.shadow),
                 str(self.align), str(self.margin_l), str(self.margin_r), str(self.margin_v),
                 str(self.encoding)]
        return "Style: " + ",".join(parts)


@dataclass
class Event:
    comment: bool = False
    layer: int = 0
    start: int = 0  # ms
    end: int = 0
    style: str = "Default"
    actor: str = ""
    margin_l: int = 0
    margin_r: int = 0
    margin_v: int = 0
    effect: str = ""
    text: str = ""

    @property
    def duration(self) -> int:
        return self.end - self.start

    def copy(self) -> "Event":
        return replace(self)

    @classmethod
    def from_line(cls, kind: str, rest: str, fmt: list[str]) -> "Event":
        parts = rest.split(",", len(fmt) - 1)
        parts += [""] * (len(fmt) - len(parts))
        d = {k.strip().lower(): v for k, v in zip(fmt, parts)}
        def i(k):
            try:
                return int(float(d.get(k, "0").strip() or 0))
            except ValueError:
                return 0
        e = cls()
        e.comment = kind.lower() == "comment"
        e.layer = i("layer") if "layer" in d else i("marked")
        e.start = parse_ass_time(d.get("start", "0:00:00.00"))
        e.end = parse_ass_time(d.get("end", "0:00:00.00"))
        e.style = d.get("style", "Default").strip()
        e.actor = d.get("name", d.get("actor", "")).strip()
        e.margin_l, e.margin_r = i("marginl"), i("marginr")
        e.margin_v = i("marginv")
        e.effect = d.get("effect", "").strip()
        e.text = d.get("text", "")
        return e

    def to_line(self) -> str:
        def m(v):
            return f"{v:04d}" if v >= 0 else str(v)
        return (f"{'Comment' if self.comment else 'Dialogue'}: {self.layer},"
                f"{format_ass_time(self.start)},{format_ass_time(self.end)},{self.style},"
                f"{self.actor},{m(self.margin_l)},{m(self.margin_r)},{m(self.margin_v)},"
                f"{self.effect},{self.text}")


@dataclass
class Document:
    info: list[tuple[str, str]] = field(default_factory=list)  # ordered; key '' = comment line
    styles: list[Style] = field(default_factory=list)
    events: list[Event] = field(default_factory=list)
    garbage: list[tuple[str, str]] = field(default_factory=list)  # [Aegisub Project Garbage]
    attachments: list[tuple[str, str, list[str]]] = field(default_factory=list)  # (section, name, lines)
    extra_sections: list[tuple[str, list[str]]] = field(default_factory=list)
    style_format: str = DEFAULT_STYLE_FORMAT
    filename: Optional[str] = None

    # ---- script info helpers
    def get_info(self, key: str, default: str = "") -> str:
        for k, v in self.info:
            if k.lower() == key.lower():
                return v
        return default

    def set_info(self, key: str, value: str) -> None:
        for i, (k, _) in enumerate(self.info):
            if k.lower() == key.lower():
                self.info[i] = (k, str(value))
                return
        self.info.append((key, str(value)))

    @property
    def res(self) -> tuple[int, int]:
        def g(k, d):
            try:
                return int(float(self.get_info(k, str(d))))
            except ValueError:
                return d
        return g("PlayResX", 384 if not self.get_info("PlayResY") else 0) or 384, g("PlayResY", 288)

    def get_garbage(self, key: str, default: str = "") -> str:
        for k, v in self.garbage:
            if k == key:
                return v
        return default

    def set_garbage(self, key: str, value: str) -> None:
        for i, (k, _) in enumerate(self.garbage):
            if k == key:
                self.garbage[i] = (k, value)
                return
        self.garbage.append((key, value))

    def style(self, name: str) -> Optional[Style]:
        for s in self.styles:
            if s.name == name:
                return s
        return None

    @classmethod
    def new(cls) -> "Document":
        d = cls()
        d.info = [("Title", "Untitled"), ("ScriptType", "v4.00+"), ("WrapStyle", "0"),
                  ("ScaledBorderAndShadow", "yes"), ("YCbCr Matrix", "TV.709"),
                  ("PlayResX", "1920"), ("PlayResY", "1080")]
        d.styles = [Style(fontsize=60, outline=3, shadow=1, margin_l=60, margin_r=60, margin_v=40)]
        return d

    # ---- parsing
    @classmethod
    def parse(cls, text: str) -> "Document":
        doc = cls()
        text = text.lstrip("﻿")
        section = None
        sfmt: list[str] = STYLE_FIELDS[:]
        efmt: list[str] = [x.strip() for x in EVENT_FORMAT.split(",")]
        cur_att = None
        extra: Optional[list[str]] = None
        for raw in text.replace("\r\n", "\n").replace("\r", "\n").split("\n"):
            line = raw
            st = line.strip()
            if st.startswith("[") and st.endswith("]") and len(st) > 2 and (
                    cur_att is None or re.fullmatch(r"\[[A-Za-z0-9+ ]{2,40}\]", st)
                    and st[1:-1].lower() in ("script info", "v4+ styles", "v4 styles", "events", "fonts",
                                             "graphics", "aegisub project garbage", "aegisub extradata")):
                section = st[1:-1]
                cur_att = None
                low = section.lower()
                if low not in ("script info", "v4+ styles", "v4 styles", "events",
                               "aegisub project garbage", "fonts", "graphics"):
                    extra = []
                    doc.extra_sections.append((section, extra))
                else:
                    extra = None
                continue
            if section is None:
                continue
            low = section.lower()
            if extra is not None:
                extra.append(line)
                continue
            if low in ("fonts", "graphics"):
                if st.startswith("fontname:") or st.startswith("filename:"):
                    cur_att = (section, st.split(":", 1)[1].strip(), [])
                    doc.attachments.append(cur_att)
                elif cur_att is not None and st:
                    cur_att[2].append(st)
                continue
            if not st:
                continue
            if low == "script info":
                if st.startswith(";"):
                    doc.info.append(("", st))
                elif ":" in st:
                    k, v = st.split(":", 1)
                    doc.info.append((k.strip(), v.strip()))
            elif low == "aegisub project garbage":
                if ":" in st:
                    k, v = st.split(":", 1)
                    doc.garbage.append((k.strip(), v.strip()))
            elif low in ("v4+ styles", "v4 styles"):
                if st.lower().startswith("format:"):
                    sfmt = [x.strip() for x in st.split(":", 1)[1].split(",")]
                    doc.style_format = ", ".join(sfmt)
                elif st.lower().startswith("style:"):
                    vals = st.split(":", 1)[1].lstrip().split(",")
                    doc.styles.append(Style.from_fields(sfmt, vals))
            elif low == "events":
                if st.lower().startswith("format:"):
                    efmt = [x.strip() for x in st.split(":", 1)[1].split(",")]
                else:
                    m = re.match(r"^(Dialogue|Comment|Picture|Sound|Movie|Command):\s?(.*)$", line.lstrip(), re.S)
                    if m and m.group(1) in ("Dialogue", "Comment"):
                        doc.events.append(Event.from_line(m.group(1), m.group(2), efmt))
        if not any(k.lower() == "scripttype" for k, _ in doc.info):
            doc.info.insert(0, ("ScriptType", "v4.00+"))
        return doc

    @classmethod
    def load(cls, path: str) -> "Document":
        data = open(path, "rb").read()
        doc = cls.parse(decode_bytes(data))
        doc.filename = path
        return doc

    # ---- writing
    def dumps(self) -> str:
        out = ["[Script Info]"]
        for k, v in self.info:
            out.append(v if k == "" else f"{k}: {v}")
        out += ["", "[V4+ Styles]", "Format: " + DEFAULT_STYLE_FORMAT]
        out += [s.to_line() for s in self.styles]
        out += ["", "[Events]", "Format: " + EVENT_FORMAT]
        out += [e.to_line() for e in self.events]
        if self.garbage:
            out += ["", "[Aegisub Project Garbage]"] + [f"{k}: {v}" for k, v in self.garbage]
        for sec in ("Fonts", "Graphics"):
            items = [a for a in self.attachments if a[0].lower() == sec.lower()]
            if items:
                out += ["", f"[{sec}]"]
                for _, name, lines in items:
                    out.append(("fontname: " if sec == "Fonts" else "filename: ") + name)
                    out += lines
                    out.append("")
        for name, lines in self.extra_sections:
            out += ["", f"[{name}]"] + [l for l in lines if l.strip() != "" or True]
        return "\n".join(out).rstrip("\n") + "\n"

    def save(self, path: Optional[str] = None, bom: bool = True, set_filename: bool = True) -> None:
        path = path or self.filename
        if not path:
            raise ValueError("no path")
        with open(path, "wb") as f:
            f.write(("﻿" if bom else "").encode("utf-8") + self.dumps().replace("\n", "\r\n").encode("utf-8"))
        if set_filename:
            self.filename = path


def decode_bytes(data: bytes) -> str:
    """Decode subtitle bytes: BOMs first, then UTF-8, then common legacy codepages."""
    if data.startswith(b"\xef\xbb\xbf"):
        return data[3:].decode("utf-8", "replace")
    if data.startswith(b"\xff\xfe") or data.startswith(b"\xfe\xff"):
        return data.decode("utf-16", "replace")
    try:
        return data.decode("utf-8")
    except UnicodeDecodeError:
        pass
    for enc in ("cp1254", "cp1252", "latin-1"):  # Turkish first
        try:
            return data.decode(enc)
        except UnicodeDecodeError:
            continue
    return data.decode("latin-1", "replace")

"""ASS-specific utilities: resolution resampling, font usage, karaoke helpers, style import."""
from __future__ import annotations
import re
import shutil
import subprocess
from .ass import Document, Style, Event

# ------------------------------------------------------------------ number formatting
def _fmt(v: float, places: int = 2) -> str:
    s = f"{v:.{places}f}".rstrip("0").rstrip(".")
    return s if s not in ("", "-0") else "0"


# ------------------------------------------------------------------ resample
_SCALE1 = re.compile(r"\\(fs|fsp|bord|xbord|ybord|shad|xshad|yshad)(-?\d+(?:\.\d+)?)")
_POS = re.compile(r"\\(pos|org)\(\s*(-?[\d.]+)\s*,\s*(-?[\d.]+)\s*\)")
_MOVE = re.compile(r"\\move\(([^)]*)\)")
_CLIP = re.compile(r"\\(i?clip)\(([^)]*)\)")
_DRAW_SCALE = re.compile(r"\\p(\d+)")


def _scale_block(block: str, sx: float, sy: float, sf: float, in_draw: list) -> str:
    def one(m):
        k, v = m.group(1), float(m.group(2))
        f = sx if k in ("xbord", "xshad") else sy if k in ("ybord", "yshad") else sf
        return f"\\{k}{_fmt(v * f)}"
    b = _SCALE1.sub(one, block)
    b = _POS.sub(lambda m: f"\\{m.group(1)}({_fmt(float(m.group(2)) * sx)},{_fmt(float(m.group(3)) * sy)})", b)

    def mv(m):
        nums = [x.strip() for x in m.group(1).split(",")]
        out = []
        for i, n in enumerate(nums):
            try:
                v = float(n)
            except ValueError:
                out.append(n); continue
            if i < 4:
                out.append(_fmt(v * (sx if i % 2 == 0 else sy)))
            else:
                out.append(n)
        return "\\move(" + ",".join(out) + ")"
    b = _MOVE.sub(mv, b)

    def clip(m):
        args = [a.strip() for a in m.group(2).split(",")]
        if len(args) == 4:
            try:
                v = [float(a) for a in args]
                return f"\\{m.group(1)}({_fmt(v[0] * sx)},{_fmt(v[1] * sy)},{_fmt(v[2] * sx)},{_fmt(v[3] * sy)})"
            except ValueError:
                return m.group(0)
        inner = m.group(2)
        # vector clip: optional scale then drawing commands
        parts = inner.split(",", 1) if re.match(r"^\s*\d+\s*,", inner) else [None, inner]
        scale = parts[0]
        return f"\\{m.group(1)}(" + (scale + "," if scale is not None else "") + _scale_draw(parts[1], sx, sy) + ")"
    b = _CLIP.sub(clip, b)
    for m in _DRAW_SCALE.finditer(b):
        in_draw[0] = int(m.group(1)) > 0
    return b


def _scale_draw(s: str, sx: float, sy: float) -> str:
    toks = s.split()
    out, i = [], 0
    for t in toks:
        if re.fullmatch(r"[a-zA-Z]+", t):
            out.append(t); i = 0
        else:
            try:
                v = float(t)
                out.append(_fmt(v * (sx if i % 2 == 0 else sy)))
                i += 1
            except ValueError:
                out.append(t)
    return " ".join(out)


def scale_text(text: str, sx: float, sy: float) -> str:
    sf = sy
    in_draw = [False]
    out, pos = [], 0
    for m in BLOCK.finditer(text):
        seg = text[pos:m.start()]
        out.append(_scale_draw(seg, sx, sy) if in_draw[0] and seg else seg)
        out.append(_scale_block(m.group(0), sx, sy, sf, in_draw))
        pos = m.end()
    seg = text[pos:]
    out.append(_scale_draw(seg, sx, sy) if in_draw[0] and seg else seg)
    return "".join(out)


def resample(doc: Document, new_x: int, new_y: int, change_ar_margins: bool = True) -> None:
    ox, oy = doc.res
    if (ox, oy) == (new_x, new_y) or not ox or not oy:
        doc.set_info("PlayResX", str(new_x)); doc.set_info("PlayResY", str(new_y)); return
    sx, sy = new_x / ox, new_y / oy
    for s in doc.styles:
        s.fontsize = round(s.fontsize * sy, 2)
        s.outline = round(s.outline * sy, 2)
        s.shadow = round(s.shadow * sy, 2)
        s.spacing = round(s.spacing * sx, 2)
        s.margin_l, s.margin_r = int(round(s.margin_l * sx)), int(round(s.margin_r * sx))
        s.margin_v = int(round(s.margin_v * sy))
    for e in doc.events:
        e.margin_l, e.margin_r = int(round(e.margin_l * sx)), int(round(e.margin_r * sx))
        e.margin_v = int(round(e.margin_v * sy))
        e.text = scale_text(e.text, sx, sy)
    doc.set_info("PlayResX", str(new_x))
    doc.set_info("PlayResY", str(new_y))


# ------------------------------------------------------------------ fonts
def fonts_used(doc: Document) -> dict[str, set[str]]:
    """font name -> set of places (style names or 'line N')"""
    used: dict[str, set[str]] = {}
    styles = {s.name: s for s in doc.styles}
    for s in doc.styles:
        used.setdefault(s.fontname, set()).add(f"stil {s.name}")
    for i, e in enumerate(doc.events):
        if e.comment:
            continue
        for m in re.finditer(r"\\fn([^\\}]+)", e.text):
            used.setdefault(m.group(1).strip(), set()).add(f"satır {i + 1}")
    return used


def installed_fonts() -> set[str]:
    fc = shutil.which("fc-list")
    names: set[str] = set()
    if not fc:
        return names
    out = subprocess.run([fc, ":", "family"], capture_output=True, text=True).stdout
    for line in out.splitlines():
        for n in line.split(","):
            names.add(n.strip().lower())
    return names


def missing_fonts(doc: Document, installed: set[str] | None = None) -> dict[str, set[str]]:
    inst = installed if installed is not None else installed_fonts()
    if not inst:
        return {}
    return {f: w for f, w in fonts_used(doc).items() if f.lstrip("@").lower() not in inst}


# ------------------------------------------------------------------ styles
def import_styles(dst: Document, src: Document, names: list[str] | None = None, overwrite: bool = True) -> int:
    n = 0
    by = {s.name: i for i, s in enumerate(dst.styles)}
    for s in src.styles:
        if names is not None and s.name not in names:
            continue
        c = Style(**s.__dict__)
        if s.name in by:
            if overwrite:
                dst.styles[by[s.name]] = c; n += 1
        else:
            dst.styles.append(c); n += 1
    return n


def unused_styles(doc: Document) -> list[str]:
    used = {e.style for e in doc.events}
    return [s.name for s in doc.styles if s.name not in used and s.name != "Default"]


# ------------------------------------------------------------------ karaoke
_K = re.compile(r"\{[^}]*\\[kK][fo]?\d+[^}]*\}")


def has_karaoke(text: str) -> bool:
    return bool(_K.search(text))


def parse_syllables(text: str) -> list[dict]:
    """Split a karaoke line into syllables: [{'dur': cs, 'tag': 'k', 'text': ...}] (other tags kept in text)."""
    syls, cur = [], {"dur": 0, "tag": "k", "text": ""}
    pos = 0
    for m in BLOCK.finditer(text):
        cur["text"] += text[pos:m.start()]
        pos = m.end()
        block = m.group(0)[1:-1]
        parts = re.split(r"(\\[kK][fo]?-?\d+)", block)
        kept = ""
        for p in parts:
            km = re.fullmatch(r"\\([kK][fo]?)(-?\d+)", p)
            if km:
                if kept:
                    cur["text"] += "{" + kept + "}"; kept = ""
                syls.append(cur)
                cur = {"dur": int(km.group(2)), "tag": km.group(1), "text": ""}
            else:
                kept += p
        if kept:
            cur["text"] += "{" + kept + "}"
    cur["text"] += text[pos:]
    syls.append(cur)
    return syls


def build_karaoke(syls: list[dict]) -> str:
    out = []
    for i, s in enumerate(syls):
        if i == 0 and not s["text"] and s["dur"] == 0:
            continue
        out.append(("{\\%s%d}" % (s["tag"], s["dur"])) + s["text"])
    return "".join(out)


def auto_karaoke(text: str, duration_ms: int, mode: str = "syllable", tag: str = "kf") -> str:
    """Spread the line duration evenly over syllables (vowel-group split) / characters / words."""
    plain = BLOCK.sub("", text)
    if mode == "char":
        units = [c for c in plain]
    elif mode == "word":
        units = re.findall(r"\s*\S+", plain)
    else:
        units = re.findall(r"[^aeıioöuüAEIİOÖUÜ\s]*[aeıioöuüAEIİOÖUÜ]+(?:[^aeıioöuüAEIİOÖUÜ\s](?![aeıioöuüAEIİOÖUÜ]))?|\s+|[^aeıioöuüAEIİOÖUÜ\s]+", plain)
    units = [u for u in units if u != ""]
    if not units:
        return text
    weights = [max(1, len(u.strip())) if u.strip() else 0 for u in units]
    total = sum(weights) or 1
    cs_total = duration_ms // 10
    out, used = [], 0
    for i, (u, w) in enumerate(zip(units, weights)):
        dur = cs_total - used if i == len(units) - 1 else int(round(cs_total * w / total))
        used += dur
        out.append(("{\\%s%d}" % (tag, max(0, dur))) + u)
    return "".join(out)


def apply_auto_karaoke(doc: Document, indices, mode="syllable", tag="kf") -> int:
    n = 0
    for i in indices:
        e = doc.events[i]
        if e.comment:
            continue
        e.text = auto_karaoke(e.text, e.duration, mode, tag)
        n += 1
    return n


def lead_in_out(doc: Document, indices, lead_in=300, lead_out=300) -> None:
    """Extend line start/end and compensate karaoke (first syllable gets the extra lead-in as a silent \\k)."""
    for i in indices:
        e = doc.events[i]
        e.start = max(0, e.start - lead_in)
        e.end += lead_out
        if lead_in and has_karaoke(e.text):
            syls = parse_syllables(e.text)
            if syls and not syls[0]["text"] and syls[0]["dur"] == 0:
                syls[0] = {"dur": lead_in // 10, "tag": "k", "text": ""}
                e.text = "{\\k%d}" % (lead_in // 10) + build_karaoke(syls)
            else:
                e.text = "{\\k%d}" % (lead_in // 10) + e.text

def uuencode(data: bytes) -> list[str]:
    out = []
    for i in range(0, len(data), 3):
        chunk = data[i:i + 3]
        n = len(chunk)
        v = int.from_bytes(chunk.ljust(3, b"\0"), "big")
        chars = [(v >> 18) & 63, (v >> 12) & 63, (v >> 6) & 63, v & 63][: n + 1]
        out.append("".join(chr(c + 33) for c in chars))
    s = "".join(out)
    return [s[i:i + 80] for i in range(0, len(s), 80)]


def uudecode(lines: list[str]) -> bytes:
    s = "".join(l.strip() for l in lines)
    out = bytearray()
    for i in range(0, len(s), 4):
        grp = s[i:i + 4]
        vals = [(ord(c) - 33) & 63 for c in grp]
        n = len(vals)
        v = 0
        for x in vals + [0] * (4 - n):
            v = (v << 6) | x
        out += v.to_bytes(3, "big")[: n - 1]
    return bytes(out)


def attach_font(doc: Document, path: str) -> str:
    import os
    name = os.path.basename(path)
    data = open(path, "rb").read()
    doc.attachments = [a for a in doc.attachments if not (a[0] == "Fonts" and a[1] == name)]
    doc.attachments.append(("Fonts", name, uuencode(data)))
    return name


def extract_fonts(doc: Document, out_dir: str) -> list[str]:

    os.makedirs(out_dir, exist_ok=True)
    paths = []

            paths.append(p)
    return paths

def kara_durations(text: str) -> list[int]:
    """Durations (cs) of every \\k-type tag in order of appearance (only inside override blocks)."""
    out = []
    for m in BLOCK.finditer(text):
        out += [int(x.group(2)) for x in _KTAG.finditer(m.group(0))]
    return out

    it = iter(durs)

    def repl_block(m):
        return _KTAG.sub(lambda k: k.group(1) + str(next(it, int(k.group(2)))), m.group(0))
    return BLOCK.sub(repl_block, text)

    syls = parse_syllables(text)
    return [BLOCK.sub("", s["text"]) for s in syls[1:]]

"""Snapshot based undo/redo for Document."""
from __future__ import annotations
from .ass import Document, Event, Style
from dataclasses import replace


def snapshot(doc: Document):
    return (list(doc.info), [replace(s) for s in doc.styles], [e.copy() for e in doc.events])


def restore(doc: Document, snap) -> None:
    doc.info = list(snap[0])
    doc.styles = [replace(s) for s in snap[1]]
    doc.events = [e.copy() for e in snap[2]]


class History:
    def __init__(self, doc: Document, limit: int = 200):
        self.doc = doc
        self.limit = limit
        self.undo_stack: list[tuple[str, tuple]] = []
        self.redo_stack: list[tuple[str, tuple]] = []
        self.current = snapshot(doc)
        self.saved_marker = self.current

    def commit(self, label: str) -> None:
        """Call after a change has been applied to doc."""
        self.undo_stack.append((label, self.current))
        if len(self.undo_stack) > self.limit:
            self.undo_stack.pop(0)
        self.current = snapshot(self.doc)
        self.redo_stack.clear()

    def undo(self):
        if not self.undo_stack:
            return None
        label, snap = self.undo_stack.pop()
        self.redo_stack.append((label, self.current))
        self.current = snap
        restore(self.doc, snap)
        return label

    def redo(self):
        if not self.redo_stack:
            return None
        label, snap = self.redo_stack.pop()
        self.undo_stack.append((label, self.current))
        self.current = snap
        restore(self.doc, snap)
        return label

    def mark_saved(self):
        self.saved_marker = self.current

    @property
    def dirty(self) -> bool:
        return self.current is not self.saved_marker

"""Spell checking through Hunspell dictionaries using the pure-Python `spylls` port (optional dependency)."""
from __future__ import annotations
import os
import re
from typing import Iterator, Optional

from .tags import BLOCK

SEARCH_DIRS = [
    os.path.expanduser("~/.osisub/dicts"), "/usr/share/hunspell", "/usr/share/myspell", "/usr/share/myspell/dicts",
    "/Library/Spelling", "C:/Program Files/LibreOffice/share/extensions/dict-tr",
]
WORD = re.compile(r"[^\W\d_]+(?:['’][^\W\d_]+)*", re.UNICODE)


def find_dictionary(lang: str) -> Optional[str]:
    """lang like 'tr_TR' / 'en_US'. Returns base path without extension."""
    for d in SEARCH_DIRS:
        base = os.path.join(d, lang)
        if os.path.isfile(base + ".dic") and os.path.isfile(base + ".aff"):
            return base
    return None


class SpellChecker:
    def __init__(self, lang: str = "tr_TR", base: Optional[str] = None):
        from spylls.hunspell import Dictionary  # optional dependency
        base = base or find_dictionary(lang)
        if not base:
            raise FileNotFoundError(f"Hunspell sözlüğü bulunamadı: {lang} (aranan: {', '.join(SEARCH_DIRS)})")
        self.lang = lang
        self.dic = Dictionary.from_files(base)
        self.user_path = os.path.expanduser(f"~/.osisub/user_{lang}.txt")
        self.user: set[str] = set()
        self.ignored: set[str] = set()
        if os.path.isfile(self.user_path):
            self.user = {l.strip() for l in open(self.user_path, encoding="utf-8") if l.strip()}

    def is_ok(self, word: str) -> bool:
        if word in self.user or word.lower() in self.user or word in self.ignored:
            return True
        if len(word) < 2 or word.isupper():  # acronyms / single letters
            return True
        w = word.replace("’", "'")
        return bool(self.dic.lookup(w) or self.dic.lookup(w.lower()) or
                    self.dic.lookup(w.replace("I", "ı").replace("İ", "i").lower()))

    def suggest(self, word: str, limit: int = 8) -> list[str]:
        out = []
        for s in self.dic.suggest(word):
            if s not in out:
                out.append(s)
            if len(out) >= limit:
                break
        return out

    def add(self, word: str) -> None:
        self.user.add(word)
        os.makedirs(os.path.dirname(self.user_path), exist_ok=True)
        with open(self.user_path, "a", encoding="utf-8") as f:
            f.write(word + "\n")

    def errors(self, text: str) -> Iterator[tuple[int, int, str]]:
        """Yield (start, end, word) of misspelled words in an ASS text, skipping {tags} and \\N escapes."""
        masked = BLOCK.sub(lambda m: " " * len(m.group(0)), text)
        masked = masked.replace("\\N", "  ").replace("\\n", "  ").replace("\\h", "  ")
        for m in WORD.finditer(masked):
            if not self.is_ok(m.group(0)):
                yield m.start(), m.end(), m.group(0)

"""Override tag helpers."""
from __future__ import annotations
import re

BLOCK = re.compile(r"\{[^}]*\}")


def strip_tags(text: str) -> str:
    t = BLOCK.sub("", text)
    return t.replace("\\N", "\n").replace("\\n", " ").replace("\\h", "\u00a0")


def visible_text(text: str) -> str:
    return strip_tags(text)


def split_blocks(text: str) -> list[tuple[bool, str]]:
    """[(is_tag_block, content)] preserving order."""
    out, pos = [], 0
    for m in BLOCK.finditer(text):
        if m.start() > pos:
            out.append((False, text[pos:m.start()]))
        out.append((True, m.group(0)))
        pos = m.end()
    if pos < len(text):
        out.append((False, text[pos:]))
    return out


def srt_to_ass_text(t: str) -> str:
    t = t.replace("\r", "")
    t = re.sub(r"<\s*(/?)\s*([biu])\s*>", lambda m: "{\\%s%d}" % (m.group(2), 0 if m.group(1) else 1), t, flags=re.I)
    t = re.sub(r"<\s*font\s+color\s*=\s*[\"']?#?([0-9a-fA-F]{6})[\"']?\s*>",
               lambda m: "{\\c&H%s%s%s&}" % (m.group(1)[4:6], m.group(1)[2:4], m.group(1)[0:2]), t, flags=re.I)
    t = re.sub(r"<\s*/\s*font\s*>", lambda m: "{\\c}", t, flags=re.I)
    t = re.sub(r"</?[a-zA-Z][^>]*>", "", t)
    t = re.sub(r"\{\\an(\d)\}", r"{\\an\1}", t)
    return t.replace("\n", "\\N")


def ass_to_srt_text(t: str) -> str:
    out, state = [], {"i": False, "b": False, "u": False}
    for is_tag, c in split_blocks(t):
        if not is_tag:
            out.append(c.replace("\\N", "\n").replace("\\n", " ").replace("\\h", " "))
            continue
        for m in re.finditer(r"\\([biu])(\d)", c):
            k, v = m.group(1), m.group(2) == "1"
            if v != state[k]:
                out.append(f"<{'' if v else '/'}{k}>")
                state[k] = v
    for k, v in state.items():
        if v:
            out.append(f"</{k}>")
    return "".join(out)

"""Time helpers. All internal times are integer milliseconds."""
from __future__ import annotations
import re

_ASS_T = re.compile(r"^\s*(-?\d+):(\d+):(\d+)[.:](\d+)\s*$")


def parse_ass_time(s: str) -> int:
    m = _ASS_T.match(s)
    if not m:
        return 0
    h, mi, se, cs = m.groups()
    frac = (cs + "00")[:2] if len(cs) < 2 else cs[:2]
    ms = int(h) * 3600000 + int(mi) * 60000 + int(se) * 1000 + int(frac) * 10
    return ms


def format_ass_time(ms: int) -> str:
    ms = max(0, int(ms))
    cs = (ms + 5) // 10  # round to centiseconds like Aegisub
    h, r = divmod(cs, 360000)
    m, r = divmod(r, 6000)
    s, c = divmod(r, 100)
    return f"{h}:{m:02d}:{s:02d}.{c:02d}"


def format_srt_time(ms: int) -> str:
    ms = max(0, int(ms))
    h, r = divmod(ms, 3600000)
    m, r = divmod(r, 60000)
    s, r = divmod(r, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{r:03d}"


def format_vtt_time(ms: int) -> str:
    return format_srt_time(ms).replace(",", ".")


_SRT_T = re.compile(r"(\d+):(\d+):(\d+)[,.](\d{1,3})")


def parse_srt_time(s: str) -> int:
    m = _SRT_T.search(s)
    if not m:
        return 0
    h, mi, se, f = m.groups()
    return int(h) * 3600000 + int(mi) * 60000 + int(se) * 1000 + int((f + "00")[:3])


class FrameRate:
    """Constant frame rate helper (supports NTSC rationals)."""

    def __init__(self, fps: float = 23.976):
        self.fps = float(fps)

    def frame_to_ms_start(self, frame: int) -> int:
        # Aegisub style: start times land in the middle between previous and this frame
        if frame <= 0:
            return 0
        return int(((frame - 0.5) * 1000.0 / self.fps) + 0.5)

    def frame_to_ms_end(self, frame: int) -> int:
        return self.frame_to_ms_start(frame + 1) if frame >= 0 else 0

    def frame_to_ms(self, frame: int) -> int:
        return int(frame * 1000.0 / self.fps + 0.5)

    def ms_to_frame(self, ms: int) -> int:
        return int(ms * self.fps / 1000.0 + 1e-6)

    def snap(self, ms: int) -> int:
        return self.frame_to_ms(round(ms * self.fps / 1000.0))

"""Editing tools (timing, text fixes, QC) modelled after Aegisub / Subtitle Edit features."""
from __future__ import annotations
import re
from dataclasses import dataclass
from typing import Iterable, Optional, Sequence
from .ass import Document, Event
from .tags import strip_tags, BLOCK
from .timeutil import FrameRate


def _idx(doc: Document, sel: Optional[Iterable[int]]) -> list[int]:
    return list(range(len(doc.events))) if sel is None else [i for i in sel if 0 <= i < len(doc.events)]


# ------------------------------------------------------------------ timing
def shift(doc: Document, ms: int, sel=None, start=True, end=True) -> None:
    for i in _idx(doc, sel):
        e = doc.events[i]
        if start:
            e.start = max(0, e.start + ms)
        if end:
            e.end = max(e.start, e.end + ms)


def shift_from(doc: Document, ms: int, from_index: int) -> None:
    shift(doc, ms, range(from_index, len(doc.events)))


def stretch(doc: Document, factor: float, sel=None) -> None:
    for i in _idx(doc, sel):
        e = doc.events[i]
        e.start, e.end = int(e.start * factor), int(e.end * factor)


def sync_two_points(doc: Document, a_old: int, a_new: int, b_old: int, b_new: int) -> None:
    """Linear resync from two reference points (typical for framerate/cut drift)."""
    if b_old == a_old:
        return
    k = (b_new - a_new) / (b_old - a_old)
    for e in doc.events:
        e.start = max(0, int(round(a_new + (e.start - a_old) * k)))
        e.end = max(e.start, int(round(a_new + (e.end - a_old) * k)))


def convert_framerate(doc: Document, src_fps: float, dst_fps: float) -> None:
    stretch(doc, src_fps / dst_fps)


def snap_to_frames(doc: Document, fps: float, sel=None) -> None:
    fr = FrameRate(fps)
    for i in _idx(doc, sel):
        e = doc.events[i]
        e.start = fr.frame_to_ms_start(round(e.start * fps / 1000))
        e.end = fr.frame_to_ms_start(round(e.end * fps / 1000))


def snap_to_keyframes(doc: Document, keyframes_ms: Sequence[int], sel=None,
                      before_start=150, after_start=150, before_end=150, after_end=150,
                      end_gap=0) -> int:
    """Aegisub-style keyframe snapping. Returns number of snapped events."""
    kf = sorted(keyframes_ms)
    n = 0
    for i in _idx(doc, sel):
        e = doc.events[i]
        ch = False
        for k in kf:
            if e.start - before_start <= k <= e.start + after_start and k != e.start:
                e.start = k
                ch = True
                break
        for k in kf:
            tgt = k - end_gap
            if e.end - before_end <= tgt <= e.end + after_end and tgt != e.end and tgt > e.start:
                e.end = tgt
                ch = True
                break
        n += ch
    return n


def fix_overlaps(doc: Document, min_gap: int = 0, sel=None) -> int:
    ev = sorted(_idx(doc, sel), key=lambda i: (doc.events[i].start, doc.events[i].end))
    n = 0
    for a, b in zip(ev, ev[1:]):
        ea, eb = doc.events[a], doc.events[b]
        if ea.comment or eb.comment or ea.style != eb.style and False:
            continue
        if ea.end > eb.start - min_gap:
            new_end = max(ea.start + 1, eb.start - min_gap)
            if new_end != ea.end:
                ea.end = new_end
                n += 1
    return n


def enforce_duration(doc: Document, min_ms=1000, max_ms=7000, cps_target: float = 0, sel=None) -> int:
    """Extend short lines (up to next start) and cap long ones; optional reading speed target."""
    order = sorted(range(len(doc.events)), key=lambda i: doc.events[i].start)
    pos = {i: k for k, i in enumerate(order)}
    n = 0
    for i in _idx(doc, sel):
        e = doc.events[i]
        if e.comment:
            continue
        want = min_ms
        if cps_target > 0:
            chars = len(strip_tags(e.text).replace("\n", ""))
            want = max(want, int(chars / cps_target * 1000))
        want = min(want, max_ms)
        if e.duration < want:
            nxt = pos[i] + 1
            limit = doc.events[order[nxt]].start if nxt < len(order) else e.start + want
            e.end = max(e.end, min(e.start + want, max(limit, e.end)))
            n += 1
        elif e.duration > max_ms:
            e.end = e.start + max_ms
            n += 1
    return n


def sort_events(doc: Document, key: str = "start") -> None:
    keys = {
        "start": lambda e: (e.start, e.end), "end": lambda e: (e.end, e.start),
        "style": lambda e: (e.style, e.start), "actor": lambda e: (e.actor, e.start),
        "effect": lambda e: (e.effect, e.start), "layer": lambda e: (e.layer, e.start),
    }
    doc.events.sort(key=keys[key])


# ------------------------------------------------------------------ structure
def split_event(doc: Document, index: int, at_ms: Optional[int] = None, at_char: Optional[int] = None) -> int:
    e = doc.events[index]
    a, b = e.copy(), e.copy()
    if at_ms is None:
        at_ms = (e.start + e.end) // 2
    if at_char is not None:
        a.text, b.text = e.text[:at_char].rstrip(), e.text[at_char:].lstrip()
    a.end = b.start = at_ms
    doc.events[index:index + 1] = [a, b]
    return index + 1


def merge_events(doc: Document, indices: Sequence[int], sep: str = "\\N") -> int:
    idx = sorted(set(indices))
    if len(idx) < 2:
        return idx[0] if idx else -1
    first = doc.events[idx[0]]
    first.text = sep.join(doc.events[i].text for i in idx)
    first.start = min(doc.events[i].start for i in idx)
    first.end = max(doc.events[i].end for i in idx)
    for i in reversed(idx[1:]):
        del doc.events[i]
    return idx[0]


def merge_duplicates(doc: Document) -> int:
    """Merge consecutive events with identical text/style that touch or overlap."""
    out, n = [], 0
    for e in sorted(doc.events, key=lambda e: (e.start, e.end)):
        if out and not e.comment and not out[-1].comment and out[-1].text == e.text \
                and out[-1].style == e.style and e.start <= out[-1].end:
            out[-1].end = max(out[-1].end, e.end)
            n += 1
        else:
            out.append(e)
    doc.events = out
    return n


def remove_empty(doc: Document) -> int:
    before = len(doc.events)
    doc.events = [e for e in doc.events if e.comment or strip_tags(e.text).strip()]
    return before - len(doc.events)


def duplicate_events(doc: Document, indices: Sequence[int]) -> list[int]:
    new = []
    for i in sorted(indices, reverse=True):
        doc.events.insert(i + 1, doc.events[i].copy())
        new.append(i + 1)
    return sorted(new)


# ------------------------------------------------------------------ text tools
def search_replace(doc: Document, find: str, repl: str, field: str = "text", regex=False,
                   ignore_case=False, whole_word=False, sel=None) -> int:
    flags = re.I if ignore_case else 0
    pat = find if regex else re.escape(find)
    if whole_word:
        pat = r"\b" + pat + r"\b"
    rx = re.compile(pat, flags | re.UNICODE)
    n = 0
    for i in _idx(doc, sel):
        e = doc.events[i]
        old = getattr(e, field)
        new, k = rx.subn(repl, old)
        if k:
            setattr(e, field, new)
            n += k
    return n


def strip_all_tags(doc: Document, sel=None, keep_breaks=True) -> None:
    for i in _idx(doc, sel):
        e = doc.events[i]
        e.text = BLOCK.sub("", e.text)
        if not keep_breaks:
            e.text = e.text.replace("\\N", " ").replace("\\n", " ")


def tr_upper(s: str) -> str:
    return s.replace("i", "İ").replace("ı", "I").upper()


def tr_lower(s: str) -> str:
    return s.replace("İ", "i").replace("I", "ı").lower()


def change_case(doc: Document, mode: str, turkish=True, sel=None) -> None:
    """mode: upper | lower | title | sentence. Tags in {} are untouched."""
    up = tr_upper if turkish else str.upper
    lo = tr_lower if turkish else str.lower

    def conv(chunk: str) -> str:
        if mode == "upper":
            return up(chunk)
        if mode == "lower":
            return lo(chunk)
        if mode == "title":
            return re.sub(r"(\w)(\w*)", lambda m: up(m.group(1)) + lo(m.group(2)), chunk, flags=re.UNICODE)
        if mode == "sentence":
            out, start = [], True
            for ch in chunk:
                if start and ch.isalpha():
                    out.append(up(ch))
                    start = False
                else:
                    out.append(lo(ch))
                    if ch in ".!?…" or ch == "\n":
                        start = True
            return "".join(out)
        return chunk

    for i in _idx(doc, sel):
        e = doc.events[i]
        parts = re.split(r"(\{[^}]*\}|\\N|\\n|\\h)", e.text)
        e.text = "".join(p if (p.startswith("{") or p in ("\\N", "\\n", "\\h")) else conv(p) for p in parts)


def fix_common_errors(doc: Document, sel=None) -> int:
    """Whitespace/punctuation clean-ups (SE 'Fix common errors' subset)."""
    n = 0
    rules = [
        (r"[ \t]{2,}", " "),
        (r"\s+([,.;:!?…])", r"\1"),
        (r"\.\.\.(?!\.)", "…"),
        (r"^\s+|\s+$", ""),
        (r"\\N\s+", r"\\N"),
        (r"\s+\\N", r"\\N"),
        (r"(\\N){2,}", r"\\N"),
    ]
    for i in _idx(doc, sel):
        e = doc.events[i]
        old = e.text
        parts = re.split(r"(\{[^}]*\})", e.text)
        for k, p in enumerate(parts):
            if p.startswith("{"):
                continue
            for pat, rep in rules:
                p = re.sub(pat, rep, p)
            parts[k] = p
        e.text = "".join(parts).strip()
        if e.text != old:
            n += 1
    return n


def balance_lines(text: str, max_chars: int = 42) -> str:
    """Auto-break plain text into at most two balanced lines at a space (keeps tags)."""
    plain = strip_tags(text)
    if "\\N" in text or len(plain) <= max_chars:
        return text
    spaces = [m.start() for m in re.finditer(" ", text)]
    if not spaces:
        return text
    mid = len(text) / 2
    best = min(spaces, key=lambda p: abs(p - mid))
    return text[:best] + "\\N" + text[best + 1:]


def auto_break(doc: Document, max_chars=42, sel=None) -> int:
    n = 0
    for i in _idx(doc, sel):
        e = doc.events[i]
        new = balance_lines(e.text, max_chars)
        if new != e.text:
            e.text, n = new, n + 1
    return n

@dataclass
class Issue:
    index: int
    kind: str
    message: str


def check(doc: Document, max_cps: float = 20, max_cpl: int = 42, min_dur: int = 500, max_dur: int = 8000,
          max_lines: int = 2, min_gap: int = 0) -> list[Issue]:
    issues: list[Issue] = []
    styles = {s.name for s in doc.styles}
    dialog = [(i, e) for i, e in enumerate(doc.events) if not e.comment]
    for i, e in dialog:
        text = strip_tags(e.text)
        lines = text.split("\n")
        chars = len(text.replace("\n", ""))
        if e.end <= e.start:
            issues.append(Issue(i, "timing", "end time is not after start time"))
        if e.duration and e.duration < min_dur:
            issues.append(Issue(i, "short", f"duration {e.duration}ms < {min_dur}ms"))
        if e.duration > max_dur:
            issues.append(Issue(i, "long", f"duration {e.duration}ms > {max_dur}ms"))
        if e.duration > 0 and chars / (e.duration / 1000) > max_cps:
            issues.append(Issue(i, "cps", f"{chars / (e.duration / 1000):.1f} chars/s > {max_cps}"))
        if any(len(l) > max_cpl for l in lines):
            issues.append(Issue(i, "cpl", f"line longer than {max_cpl} chars"))
        if len(lines) > max_lines:
            issues.append(Issue(i, "lines", f"{len(lines)} lines (max {max_lines})"))
        if not text.strip():
            issues.append(Issue(i, "empty", "empty text"))
        if e.style not in styles:
            issues.append(Issue(i, "style", f"unknown style '{e.style}'"))
        if re.search(r"[ \t]{2,}", text) or text != text.strip():
            issues.append(Issue(i, "whitespace", "extra whitespace"))
        if e.text.count("{") != e.text.count("}"):
            issues.append(Issue(i, "tags", "unbalanced override braces"))
    by_start = sorted(dialog, key=lambda p: (p[1].start, p[1].end))
    for (ia, a), (ib, b) in zip(by_start, by_start[1:]):
        if a.style == b.style and a.layer == b.layer and a.end > b.start and not (a.effect or b.effect):
            issues.append(Issue(ia, "overlap", f"overlaps line {ib + 1}"))
        elif 0 < b.start - a.end < min_gap:
            issues.append(Issue(ia, "gap", f"gap to next line {b.start - a.end}ms"))
    return sorted(issues, key=lambda x: x.index)


# ------------------------------------------------------------------ selection / post-processing
def select_lines(doc: Document, pattern: str, field: str = "text", regex: bool = False, case: bool = False,
                 invert: bool = False, include_comments: bool = True) -> list[int]:
    flags = 0 if case else re.I
    rx = re.compile(pattern if regex else re.escape(pattern), flags)
    out = []
    for i, e in enumerate(doc.events):
        if e.comment and not include_comments:
            continue
        hit = bool(rx.search(getattr(e, field)))
        if hit != invert:
            out.append(i)
    return out


def timing_postprocess(doc: Document, lead_in=0, lead_out=0, join_gap=0, keyframes: Sequence[int] = (),
                       kf_before=0, kf_after=0, sel=None) -> int:
    """Aegisub-style timing post-processor. Returns number of modified events."""
    idx = sorted(_idx(doc, sel), key=lambda i: (doc.events[i].start, doc.events[i].end))
    idx = [i for i in idx if not doc.events[i].comment]
    orig = [(doc.events[i].start, doc.events[i].end) for i in idx]
    for k, i in enumerate(idx):
        e = doc.events[i]
        prev_end = doc.events[idx[k - 1]].end if k else 0
        nxt_start = doc.events[idx[k + 1]].start if k + 1 < len(idx) else None
        e.start = max(prev_end if prev_end <= e.start else 0, e.start - lead_in, 0)
        e.end = e.end + lead_out
        if nxt_start is not None and e.end > nxt_start:
            e.end = max(nxt_start, e.start + 1)
    for k in range(len(idx) - 1):
        a, b = doc.events[idx[k]], doc.events[idx[k + 1]]
        if join_gap and 0 < b.start - a.end <= join_gap:
            mid = (a.end + b.start) // 2
            a.end = b.start = mid
    if keyframes and (kf_before or kf_after):
        snap_to_keyframes(doc, keyframes, idx, kf_before, kf_after, kf_before, kf_after)
    return sum(1 for k, i in enumerate(idx) if (doc.events[i].start, doc.events[i].end) != orig[k])

def remove_hearing_impaired(doc: Document, sel=None) -> int:
    """Remove [sound], (sound), ♪ lines and 'NAME:' speaker labels; delete lines that become empty."""
    n = 0
    pats = [r"\[[^\]]*\]", r"\([^)]*\)", r"^[♪♫#\s]+$", r"^\s*[A-ZÇĞİÖŞÜ][A-ZÇĞİÖŞÜ0-9 .'-]{1,24}:\s*"]
    for i in _idx(doc, sel):
        e = doc.events[i]
        if e.comment:
            continue
        old = e.text
        parts = re.split(r"(\{[^}]*\})", e.text)
        for k, p in enumerate(parts):
            if p.startswith("{"):
                continue
            for pat in pats:
                p = re.sub(pat, "", p, flags=re.M)
            parts[k] = p
        e.text = re.sub(r"(\\N)+$|^(\\N)+", "", "".join(parts).strip()).strip()
        if e.text != old:
            n += 1
    remove_empty(doc)
    return n


def fix_mojibake(doc: Document, sel=None) -> int:
    """Repair UTF-8 text that was decoded as cp1252/cp1254 (e.g. 'Ã¼' -> 'ü')."""
    n = 0
    for i in _idx(doc, sel):
        e = doc.events[i]
        if not any(c in e.text for c in "ÃÄÅ"):
            continue
        for enc in ("cp1252", "cp1254", "latin-1"):
            try:
                fixed = e.text.encode(enc).decode("utf-8")
            except (UnicodeEncodeError, UnicodeDecodeError):
                continue
            e.text, n = fixed, n + 1
            break
    return n


def statistics(doc: Document) -> dict:
    ev = [e for e in doc.events if not e.comment]
    total_chars = sum(len(strip_tags(e.text).replace("\n", "")) for e in ev)
    total_dur = sum(e.duration for e in ev)
    cps = [len(strip_tags(e.text).replace("\n", "")) / (e.duration / 1000) for e in ev if e.duration > 0]
    return {
        "lines": len(ev), "comments": len(doc.events) - len(ev), "chars": total_chars,
        "avg_cps": round(sum(cps) / len(cps), 2) if cps else 0.0, "max_cps": round(max(cps), 2) if cps else 0.0,
        "total_duration_s": round(total_dur / 1000, 2),
        "span_s": round((max(e.end for e in ev) - min(e.start for e in ev)) / 1000, 2) if ev else 0.0,
        "styles": len({e.style for e in ev}),
    }


def append_document(doc: Document, other: Document, offset_ms: Optional[int] = None, import_styles: bool = True) -> int:
    """Append another document's events (Subtitle Edit 'join'). offset defaults to the end of `doc`."""
    if offset_ms is None:
        offset_ms = max((e.end for e in doc.events), default=0)
    have = {s.name for s in doc.styles}
    if import_styles:
        from dataclasses import replace
        doc.styles += [replace(s) for s in other.styles if s.name not in have]
    for e in other.events:
        c = e.copy()
        c.start += offset_ms
        c.end += offset_ms
        doc.events.append(c)
    return len(other.events)


def split_document(doc: Document, at_ms: int) -> tuple[Document, Document]:
    """Split into two documents at a time; the second part is re-based to zero."""
    from dataclasses import replace
    a, b = Document(), Document()
    for d in (a, b):
        d.info = list(doc.info)
        d.styles = [replace(s) for s in doc.styles]
    for e in doc.events:
        if e.start < at_ms:
            a.events.append(e.copy())
        else:
            c = e.copy()
            c.start -= at_ms
            c.end -= at_ms
            b.events.append(c)
    return a, b

"""Subtitle format readers/writers. Everything converts to/from core.ass.Document."""
from __future__ import annotations
import os
import re
from ..core.ass import Document, Event, decode_bytes
from ..core.timeutil import parse_srt_time, format_srt_time, format_vtt_time
from ..core.tags import srt_to_ass_text, ass_to_srt_text

_ARROW = re.compile(r"(\d+:\d+:\d+[,.]\d+|\d+:\d+[,.]\d+)\s*-->\s*(\d+:\d+:\d+[,.]\d+|\d+:\d+[,.]\d+)")


def _ts(s: str) -> int:
    if s.count(":") == 1:
        s = "00:" + s
    return parse_srt_time(s)


def parse_srt(text: str, vtt: bool = False) -> Document:
    doc = Document.new()
    doc.info = [(k, v) for k, v in doc.info if k != "Title"] + [("Title", "Imported")]
    doc.set_info("PlayResX", "1280")
    doc.set_info("PlayResY", "720")
    doc.styles[0].fontsize = 40
    text = text.lstrip("\ufeff").replace("\r\n", "\n").replace("\r", "\n")
    for block in re.split(r"\n\s*\n", text):
        lines = [l for l in block.split("\n")]
        for i, l in enumerate(lines):
            m = _ARROW.search(l)
            if m:
                body = "\n".join(lines[i + 1:]).strip("\n")
                if vtt:
                    body = re.sub(r"<\d+:\d+[:.]\d+(?:\.\d+)?>", "", body)
                    body = re.sub(r"</?c[^>]*>", "", body)
                    body = re.sub(r"</?v[^>]*>", "", body)
                if not body.strip():
                    break
                doc.events.append(Event(start=_ts(m.group(1)), end=_ts(m.group(2)),
                                        text=srt_to_ass_text(body)))
                break
    return doc


def dump_srt(doc: Document) -> str:
    out = []
    n = 0
    for e in sorted((e for e in doc.events if not e.comment), key=lambda e: (e.start, e.end)):
        n += 1
        out.append(f"{n}\n{format_srt_time(e.start)} --> {format_srt_time(e.end)}\n{ass_to_srt_text(e.text)}\n")
    return "\n".join(out)


def dump_vtt(doc: Document) -> str:
    out = ["WEBVTT\n"]
    for e in sorted((e for e in doc.events if not e.comment), key=lambda e: (e.start, e.end)):
        out.append(f"{format_vtt_time(e.start)} --> {format_vtt_time(e.end)}\n{ass_to_srt_text(e.text)}\n")
    return "\n".join(out)


def dump_txt(doc: Document) -> str:
    from ..core.tags import strip_tags
    return "\n".join(strip_tags(e.text) for e in doc.events if not e.comment) + "\n"


def load_any(path: str) -> Document:
    data = open(path, "rb").read()
    text = decode_bytes(data)
    ext = os.path.splitext(path)[1].lower()
    if ext in (".ass", ".ssa") or text.lstrip("\ufeff").lstrip().startswith("[Script Info]"):
        doc = Document.parse(text)
    elif ext == ".vtt" or text.lstrip("\ufeff").startswith("WEBVTT"):
        doc = parse_srt(text, vtt=True)
    else:
        doc = parse_srt(text)
    doc.filename = path if ext in (".ass", ".ssa") else None
    return doc


def save_any(doc: Document, path: str) -> None:
    ext = os.path.splitext(path)[1].lower()
    if ext in (".ass", ".ssa"):
        doc.save(path)
    elif ext == ".srt":
        open(path, "w", encoding="utf-8-sig", newline="\r\n").write(dump_srt(doc))
    elif ext == ".vtt":
        open(path, "w", encoding="utf-8", newline="\n").write(dump_vtt(doc))
    elif ext == ".txt":
        open(path, "w", encoding="utf-8", newline="\n").write(dump_txt(doc))
    else:
        raise ValueError(f"unsupported output format: {ext}")

    def selected_rows(self) -> list[int]:
        return sorted({i.row() for i in self.table.selectionModel().selectedRows()})

    def current_row(self) -> int:
        rows = self.selected_rows()
        if rows:
            return rows[0]
        idx = self.table.currentIndex()
        return idx.row() if idx.isValid() else -1

    def commit(self, label: str):
        self._commit_timer.stop()
        self.history.commit(label)
        self._refresh_keep_selection()
        self._update_title()

    def _refresh_keep_selection(self):
        from PySide6.QtCore import QItemSelectionModel
        rows, cur = self.selected_rows(), self.table.currentIndex().row()
        sm = self.table.selectionModel()
        sm.blockSignals(True)
        self.model.refresh()
        n = len(self.doc.events)
        for r in rows:
            if r < n:
                sm.select(self.model.index(r, 0), QItemSelectionModel.Select | QItemSelectionModel.Rows)
        if 0 <= cur < n:
            sm.setCurrentIndex(self.model.index(cur, 0), QItemSelectionModel.NoUpdate)
        sm.blockSignals(False)

    def mutate(self, label: str, fn, select=None):
        self._flush_edit()
        fn(self.doc)
        self.commit(label)
        if select is not None:
            self.select_rows(select)

    def _flush_edit(self):
        if self._commit_timer.isActive():
            self.commit("Düzenleme")

    def select_rows(self, rows):
        sm = self.table.selectionModel()
        sm.clearSelection()
        from PySide6.QtCore import QItemSelectionModel
        for r in rows:
            if 0 <= r < len(self.doc.events):
                sm.select(self.model.index(r, 0), QItemSelectionModel.Select | QItemSelectionModel.Rows)
        if rows:
            self.table.setCurrentIndex(self.model.index(rows[0], 0))
            self.table.scrollTo(self.model.index(rows[0], 0))

    def _update_title(self):
        name = os.path.basename(self.doc.filename) if self.doc.filename else "Adsız"
        self.setWindowTitle(f"{name}{'*' if self.history.dirty else ''} — {APP}")

        self.statusBar().showMessage(msg, ms)

        if not self.history.dirty:
            return True

    def open_dialog(self):
        p, _ = QFileDialog.getOpenFileName(self, "Altyazı aç", self.settings.value("last_dir", ""), OPEN_FILTER)
        if p:
            self.open_path(p)

    def open_path(self, path: str):
        if not self._confirm_discard():
            return
        try:
            doc = load_any(path)
        except Exception as e:
            QMessageBox.critical(self, APP, f"Açılamadı:\n{e}")
            return
        self.settings.setValue("last_dir", os.path.dirname(path))
        self._remember(path)
        if not doc.filename:
            doc.filename = None
        self.set_document(doc)
        self._import_path = path
        self.status(f"Açıldı: {path}")
        self._restore_project_media(doc, path)

    def autosave(self):
        if not self.history.dirty:
            return
        import time
        d = os.path.expanduser("~/.osisub/autosave")
        name = os.path.splitext(os.path.basename(self.doc.filename or "untitled"))[0]
        try:
            os.makedirs(d, exist_ok=True)
            self.doc.save(os.path.join(d, f"{name}.{time.strftime('%Y%m%d-%H%M%S')}.autosave.ass"), set_filename=False)
        except OSError:
            return
        self.status("Otomatik kaydedildi")

    def _restore_project_media(self, doc, path):
        vf = doc.get_garbage("Video File")
        if not vf or not media.available():
            return
        base = os.path.dirname(path)
        for cand in (vf, os.path.join(base, vf), os.path.join(base, os.path.basename(vf))):
            if cand.startswith("?script"):
                cand = base + cand[len("?script"):]
            if os.path.isfile(cand):
                self.load_video(cand)
                try:
                    self.wave.pos_ms = int(doc.get_garbage("Video Position", "0"))
                except ValueError:
                    pass
                return

    def _store_project_media(self):
        if self.video:
            self.doc.set_garbage("Video File", self.video.path)
            if self.video.has_audio:
                self.doc.set_garbage("Audio File", self.video.path)
        row = self.current_row()
        if row >= 0:
            self.doc.set_garbage("Active Line", str(row))

    def save(self):
        self._flush_edit()
        self._store_project_media()
        if not self.doc.filename:
            return self.save_as()
        if os.path.exists(self.doc.filename):
            try:
                import shutil
                shutil.copy2(self.doc.filename, self.doc.filename + ".bak")
            except OSError:
                pass
        self.doc.save()
        self.history.mark_saved()
        self._update_title()
        self.status("Kaydedildi")

    def save_as(self):
        self._flush_edit()
        self._store_project_media()
        p, flt = QFileDialog.getSaveFileName(self, "Farklı kaydet", self.settings.value("last_dir", ""),
                                             "ASS (*.ass);;SRT (*.srt);;WebVTT (*.vtt);;Metin (*.txt)")
        if not p:
            return
        ext = {"ASS": ".ass", "SRT": ".srt", "WebVTT": ".vtt", "Metin": ".txt"}.get(flt.split(" ")[0], ".ass")
        if not os.path.splitext(p)[1]:
            p += ext
        save_any(self.doc, p)
        if p.lower().endswith(".ass"):
            self.doc.filename = p
            self.history.mark_saved()
        self._update_title()
        self.status(f"Kaydedildi: {p}")

    def closeEvent(self, e):
        self.stop_play()
        if not self._confirm_discard():
            e.ignore()
            return
        self.settings.setValue("w", self.width()); self.settings.setValue("h", self.height())
        e.accept()

    # ------------------------------------------------------------ edit panel
    def _fill_styles(self):
        self.e_style.blockSignals(True)
        self.e_style.clear()
        self.e_style.addItems([s.name for s in self.doc.styles])
        self.e_style.blockSignals(False)

    def _selection_changed(self, *_):
        row = self.current_row()
        self._load_edit(row)

    def _load_edit(self, row: int):
        self._loading_edit = True
        try:
            ok = 0 <= row < len(self.doc.events)
            for w in (self.e_text, self.e_start, self.e_end, self.e_style, self.e_actor, self.e_effect, self.e_layer, self.e_comment):
                w.setEnabled(ok)
            if not ok:
                self.e_text.setPlainText("")
                return
            e = self.doc.events[row]
            self.e_text.setPlainText(e.text)
            self.e_start.set_ms(e.start); self.e_end.set_ms(e.end)
            self.e_actor.setText(e.actor); self.e_effect.setText(e.effect); self.e_layer.setValue(e.layer)
            self.e_comment.setChecked(e.comment)
            i = self.e_style.findText(e.style)
            if i < 0:
                self.e_style.addItem(e.style); i = self.e_style.findText(e.style)
            self.e_style.setCurrentIndex(i)
            self._update_info(row)
            self.wave.set_events(self.doc.events, row)
            self._set_wave_kara(row)
            self.wave.pos_ms = e.start
            self.wave.center_on(e.start)
        finally:
            self._loading_edit = False
        self._refresh_preview()
        self._update_reference()

    def _set_wave_kara(self, row):
        e = self.doc.events[row] if 0 <= row < len(self.doc.events) else None
        if e and assutil.has_karaoke(e.text):
            durs = assutil.kara_durations(e.text)
            texts = assutil.kara_syllable_texts(e.text)
            first = assutil.parse_syllables(e.text)[0]
            if first["text"] or True:
                self.wave.set_kara(row, durs, texts[: len(durs)])
                return
        self.wave.set_kara(-1, [], [])

    def _wave_kara(self, idx, durs):
        e = self.doc.events[idx]
        e.text = assutil.set_kara_durations(e.text, durs)
        self._loading_edit = True
        self.e_text.setPlainText(e.text)
        self._loading_edit = False
        self.model.refresh_row(idx)
        self._update_title_dirty()
        self._commit_timer.start()

    def _update_info(self, row):
        e = self.doc.events[row]
        self.e_dur.setText(f"{e.duration / 1000:.2f} s")
        self.e_cps.setText(f"{self.model.cps(row):.1f} CPS")

    def _edit_field(self, field: str, value):
        if self._loading_edit:
            return
        row = self.current_row()
        if row < 0:
            return
        rows = self.selected_rows() or [row]
        for r in rows:
            setattr(self.doc.events[r], field, value)
        self._after_edit(rows)

    def _edit_text(self):
        if self._loading_edit:
            return
        row = self.current_row()
        if row < 0:
            return
        text = self.e_text.toPlainText().replace("\n", "\\N")
        if text != self.doc.events[row].text:
            self.doc.events[row].text = text
            self._after_edit([row])

    def _edit_time(self, is_start: bool, ms: int):
        row = self.current_row()
        if row < 0:
            return
        e = self.doc.events[row]
        if is_start:
            e.start = ms
        else:
            e.end = ms
        self._after_edit([row])
        self.e_start.set_ms(e.start); self.e_end.set_ms(e.end)

    def _after_edit(self, rows):
        self._commit_timer.start()
        for r in rows:
            self.model.refresh_row(r)
        self._update_info(rows[0])
        self.wave.set_events(self.doc.events, self.current_row())
        self._refresh_preview()
        self._update_title_dirty()

    def _update_title_dirty(self):
        name = os.path.basename(self.doc.filename) if self.doc.filename else "Adsız"
        self.setWindowTitle(f"{name}* — {APP}")

    def insert_tag(self, tag: str):
        self.e_text.textCursor().insertText("{" + tag + "}")
        self.e_text.setFocus()

    def _refresh_preview(self):
        row = self.current_row()
        ms = self.doc.events[row].start if 0 <= row < len(self.doc.events) else 0
        if 0 <= row < len(self.doc.events):
            e = self.doc.events[row]
            ms = e.start + min(e.duration // 2, 500)
        self.preview.request(self._frame_ass(ms), ms, self.doc.res)

    def _frame_ass(self, ms: int) -> str:
        """ASS text restricted to events visible at `ms` (keeps preview fast for huge files)."""
        if len(self.doc.events) < 500:
            return self.doc.dumps()
        sub = Document()
        sub.info, sub.styles, sub.attachments = self.doc.info, self.doc.styles, self.doc.attachments
        sub.events = [e for e in self.doc.events if e.start <= ms < e.end]
        return sub.dumps()

    # ------------------------------------------------------------ structural edits
    def insert_line(self):
        self._flush_edit()
        row = self.current_row()
        base = self.doc.events[row] if row >= 0 else None
        ev = Event(start=base.end if base else 0, end=(base.end + 2000) if base else 2000,
                   style=base.style if base else self.doc.styles[0].name)
        at = row + 1 if row >= 0 else len(self.doc.events)
        self.doc.events.insert(at, ev)
        self.commit("Satır ekle")
        self.select_rows([at])
        self.e_text.setFocus()

    def duplicate(self):
        rows = self.selected_rows()
        if rows:
            self._flush_edit()
            new = tools.duplicate_events(self.doc, rows)
            self.commit("Çoğalt")
            self.select_rows(new)

    def delete_lines(self):
        rows = self.selected_rows()
        if not rows:
            return
        self._flush_edit()
        for r in reversed(rows):
            del self.doc.events[r]
        self.commit("Sil")
        self.select_rows([min(rows[0], len(self.doc.events) - 1)])

    def merge_lines(self):
        rows = self.selected_rows()
        if len(rows) > 1:
            self._flush_edit()
            first = tools.merge_events(self.doc, rows)
            self.commit("Birleştir")
            self.select_rows([first])

    def split_line(self):
        row = self.current_row()
        if row < 0:
            return
        self._flush_edit()
        pos = self.e_text.textCursor().position()
        text = self.doc.events[row].text
        pos = max(1, min(pos, len(text) - 1)) if len(text) > 1 else None
        tools.split_event(self.doc, row, at_char=pos)
        self.commit("Böl")
        self.select_rows([row + 1])

    def undo(self):
        self._commit_timer.stop() if False else None
        self._flush_edit()
        if self.history.undo():
            self._after_history()

    def redo(self):
        if self.history.redo():
            self._after_history()

    def _after_history(self):
        row = self.current_row()
        self._refresh_keep_selection()
        self._fill_styles()
        self._load_edit(min(row, len(self.doc.events) - 1))
        self._update_title()

    # ------------------------------------------------------------ text tools
    def _sel_or_all(self):
        rows = self.selected_rows()
        return rows if len(rows) > 1 else None

    def case(self, mode):
        sel = self._sel_or_all()

        sel = self._sel_or_all()
        self.mutate("Etiket temizle", lambda d: tools.strip_all_tags(d, sel))
        self._load_edit(self.current_row())

        n = [0]
        self.mutate("Hata düzelt", lambda d: n.__setitem__(0, tools.fix_common_errors(d, self._sel_or_all())))
        self.status(f"{n[0]} satır düzeltildi"); self._load_edit(self.current_row())

    def find_replace(self):
        dlg = FindReplaceDialog(self)

        def do_all():
            sel = self.selected_rows() if dlg.sel_only.isChecked() else None
            cnt = [0]
            try:
                self.mutate("Değiştir", lambda d: cnt.__setitem__(0, tools.search_replace(
                    d, dlg.find.text(), dlg.repl.text(), dlg.field.currentText(), dlg.regex.isChecked(),
                    dlg.case.isChecked(), dlg.word.isChecked(), sel)))
            except Exception as e:
                QMessageBox.warning(dlg, APP, f"Hata: {e}")
                return
            self.status(f"{cnt[0]} değişiklik yapıldı")
            self._load_edit(self.current_row())

        def find_next():
            import re
            pat = dlg.find.text()
            if not pat:
                return
            flags = re.I if dlg.case.isChecked() else 0
            try:
                rx = re.compile(pat if dlg.regex.isChecked() else re.escape(pat), flags)
            except re.error:
                return
            start = self.current_row() + 1
            n = len(self.doc.events)
            for k in range(n):
                r = (start + k) % n
                if rx.search(getattr(self.doc.events[r], dlg.field.currentText())):
                    self.select_rows([r]); return
            self.status("Bulunamadı")

        dlg.btn_all.clicked.connect(do_all)
        dlg.btn_next.clicked.connect(find_next)
        dlg.show()
        self._fr = dlg

    def load_video(self, p: str):
        if not media.available():
            QMessageBox.warning(self, APP, "ffmpeg/ffprobe bulunamadı.")

        try:
            info = media.probe(p)

        self.video = info
        self.fps = info.fps
        self.engine.fps.fps = info.fps
        self.engine.video_res = (info.width, info.height)
        self.engine.project_props["video_file"] = info.path
        self.engine.project_props["audio_file"] = info.path if info.has_audio else ""
        self.preview.video = info
        if self.doc.get_info("PlayResX") in ("", "0"):
            self.doc.set_info("PlayResX", str(info.width)); self.doc.set_info("PlayResY", str(info.height))
        self.status(f"Video: {info.width}x{info.height} @ {info.fps:.3f} fps")
        self.load_audio()
        threading.Thread(target=lambda: self._peak_sig.keyframes.emit(media.keyframes(p)), daemon=True).start()
        self._refresh_preview()

        if not res.ok:

                self.status("Betik iptal edildi")
            else:
                self.log_view.appendPlainText(res.error)
                self.log_dock.show()

        self.doc.info, self.doc.styles, self.doc.events = res.document.info, res.document.styles, res.document.events

        self._fill_styles()
        if res.selection:

    def _progress_begin(self, title):
        dlg = QProgressDialog(title, "İptal", 0, 100, self)
        dlg.setWindowModality(Qt.WindowModal)
        dlg.setMinimumDuration(400)
        dlg.canceled.connect(lambda: setattr(self.engine, "cancel_flag", True))
        self._progress = dlg

        def handler(kind, v):
            if kind == "set":
                dlg.setValue(int(max(0, min(100, v))))
            elif kind in ("task", "title"):
                dlg.setLabelText(str(v))
            QApplication.processEvents()
        self.engine.progress_handler = handler

    def _progress_end(self):
        if self._progress:
            self._progress.reset()
            self._progress = None
        self.engine.progress_handler = None

    def run_macro(self, mac):
        self._flush_edit()
        sel = self.selected_rows()
        self.engine.clipboard_text = QApplication.clipboard().text()
        if not self.engine.validate_macro(mac, self.doc, sel, self.current_row()):
            self.status("Bu makro mevcut seçim için geçerli değil"); return
        self._progress_begin(mac.name)
        try:
            res = self.engine.run_macro(mac, self.doc, sel, self.current_row())
        finally:
            self._progress_end()
        QApplication.clipboard().setText(self.engine.clipboard_text)
        self._apply_result(mac.name, res)

        try:
            res = self.engine.run_filter(flt, self.doc, cfg)
        finally:
            self._progress_end()
        self._apply_result(flt.name, res)

            if p.lower().endswith(".lua"):
                self.engine.load_script(p); self.rebuild_automation_menu(); return

    def join_file(self):
        p, _ = QFileDialog.getOpenFileName(self, "Eklenecek altyazı", self.settings.value("last_dir", ""), OPEN_FILTER)
        if not p:
            return
        other = load_any(p)
        off, ok = QInputDialog.getInt(self, "Birleştir", "Zaman kayması (ms, boş=sonuna ekle):",
                                      max((e.end for e in self.doc.events), default=0), 0, 10**9)
        if ok:
            n = [0]
            self.mutate("Dosya ekle", lambda d: n.__setitem__(0, tools.append_document(d, other, off)))
            self._fill_styles(); self.status(f"{n[0]} satır eklendi")

    def split_file(self):
        t, ok = QInputDialog.getText(self, "Böl", "Bölme zamanı (H:MM:SS.cc):", text=format_ass_time(self.wave.pos_ms))
        if not ok:
            return
        a, b = tools.split_document(self.doc, parse_ass_time(t))
        base = self.doc.filename or os.path.join(self.settings.value("last_dir", ""), "split.ass")
        root, _ = os.path.splitext(base)
        a.save(root + ".part1.ass", set_filename=False); b.save(root + ".part2.ass", set_filename=False)
        self.status(f"Yazıldı: {root}.part1.ass / .part2.ass")

    def goto_line(self):

        if ok:
            self.select_rows([n - 1])

    # ------------------------------------------------------------ playback / pick / reference
    def play_line(self):
        row = self.current_row()
        if row < 0 or not self.video or not AudioPlayer.available():
            self.status("Çalmak için video açın (ffplay gerekir)"); return
        e = self.doc.events[row]
        self.player.play(self.video.path, e.start, e.end)
        self.play_timer.start()

    def stop_play(self):
        self.player.stop()
        self.play_timer.stop()
        if self.playback:
            self.playback.stop()
            self.playback = None

    def toggle_video(self):
        if self.playback or self.player.playing:
            self.stop_play(); return
        if not self.video or not media.available():
            self.status("Önce video açın"); return
        self._flush_edit()
        start = self.wave.pos_ms
        w = max(320, min(self.preview.width(), 960))
        self.playback = VideoPlayback(self.video, self.doc.dumps(), start, w, self._on_video_frame, self._on_video_done)
        if AudioPlayer.available():
            self.player.play(self.video.path, start, 0)
        self.play_timer.start()

    def _on_video_frame(self, img, ms):
        self.preview.show_image(img)

    def _on_video_done(self):
        self.playback = None
        self.player.stop()
        self.play_timer.stop()

    def step_frames(self, n):
        step = 1000.0 / (self.fps or 23.976)
        self.wave.pos_ms = max(0, int(round(self.wave.pos_ms + n * step)))
        self.wave.update()
        self.preview.request(self._frame_ass(self.wave.pos_ms), self.wave.pos_ms, self.doc.res)

    def end_and_next(self):
        row = self.current_row()
        if row < 0:
            return
        e = self.doc.events[row]
        e.end = max(self.wave.pos_ms, e.start)
        self.commit("Bitiş")
        nxt = row + 1
        if nxt < len(self.doc.events):
            self.doc.events[nxt].start = e.end
            self.commit("Başlangıç")
            self.select_rows([nxt])
        else:
            self._load_edit(row)

    def _play_tick(self):
        if not self.player.playing:
            self.play_timer.stop(); return
        ms = self.player.position()
        self.wave.pos_ms = ms
        self.wave.center_on(ms)
        self._update_reference(ms)

    def toggle_pick(self):
        self.preview.pick_mode = self.pick_action.isChecked()
        self.preview.setCursor(Qt.CrossCursor if self.preview.pick_mode else Qt.ArrowCursor)

    def _set_ts_mode(self, mode):
        self.ts_mode = mode
        self._move_start = None
        self.preview.pick_mode = True
        self.pick_action.setChecked(True)
        self.toggle_pick()

    def _set_tag(self, row, name, value):
        """Insert or replace an override tag like \\pos(...) in the first block of the line."""
        import re
        e = self.doc.events[row]
        tag = "\\" + name + "(" + value + ")"
        rx = re.compile(r"\\" + name + r"\([^)]*\)")
        if name in ("clip", "iclip"):
            e.text = re.sub(r"\\i?clip\([^)]*\)", "", e.text)
        if rx.search(e.text):
            e.text = rx.sub(lambda m: tag, e.text, count=1)
        elif e.text.startswith("{"):
            e.text = "{" + tag + e.text[1:]
        else:
            e.text = "{" + tag + "}" + e.text
        self.commit(name)
        self._load_edit(row)

    def _preview_clicked(self, x, y):
        row = self.current_row()
        if row < 0:
            return
        if self.ts_mode == "org":
            self._set_tag(row, "org", "%d,%d" % (round(x), round(y)))
        elif self.ts_mode == "move":
            if self._move_start is None:
                self._move_start = (x, y)
                self.status("\\move: bitiş noktasına tıkla")
            else:
                x0, y0 = self._move_start
                self._move_start = None
                import re
                e = self.doc.events[row]
                e.text = re.sub(r"\\pos\([^)]*\)", "", e.text)
                self._set_tag(row, "move", "%d,%d,%d,%d" % (round(x0), round(y0), round(x), round(y)))
        elif self.ts_mode in ("pos",):
            self._set_tag(row, "pos", "%d,%d" % (round(x), round(y)))

    def _preview_dragged(self, x0, y0, x1, y1):
        row = self.current_row()
        if row < 0 or self.ts_mode not in ("clip", "iclip"):
            if self.ts_mode == "pos":
                self._preview_clicked(x1, y1)
            return
        xa, xb = sorted((round(x0), round(x1)))
        ya, yb = sorted((round(y0), round(y1)))
        self._set_tag(row, self.ts_mode, "%d,%d,%d,%d" % (xa, ya, xb, yb))

    def open_reference(self):
        p, _ = QFileDialog.getOpenFileName(self, "Referans altyazı", self.settings.value("last_dir", ""), OPEN_FILTER)
        if p:
            self.ref_doc = load_any(p)
            self.ref_dock.show()
            self._update_reference()

    def _update_reference(self, ms=None):
        if self.ref_doc is None:
            return
        row = self.current_row()
        if ms is None:
            if row < 0:
                return
            e = self.doc.events[row]
            lo, hi = e.start, e.end
        else:
            lo = hi = ms
        from ..core.tags import strip_tags
        hits = [strip_tags(r.text) for r in self.ref_doc.events if not r.comment and r.start < max(hi, lo + 1) and r.end > lo]
        self.ref_view.setPlainText("\n---\n".join(hits))

    # ------------------------------------------------------------ table menu
    def _table_menu(self, pos):
        m = QMenu(self)
        for text, slot in (("Satır ekle", self.insert_line), ("Çoğalt", self.duplicate), ("Birleştir", self.merge_lines),
                           ("Sil", self.delete_lines)):
            self._act(m, text, slot)
        m.exec(self.table.viewport().mapToGlobal(pos))

def ass_to_qcolor(s: str) -> QColor:
    s = s.strip().lstrip("&Hh").rstrip("&")
    s = s.zfill(8)
    a, b, g, r = (int(s[i:i + 2], 16) for i in (0, 2, 4, 6))
    return QColor(r, g, b, 255 - a)


def qcolor_to_ass(c: QColor) -> str:
    return f"&H{255 - c.alpha():02X}{c.blue():02X}{c.green():02X}{c.red():02X}"


class ColorButton(QPushButton):
    def __init__(self, ass: str = "&H00FFFFFF", parent=None):
        super().__init__(parent)
        self.set_ass(ass)
        self.clicked.connect(self._pick)

    def set_ass(self, ass: str) -> None:
        self._ass = ass
        c = ass_to_qcolor(ass)
        self.setText(ass)
        self.setStyleSheet(f"background-color: rgb({c.red()},{c.green()},{c.blue()});"
                           f"color: {'black' if c.lightness() > 128 else 'white'};")

    def ass(self) -> str:
        return self._ass

    def _pick(self):
        c = QColorDialog.getColor(ass_to_qcolor(self._ass), self, "Renk", QColorDialog.ShowAlphaChannel)
        if c.isValid():
            self.set_ass(qcolor_to_ass(c))

class AutomationDialog(QDialog):
    """Builds a Qt dialog from an Aegisub Automation dialog description."""

    def __init__(self, controls, buttons, ids, parent=None, title="Otomasyon"):
        super().__init__(parent)
        self.setWindowTitle(title)
        self.controls = controls
        self.buttons = buttons
        self.ids = ids or {}
        self.widgets = {}
        self.clicked = False
        lay = QVBoxLayout(self)
        grid = QGridLayout()
        lay.addLayout(grid)
        for c in controls:
            cls = c.get("class")
            x, y = int(c.get("x", 0) or 0), int(c.get("y", 0) or 0)
            w, h = int(c.get("width", 1) or 1), int(c.get("height", 1) or 1)
            widget = None
            if cls == "label":
                widget = QLabel(str(c.get("label", "")))
            elif cls == "edit":
                widget = QLineEdit(str(c.get("text", ""))); widget.setToolTip(str(c.get("hint", "")))
            elif cls == "textbox":
                widget = QPlainTextEdit(str(c.get("text", ""))); widget.setMinimumHeight(20 * max(h, 2))
            elif cls == "intedit":
                widget = QSpinBox(); widget.setRange(int(c.get("min", -2**31)), int(c.get("max", 2**31 - 1)))
                widget.setValue(int(c.get("value", 0) or 0))
            elif cls == "floatedit":
                widget = QDoubleSpinBox(); widget.setDecimals(4)
                widget.setRange(float(c.get("min", -1e9)), float(c.get("max", 1e9)))
                widget.setSingleStep(float(c.get("step", 0.1) or 0.1)); widget.setValue(float(c.get("value", 0) or 0))
            elif cls == "checkbox":
                widget = QCheckBox(str(c.get("label", ""))); widget.setChecked(bool(c.get("value", False)))
            elif cls == "dropdown":
                widget = QComboBox()
                items = c.get("items") or {}
                widget.addItems([str(items[k]) for k in sorted(items)])
                widget.setCurrentText(str(c.get("value", "")))
            elif cls in ("color", "coloralpha", "alpha"):
                widget = ColorButton(str(c.get("value", c.get("text", "&H00FFFFFF"))) if cls != "color" or True else "")
            if widget is not None:
                if cls == "label" or cls == "checkbox":
                    pass
                grid.addWidget(widget, y, x, h, w)
                if c.get("name"):
                    self.widgets[c["name"]] = (cls, widget)
        bb = QDialogButtonBox()
        self.btns = {}
        for b in buttons:
            btn = bb.addButton(str(b), QDialogButtonBox.ActionRole)
            btn.clicked.connect(lambda _=False, name=b: self._press(name))
            self.btns[b] = btn
        lay.addWidget(bb)

    def _press(self, name):
        self.clicked = name
        cancel = self.ids.get("cancel")
        if name == cancel or str(name).lower() in ("cancel", "iptal"):
            self.reject()
        else:
            self.accept()

    def results(self):
        out = {}
        for name, (cls, w) in self.widgets.items():
            if cls in ("edit",):
                out[name] = w.text()
            elif cls == "textbox":
                out[name] = w.toPlainText()
            elif cls in ("intedit",):
                out[name] = int(w.value())
            elif cls == "floatedit":
                out[name] = float(w.value())
            elif cls == "checkbox":
                out[name] = w.isChecked()
            elif cls == "dropdown":
                out[name] = w.currentText()
            elif cls in ("color", "coloralpha", "alpha"):
                from ..automation.runtime import _color_result
                out[name] = _color_result(cls, w.ass())
        return out

class SpellDialog(QDialog):
    """Walks through the document line by line offering suggestions (Hunspell via spylls)."""

    def __init__(self, checker, doc, start_row, on_change, on_goto, parent=None):
        super().__init__(parent)
        self.setWindowTitle("Yazım denetimi")
        self.resize(520, 380)
        self.sc, self.doc, self.on_change, self.on_goto = checker, doc, on_change, on_goto
        self.row = max(0, start_row)
        self.cur = None  # (row, start, end, word)
        self.changed = False
        lay = QVBoxLayout(self)
        self.ctx = QLabel(); self.ctx.setWordWrap(True); self.ctx.setTextFormat(Qt.RichText)
        lay.addWidget(self.ctx)
        self.edit = QLineEdit(); lay.addWidget(self.edit)
        self.sugg = QListWidget(); lay.addWidget(self.sugg, 1)
        self.sugg.currentTextChanged.connect(lambda t: t and self.edit.setText(t))
        self.sugg.itemDoubleClicked.connect(lambda _: self.replace())
        row = QHBoxLayout()
        for text, fn in (("Değiştir", self.replace), ("Tümünü değiştir", self.replace_all), ("Yoksay", self.ignore),
                         ("Hepsini yoksay", self.ignore_all), ("Sözlüğe ekle", self.add_word)):
            b = QPushButton(text); b.clicked.connect(fn); row.addWidget(b)
        lay.addLayout(row)
        self.status = QLabel(); lay.addWidget(self.status)
        self.find_next()

    def _scan_from(self, row, offset):
        for r in range(row, len(self.doc.events)):
            e = self.doc.events[r]
            if e.comment:
                continue
            for s, en, w in self.sc.errors(e.text):
                if r == row and s < offset:
                    continue
                return r, s, en, w
        return None

    def find_next(self, offset=0):
        hit = self._scan_from(self.row, offset)
        if not hit:
            self.cur = None
            self.ctx.setText("<b>Yazım denetimi tamamlandı.</b>")
            self.sugg.clear(); self.edit.clear()
            return
        self.cur = hit
        r, s, e, w = hit
        self.row = r
        t = self.doc.events[r].text
        from html import escape
        self.ctx.setText(f"<small>Satır {r + 1}</small><br>{escape(t[:s])}<b style='color:#d33'>{escape(w)}</b>{escape(t[e:])}")
        self.sugg.clear()
        self.sugg.addItems(self.sc.suggest(w))
        self.edit.setText(w)
        self.on_goto(r)

    def replace(self):
        if not self.cur:
            return
        r, s, e, w = self.cur
        ev = self.doc.events[r]
        new = self.edit.text()
        ev.text = ev.text[:s] + new + ev.text[e:]
        self.changed = True
        self.on_change()
        self.find_next(s + len(new))

    def replace_all(self):
        if not self.cur:
            return
        word, new = self.cur[3], self.edit.text()
        import re as _re
        rx = _re.compile(r"(?<![^\W\d_])" + _re.escape(word) + r"(?![^\W\d_])")
        for ev in self.doc.events:
            ev.text = rx.sub(new, ev.text)
        self.changed = True
        self.on_change()
        self.find_next(0)

    def ignore(self):
        if self.cur:
            self.find_next(self.cur[2])

    def ignore_all(self):
        if self.cur:
            self.sc.ignored.add(self.cur[3])
            self.find_next(self.cur[1])

    def add_word(self):
        if self.cur:
            self.sc.add(self.cur[3])
            self.find_next(self.cur[1])

COLUMNS = ["#", "Katman", "Başla", "Bitir", "Süre", "CPS", "Stil", "Aktör", "Efekt", "Metin"]


class EventModel(QAbstractTableModel):
    def __init__(self, doc: Document, parent=None):
        super().__init__(parent)
        self.doc = doc
        self.overlaps: set[int] = set()
        self.max_cps = 20.0
        self.recompute()

    def set_document(self, doc: Document) -> None:
        self.beginResetModel()
        self.doc = doc
        self.recompute()
        self.endResetModel()

    def refresh(self) -> None:
        self.beginResetModel()
        self.recompute()
        self.endResetModel()

    def refresh_row(self, row: int) -> None:
        self.recompute()
        self.dataChanged.emit(self.index(row, 0), self.index(row, len(COLUMNS) - 1))

    def recompute(self) -> None:
        order = sorted((i for i, e in enumerate(self.doc.events) if not e.comment),
                       key=lambda i: (self.doc.events[i].start, self.doc.events[i].end))
        self.overlaps = set()
        for a, b in zip(order, order[1:]):
            ea, eb = self.doc.events[a], self.doc.events[b]
            if ea.end > eb.start and ea.style == eb.style and ea.layer == eb.layer and not (ea.effect or eb.effect):
                self.overlaps.update((a, b))

    def rowCount(self, parent=QModelIndex()):
        return 0 if parent.isValid() else len(self.doc.events)

    def columnCount(self, parent=QModelIndex()):
        return len(COLUMNS)

    def headerData(self, section, orientation, role=Qt.DisplayRole):
        if role == Qt.DisplayRole and orientation == Qt.Horizontal:
            return COLUMNS[section]
        return None

    def cps(self, row: int) -> float:
        e = self.doc.events[row]
        if e.duration <= 0:
            return 0.0
        return len(strip_tags(e.text).replace("\n", "")) / (e.duration / 1000)

    def data(self, index, role=Qt.DisplayRole):
        if not index.isValid():
            return None
        r, c = index.row(), index.column()
        e = self.doc.events[r]
        if role == Qt.DisplayRole:
            if c == 0:
                return str(r + 1)
            if c == 1:
                return str(e.layer)
            if c == 2:
                return format_ass_time(e.start)
            if c == 3:
                return format_ass_time(e.end)
            if c == 4:
                return f"{e.duration / 1000:.2f}"
            if c == 5:
                return f"{self.cps(r):.1f}"
            if c == 6:
                return e.style
            if c == 7:
                return e.actor
            if c == 8:
                return e.effect
            if c == 9:
                return e.text.replace("\\N", " ⏎ ")
        elif role == Qt.ToolTipRole and c == 9:
            return e.text
        elif role == Qt.BackgroundRole:
            if e.comment:
                return QBrush(QColor(70, 90, 70, 90))
            if r in self.overlaps:
                return QBrush(QColor(200, 60, 60, 90))
            if c == 5 and self.cps(r) > self.max_cps:
                return QBrush(QColor(220, 150, 40, 110))
        elif role == Qt.TextAlignmentRole and c in (0, 1, 2, 3, 4, 5):
            return int(Qt.AlignRight | Qt.AlignVCenter)
        return None

from __future__ import annotations
from PySide6.QtCore import QObject, QRunnable, QThreadPool, QTimer, Qt, Signal, QRectF, QPointF
from PySide6.QtGui import QColor, QImage, QPainter, QPen, QPixmap
from PySide6.QtWidgets import QLabel, QSizePolicy, QWidget
from .. import media


class _FrameSignals(QObject):
    done = Signal(int, QImage, str)


class _FrameJob(QRunnable):
    def __init__(self, serial, fn):
        super().__init__()
        self.serial, self.fn = serial, fn
        self.signals = _FrameSignals()

    def run(self):
        try:
            img = QImage.fromData(self.fn())
            self.signals.done.emit(self.serial, img, "")
        except Exception as e:  # pragma: no cover
            self.signals.done.emit(self.serial, QImage(), str(e))


class _StreamSignals(QObject):
    frame = Signal(QImage, int)
    finished = Signal()


class VideoPlayback:
    """Runs a media.VideoStream in a thread and emits QImage frames."""

    def __init__(self, info, ass_text, start_ms, width, on_frame, on_done):
        import threading
        self.stream = media.VideoStream(info, ass_text, start_ms, width)
        self.sig = _StreamSignals()
        self.sig.frame.connect(on_frame)
        self.sig.finished.connect(on_done)
        self.stop_flag = False
        self.thread = threading.Thread(target=self._run, daemon=True)
        self.thread.start()

    def _run(self):
        w, h = self.stream.width, self.stream.height
        try:
            for ms, buf in self.stream.frames():
                if self.stop_flag:
                    break
                img = QImage(buf, w, h, w * 3, QImage.Format_RGB888).copy()
                self.sig.frame.emit(img, ms)
        finally:
            self.sig.finished.emit()

    def stop(self):
        self.stop_flag = True
        self.stream.close()


class PreviewWidget(QLabel):
    """Renders the current frame (optional video) with subtitles via ffmpeg/libass, asynchronously."""
    clicked = Signal(float, float)  # script-resolution coordinates
    dragged = Signal(float, float, float, float)

    def __init__(self, parent=None):
        super().__init__(parent)
        self.setMinimumSize(320, 180)
        self.setAlignment(Qt.AlignCenter)
        self.setStyleSheet("background:#15181c;color:#8a93a0;")
        self.setSizePolicy(QSizePolicy.Expanding, QSizePolicy.Expanding)
        self.setText("Önizleme")
        self.pool = QThreadPool(self)
        self.pool.setMaxThreadCount(1)
        self.serial = 0
        self._pix = None
        self._timer = QTimer(self, singleShot=True, interval=150)
        self._timer.timeout.connect(self._kick)
        self._req = None
        self.video = None  # VideoInfo
        self.script_res = (1920, 1080)
        self.pick_mode = False

    def request(self, ass_text: str, ms: int, res: tuple[int, int]):
        self._req = (ass_text, ms, res)
        self._timer.start()

    def _kick(self):
        if not self._req or not media.available():
            if not media.available():
                self.setText("ffmpeg bulunamadı — önizleme devre dışı")
            return
        text, ms, (rx, ry) = self._req
        self.script_res = (rx or 1920, ry or 1080)
        self.serial += 1
        w = max(320, min(self.width(), 1280))
        video = self.video
        import os, tempfile

        def work():
            if video:
                fd, p = tempfile.mkstemp(suffix=".ass"); os.close(fd)
                try:
                    open(p, "w", encoding="utf-8").write(text)
                    return media.grab_frame(video.path, ms, ass_path=p, width=w)
                finally:
                    os.unlink(p)
            h = int(w * ry / max(rx, 1))
            return media.render_blank_with_subs(text, ms, w - w % 2, h - h % 2)

        job = _FrameJob(self.serial, work)
        job.signals.done.connect(self._done)
        self.pool.start(job)

    def show_image(self, img: QImage):
        self.serial += 1  # invalidate pending async renders
        self._pix = QPixmap.fromImage(img)
        self._fit()

    def _done(self, serial, img, err):
        if serial != self.serial:
            return
        if err or img.isNull():
            self.setText(err or "önizleme hatası")
            return
        self._pix = QPixmap.fromImage(img)
        self._fit()

    def _fit(self):
        if self._pix:
            self.setPixmap(self._pix.scaled(self.size(), Qt.KeepAspectRatio, Qt.SmoothTransformation))

    def resizeEvent(self, e):
        super().resizeEvent(e)
        self._fit()

    def _to_script(self, pos):
        pm = self.pixmap()
        if pm is None or pm.isNull():
            return None
        pw, ph = pm.width() / pm.devicePixelRatio(), pm.height() / pm.devicePixelRatio()
        ox, oy = (self.width() - pw) / 2, (self.height() - ph) / 2
        x, y = pos.x() - ox, pos.y() - oy
        if 0 <= x <= pw and 0 <= y <= ph:
            return x / pw * self.script_res[0], y / ph * self.script_res[1]
        return None

    def mousePressEvent(self, ev):
        if self.pick_mode:
            p = self._to_script(ev.position())
            if p:
                self._press = p
                return
        super().mousePressEvent(ev)

    def mouseReleaseEvent(self, ev):
        p0 = getattr(self, "_press", None)
        self._press = None
        if self.pick_mode and p0:
            p1 = self._to_script(ev.position()) or p0
            if abs(p1[0] - p0[0]) + abs(p1[1] - p0[1]) > 4:
                self.dragged.emit(p0[0], p0[1], p1[0], p1[1])
            else:
                self.clicked.emit(*p0)
            return
        super().mouseReleaseEvent(ev)


class WaveformWidget(QWidget):
    """Audio waveform with subtitle bars; drag start/end handles of the active line to retime."""
    seek = Signal(int)
    timing_changed = Signal(int, int, int)  # event index, start, end (live)
    timing_committed = Signal()
    kara_changed = Signal(int, list)  # event index, new durations (cs)

    def __init__(self, parent=None):
        super().__init__(parent)
        self.setMinimumHeight(110)
        self.peaks = None
        self.rate = 100
        self.events = []
        self.active = -1
        self.pos_ms = 0
        self.view_start = 0.0  # ms
        self.ms_per_px = 20.0
        self._drag = None
        self.keyframes = []
        self.kara = None  # (event_index, [durations cs], [syllable texts]) for the active line
        self.setMouseTracking(True)
        self.setFocusPolicy(Qt.StrongFocus)

    def set_peaks(self, peaks, rate):
        self.peaks, self.rate = peaks, rate
        self.update()

    def set_events(self, events, active):
        self.events, self.active = events, active
        self.update()

    def set_kara(self, idx, durs, texts):
        self.kara = (idx, list(durs), list(texts)) if durs else None
        self.update()

    def _kara_bounds(self):
        if not self.kara or not (0 <= self.kara[0] < len(self.events)):
            return []
        e = self.events[self.kara[0]]
        t, out = e.start, []
        for d in self.kara[1]:
            t += d * 10
            out.append(t)
        return out  # boundary after each syllable (last one = end of last syllable)

    def center_on(self, ms):
        w = self.width() * self.ms_per_px
        if not (self.view_start + w * 0.05 < ms < self.view_start + w * 0.95):
            self.view_start = max(0.0, ms - w / 2)
        self.update()

    def x_of(self, ms):
        return (ms - self.view_start) / self.ms_per_px

    def ms_of(self, x):
        return int(self.view_start + x * self.ms_per_px)

    def paintEvent(self, ev):
        p = QPainter(self)
        p.fillRect(self.rect(), QColor("#101317"))
        h = self.height()
        mid = h / 2
        if self.peaks is not None and len(self.peaks):
            p.setPen(QPen(QColor("#3b82c4")))
            mx = max(int(self.peaks.max()), 1)
            for x in range(self.width()):
                a = int((self.view_start + x * self.ms_per_px) * self.rate / 1000)
                b = int((self.view_start + (x + 1) * self.ms_per_px) * self.rate / 1000) + 1
                if a >= len(self.peaks):
                    break
                v = int(self.peaks[a:b].max()) / mx * (h / 2 - 4)
                p.drawLine(x, int(mid - v), x, int(mid + v))
        if self.keyframes:
            p.setPen(QPen(QColor(80, 200, 120, 130), 1, Qt.DashLine))
            for k in self.keyframes:
                x = self.x_of(k)
                if 0 <= x <= self.width():
                    p.drawLine(int(x), 0, int(x), h)
        for i, e in enumerate(self.events):
            x1, x2 = self.x_of(e.start), self.x_of(e.end)
            if x2 < 0 or x1 > self.width():
                continue
            act = i == self.active
            c = QColor(240, 180, 60, 70 if act else 30)
            p.fillRect(QRectF(x1, 0, x2 - x1, h), c)
            p.setPen(QPen(QColor("#f0b43c" if act else "#7a6a40"), 2 if act else 1))
            p.drawLine(int(x1), 0, int(x1), h)
            p.drawLine(int(x2), 0, int(x2), h)
        if self.kara:
            e = self.events[self.kara[0]]
            starts = [e.start] + self._kara_bounds()[:-1]
            p.setPen(QPen(QColor("#40e0d0"), 1))
            for i, (b, txt) in enumerate(zip(self._kara_bounds(), self.kara[2])):
                x = self.x_of(b)
                p.drawLine(int(x), 0, int(x), h)
                p.drawText(int(self.x_of(starts[i])) + 3, 14, txt)
        p.setPen(QPen(QColor("#ff5555")))
        px = self.x_of(self.pos_ms)
        p.drawLine(int(px), 0, int(px), h)
        p.end()

    def _handle_at(self, x):
        if 0 <= self.active < len(self.events):
            e = self.events[self.active]
            for which, ms in (("start", e.start), ("end", e.end)):
                if abs(self.x_of(ms) - x) < 6:
                    return which
        return None

    def _kara_handle_at(self, x):
        for i, b in enumerate(self._kara_bounds()[:-1]):
            if abs(self.x_of(b) - x) < 5:
                return i
        return None

    def mousePressEvent(self, ev):
        x = ev.position().x()
        h = self._handle_at(x)
        k = self._kara_handle_at(x)
        if h:
            self._drag = h
        elif k is not None:
            self._drag = ("kara", k)
        else:
            self.pos_ms = self.ms_of(x)
            self.seek.emit(self.pos_ms)
            self.update()

    def mouseMoveEvent(self, ev):
        x = ev.position().x()
        if isinstance(self._drag, tuple) and self.kara:
            i = self._drag[1]
            idx, durs, texts = self.kara
            e = self.events[idx]
            bounds = self._kara_bounds()
            prev = bounds[i - 1] if i > 0 else e.start
            nxt = bounds[i + 1] if i + 1 < len(bounds) else bounds[i] + durs[i + 1] * 10
            ms = min(max(self.ms_of(x), prev), nxt)
            new_a = max(0, round((ms - prev) / 10))
            total = durs[i] + durs[i + 1]
            durs[i], durs[i + 1] = new_a, max(0, total - new_a)
            self.kara_changed.emit(idx, list(durs))
            self.update()
        elif self._drag and 0 <= self.active < len(self.events):
            e = self.events[self.active]
            ms = max(0, self.ms_of(x))
            if self._drag == "start":
                e.start = min(ms, e.end)
            else:
                e.end = max(ms, e.start)
            self.timing_changed.emit(self.active, e.start, e.end)
            self.update()
        else:
            self.setCursor(Qt.SizeHorCursor if (self._handle_at(x) or self._kara_handle_at(x) is not None) else Qt.ArrowCursor)

    def mouseReleaseEvent(self, ev):
        if self._drag:
            self._drag = None
            self.timing_committed.emit()

    def wheelEvent(self, ev):
        d = ev.angleDelta().y()
        if ev.modifiers() & Qt.ControlModifier:
            x = ev.position().x()
            anchor = self.ms_of(x)
            self.ms_per_px = min(400.0, max(1.0, self.ms_per_px * (0.85 if d > 0 else 1 / 0.85)))
            self.view_start = max(0.0, anchor - x * self.ms_per_px)
        else:
            self.view_start = max(0.0, self.view_start - d * self.ms_per_px / 2)
        self.update()

"""Media helpers backed by ffmpeg/ffprobe: probing, frame grabbing (with libass subtitle burn-in),
audio peaks for the waveform and keyframe detection."""
from __future__ import annotations
import json
import os
import shutil
import subprocess
import tempfile
from dataclasses import dataclass
from typing import Optional

FFMPEG = shutil.which("ffmpeg")
FFPROBE = shutil.which("ffprobe")


def available() -> bool:
    return bool(FFMPEG and FFPROBE)


@dataclass
class VideoInfo:
    path: str
    width: int = 0
    height: int = 0
    fps: float = 23.976
    duration_ms: int = 0
    has_audio: bool = False


def _fps(s: str) -> float:
    try:
        if "/" in s:
            a, b = s.split("/")
            return float(a) / float(b) if float(b) else 0.0
        return float(s)
    except ValueError:
        return 0.0


def probe(path: str) -> VideoInfo:
    if not FFPROBE:
        raise RuntimeError("ffprobe not found")
    out = subprocess.run([FFPROBE, "-v", "error", "-print_format", "json", "-show_streams", "-show_format", path],
                         capture_output=True, text=True, check=True).stdout
    j = json.loads(out)
    info = VideoInfo(path)
    for st in j.get("streams", []):
        if st.get("codec_type") == "video" and not info.width:
            info.width, info.height = int(st.get("width", 0)), int(st.get("height", 0))
            info.fps = _fps(st.get("avg_frame_rate", "0")) or _fps(st.get("r_frame_rate", "0")) or 23.976
        elif st.get("codec_type") == "audio":
            info.has_audio = True
    try:
        info.duration_ms = int(float(j["format"]["duration"]) * 1000)
    except (KeyError, ValueError):
        pass
    return info


def grab_frame(path: str, ms: int, ass_path: Optional[str] = None, width: int = 0,
               fonts_dir: Optional[str] = None) -> bytes:
    """Return a PNG of the frame at `ms`; if ass_path is given the subtitles are rendered by libass."""
    if not FFMPEG:
        raise RuntimeError("ffmpeg not found")
    vf = []
    if ass_path:
        esc = ass_path.replace("\\", "/").replace(":", r"\:").replace("'", r"\'")
        f = f"ass='{esc}'"
        if fonts_dir:
            f += ":fontsdir='" + fonts_dir.replace(":", r"\:") + "'"
        vf.append(f)
    if width:
        vf.append(f"scale={width}:-2")
    cmd = [FFMPEG, "-v", "error", "-ss", f"{ms / 1000:.3f}", "-i", path]
    if ass_path:
        # subtitles are timed against the stream; -ss before -i resets timestamps, so shift subtitle clock
        cmd = [FFMPEG, "-v", "error", "-i", path, "-ss", f"{ms / 1000:.3f}"]
    if vf:
        cmd += ["-vf", ",".join(vf)]
    cmd += ["-frames:v", "1", "-f", "image2pipe", "-vcodec", "png", "-"]
    r = subprocess.run(cmd, capture_output=True)
    if r.returncode != 0 or not r.stdout:
        raise RuntimeError(r.stderr.decode("utf-8", "replace")[:300])
    return r.stdout


def render_blank_with_subs(doc_text: str, ms: int, width: int, height: int) -> bytes:
    """Render a subtitle frame over a black canvas with libass (no video needed)."""
    if not FFMPEG:
        raise RuntimeError("ffmpeg not found")
    with tempfile.TemporaryDirectory() as td:
        p = os.path.join(td, "s.ass")
        with open(p, "w", encoding="utf-8") as f:
            f.write(doc_text)
        esc = p.replace(":", r"\:")
        cmd = [FFMPEG, "-v", "error", "-f", "lavfi", "-i", f"color=c=0x202428:s={width}x{height}:r=25:d={ms / 1000 + 2:.3f}",
               "-vf", f"ass='{esc}'", "-ss", f"{ms / 1000:.3f}", "-frames:v", "1", "-f", "image2pipe", "-vcodec", "png", "-"]
        r = subprocess.run(cmd, capture_output=True)
        if r.returncode != 0 or not r.stdout:
            raise RuntimeError(r.stderr.decode("utf-8", "replace")[:300])
        return r.stdout


def audio_peaks(path: str, rate: int = 100, sample_rate: int = 8000):
    """Return numpy int array of per-bin absolute peaks (bins per second = `rate`)."""
    import numpy as np
    if not FFMPEG:
        raise RuntimeError("ffmpeg not found")
    p = subprocess.run([FFMPEG, "-v", "error", "-i", path, "-vn", "-ac", "1", "-ar", str(sample_rate),
                        "-f", "s16le", "-"], capture_output=True)
    data = np.frombuffer(p.stdout, dtype=np.int16)
    if data.size == 0:
        return np.zeros(0, dtype=np.int16), rate
    step = sample_rate // rate
    n = data.size // step
    data = np.abs(data[: n * step].astype(np.int32)).reshape(n, step).max(axis=1)
    return data.astype(np.int16), rate


def keyframes(path: str) -> list[int]:
    """Keyframe timestamps (ms) via ffprobe packet flags (video stream only)."""
    if not FFPROBE:
        raise RuntimeError("ffprobe not found")
    r = subprocess.run([FFPROBE, "-v", "error", "-select_streams", "v:0", "-show_entries", "packet=pts_time,flags",
                        "-of", "csv=print_section=0", path], capture_output=True, text=True)
    out = []
    for line in r.stdout.splitlines():
        parts = line.strip().split(",")
        if len(parts) >= 2 and "K" in parts[1]:
            try:
                out.append(int(float(parts[0]) * 1000 + 0.5))
            except ValueError:
                pass
    return sorted(set(out))


class AudioPlayer:
    """Plays an audio range through ffplay (no Qt multimedia dependency). Position is tracked by wall clock."""

    def __init__(self) -> None:
        self.proc: Optional[subprocess.Popen] = None
        self.start_ms = 0
        self.end_ms = 0
        self._t0 = 0.0

    @staticmethod
    def available() -> bool:
        return bool(shutil.which("ffplay"))

    def play(self, path: str, start_ms: int, end_ms: int = 0) -> None:
        import time
        self.stop()
        exe = shutil.which("ffplay")
        if not exe:
            return
        cmd = [exe, "-v", "quiet", "-nodisp", "-autoexit", "-ss", f"{start_ms / 1000:.3f}"]
        if end_ms > start_ms:
            cmd += ["-t", f"{(end_ms - start_ms) / 1000:.3f}"]
        cmd.append(path)
        self.proc = subprocess.Popen(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        self.start_ms, self.end_ms, self._t0 = start_ms, end_ms, time.monotonic()

    def position(self) -> int:
        import time
        return self.start_ms + int((time.monotonic() - self._t0) * 1000)

    @property
    def playing(self) -> bool:
        return self.proc is not None and self.proc.poll() is None

    def stop(self) -> None:
        if self.proc and self.proc.poll() is None:
            self.proc.terminate()
        self.proc = None


class VideoStream:
    """Streams rendered frames (video + libass subtitles) from ffmpeg as raw RGB, paced by wall clock."""

    def __init__(self, info: VideoInfo, ass_text: str, start_ms: int, width: int = 640, fps: float = 15.0):
        import tempfile
        self.info = info
        self.start_ms = start_ms
        self.fps = fps
        self.width = max(2, width - width % 2)
        self.height = max(2, int(round(self.width * info.height / max(info.width, 1) / 2)) * 2)
        fd, self.ass_path = tempfile.mkstemp(suffix=".ass")
        os.close(fd)
        with open(self.ass_path, "w", encoding="utf-8") as f:
            f.write(ass_text)
        esc = self.ass_path.replace("\\", "/").replace(":", r"\:").replace("'", r"\'")
        vf = f"ass='{esc}',scale={self.width}:{self.height},fps={fps}"
        self.proc = subprocess.Popen(
            [FFMPEG, "-v", "error", "-i", info.path, "-ss", f"{start_ms / 1000:.3f}", "-vf", vf,
             "-pix_fmt", "rgb24", "-f", "rawvideo", "-"], stdout=subprocess.PIPE, stderr=subprocess.DEVNULL)

    def frames(self):
        """Yield (ms, bytes) paced in real time. Frames that are late are dropped."""
        import time
        size = self.width * self.height * 3
        t0 = time.monotonic()
        n = 0
        while True:
            buf = self.proc.stdout.read(size)
            if not buf or len(buf) < size:
                return
            due = t0 + n / self.fps
            now = time.monotonic()
            if now < due:
                time.sleep(due - now)
            elif now - due > 0.25:  # too late: skip display
                n += 1
                continue
            yield self.start_ms + int(n * 1000 / self.fps), buf
            n += 1

    def close(self):
        try:
            if self.proc.poll() is None:
                self.proc.kill()
        finally:
            try:
                os.unlink(self.ass_path)
            except OSError:
                pass

import pytest

def test_turkish():
    sc = spell.SpellChecker("tr_TR")
    bad = [w for _, _, w in sc.errors(r"{\i1}Merhaba{\i0} dünyaa\Nkitaplar ABD 42")]
    assert bad == ["dünyaa"]
    assert "dünya" in sc.suggest("dünyaa")


def test_spell_dialog():
    import os
    os.environ.setdefault("QT_QPA_PLATFORM", "offscreen")
    from PySide6.QtWidgets import QApplication
    from osisub.gui.dialogs import SpellDialog
